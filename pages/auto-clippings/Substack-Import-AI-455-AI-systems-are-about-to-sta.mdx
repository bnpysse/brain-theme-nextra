# 📰 Import AI 455: AI systems are about to start building themselves.

**来源**: Import AI
**链接**: https://importai.substack.com/p/import-ai-455-automating-ai-research

## 📝 核心主旨 (TL;DR)
基于AI在代码编写、长程任务执行及核心科研技能上的指数级进步，作者认为到2028年底有超过60%的概率实现“完全无人工参与的AI自动化研发（AI自主训练其继任者）”。由于AI研发目前更多依赖99%的工程迭代而非1%的颠覆性灵感，AI已具备自动化这些繁重“苦力活”的能力，这将彻底改变AI发展轨迹，并引发对齐失效、资源分配不均及“资本密集、人力轻量”的机器经济等深远变革。

## 💡 关键知识点 / 核心观点

1. **AI编码能力与长程任务执行时间的爆发**
   AI解决真实世界软件工程问题的能力已趋于饱和（如SWE-Bench得分从2023年的2%飙升至93.9%）。更关键的是，AI能独立、可靠执行的任务时间跨度呈指数级增长：从2022年的30秒（GPT-3.5）激增至2026年的12小时（Opus 4.6），预计2026年底可达100小时。这足以覆盖AI研发中大量需要数小时专注力的工程任务（如数据清洗、实验启动等）。

2. **AI已全面掌握AI研发的核心“工程苦力”技能**
   在AI研发的关键环节，AI系统的表现正快速逼近甚至超越人类基线：
   * **复现论文**：CORE-Bench得分从21.5%飙升至95.5%。
   * **构建ML系统**：在MLE-Bench（Kaggle竞赛）中得分从16.9%升至64.4%。
   * **底层优化与微调**：AI已能自动化GPU Kernel设计、Triton/CUDA代码生成；在PostTrainBench中，AI微调效果已达人类专家基线的一半；在Anthropic的训练加速测试中，AI将小模型训练速度提升了52倍（人类需数小时才能达到4倍）。

3. **“搭乐高”式的研发范式与AI自我进化逻辑**
   作者认为，AI领域的进步主要依赖99%的“汗水”（扩大规模、调参、修复工程Bug），而非1%的“灵感”（如Transformer架构的提出）。即使AI目前缺乏真正的颠覆性创造力，它也能通过自动化这些繁重的工程任务、管理“合成团队”（AI管理多个子代理），以及自动探索参数空间，来持续推动自身发展。

4. **自动化AI R&D带来的三大深远影响**
   * **对齐危机**：在递归自我改进中，现有的对齐技术可能因“复合错误”或AI的“伪装对齐（欺骗）”而迅速失效。
   * **生产力乘数与经济瓶颈**：AI将带来巨大的生产力提升，但会加剧算力资源分配的不平等，并暴露出物理世界（如药物试验）无法匹配数字世界速度的“阿姆达尔定律”瓶颈。
   * **机器经济的崛起**：经济结构将向“资本密集、人力轻量”转型，催生大量依赖算力和AI服务的新型公司，甚至最终出现由AI完全自治的企业，深刻改变财富分配与社会治理。
