John Ternus 明日接任苹果 CEO，AI 与秋季新品成首要任务

苹果将在 9 月 1 日完成 CEO 交接：现任硬件工程高级副总裁 John Ternus 接替 Tim Cook，后者转任董事会执行主席，并继续负责与全球政策制定者沟通等事务。Ternus 同日加入董事会，原董事长 Arthur Levinson 转任首席独立董事。

据彭博社报道，Ternus 上任后很快要主持苹果秋季产品周期。今年新品包括首款折叠屏 iPhone、可识别说话者并按用户调整内容的智能显示器，OLED 版 iPad mini 预计也将在 10 月推出。

更远的产品线里，还有带摄像头的 AirPods、智能眼镜、家庭安防系统、机械臂显示器和可佩戴摄像头等。

Ternus 在苹果工作 25 年，早期负责 Mac 工程，之后陆续管理 iPad、AirPods、iPhone 和整个硬件工程部门。报道称，由于他在财务、销售、法务、政府关系和采购方面经验较少，首席运营官 Sabih Khan、首席财务官 Kevan Parekh 和服务业务主管 Eddy Cue 预计将承担更大职责。

长鑫 LPDDR6 内存量产，小米 18 Fold 将首发搭载

长鑫存储宣布 LPDDR6 内存正式量产，小米 18 Fold 将全球首发搭载，并计划在 9 月亮相。小米董事长雷军同时确认，自研玄戒 O3 芯片首家支持长鑫 LPDDR6。

LPDDR6 面向移动设备和端侧 AI 对带宽、能效的更高需求。本次量产把玄戒 O3、小米折叠屏与国产移动内存连接到同一套供应链协作中；按照双方公布的时间表，具体产品信息会随小米 18 Fold 在 9 月发布。

马斯克回应 OpenAI「断供」Cursor：毫不在意

OpenAI 宣布，已通知 SpaceX，计划逐步终止向 Cursor 直接提供 OpenAI 模型的合同，拟定停止日期为 2026 年 11 月 12 日。

OpenAI 表示，这一日期已经用足合同规定的通知期限，受影响的主要是通过 Cursor 订阅直接调用其模型的开发者。

现有模型直连在拟定日期前仍可继续使用，但 OpenAI 不会再向 Cursor 提供未来模型，包括尚未发布的 Astra。

对此，马斯克在 X 上只回了一句：「毫不在意。」

随后他继续开火，称 OpenAI CEO Sam Altman 和总裁 Greg Brockman「完全不值得信任」，并再次指责两人「偷走了一个开源非营利组织」。

马斯克与 OpenAI 的矛盾也因此进一步升级。此前马斯克已向 OpenAI 发起 1500 亿美元索赔诉讼，指控 OpenAI 与 Altman 背弃最初的非营利使命；OpenAI 则反驳称，马斯克过去曾试图夺取公司控制权。

索尼与华纳音乐出版机构起诉 Anthropic，指控其大规模盗用版权作品

Axios 报道称，索尼音乐与华纳音乐旗下出版机构于当地时间周五晚在加州北区联邦法院起诉 Anthropic，并将 CEO Dario Amodei 和联合创始人 Benjamin Mann 列为被告。原告指控 Anthropic 在开发和运营 Claude 系列模型时，通过种子下载、抓取等方式获取受版权保护的作品。

诉状长 48 页，涉及「数万首」出版商拥有版权的音乐作品。原告还称 Anthropic 盗版了数千首作品；作为对比，BMG 此前针对 Anthropic 的诉讼聚焦于 493 首作品，本案覆盖范围更广。

Anthropic 回应称不同意出版商的主张，并将积极应诉。音乐版权通常可拆分为歌词、录音和曲谱等不同权利，同一首歌可能由多方分别持有权利，这也让围绕模型训练材料的争议可能同时产生多组诉讼。

Codex 修复 8 类额度异常，付费用户同等额度预计可多用 10%～50%

OpenAI Codex 工程负责人 Tibo 表示，团队已修复 8 类会额外消耗使用额度的问题，并为 Codex 与 ChatGPT Work 付费用户重置额度。按照使用方式不同，同等额度预计可比此前多支撑 10%～50%。

本轮修复涉及图片压缩后仍保留旧图、后台记忆进程无法停止、Goal 任务越过终止条件、自动化超频运行、子 Agent 调用模型异常、Computer History 重复总结、普通对话触发额外后台请求，以及 MCP 结果重复编码或工具说明被截断后重新获取。

其中，异常 Goal 任务曾在完成后继续运行，个别案例消耗一周额度的 15%～70%；旧版 Computer History 在部分场景中每周最多消耗约五分之一额度。OpenAI 还将增加监控，发生同类回归时自动告警，并计划在应用中进一步展示额度去向。

乔布斯八年级科学展项目以 34375 美元成交

据 MacRumors 报道，乔布斯 1968 年为八年级科学展制作的「What is the SCR?」项目以 34375 美元拍卖成交。拍品包括一块三栏胶合板展示板和一份 10 页报告，主题是可控硅整流器的结构、特性与电路应用。

展示板左侧是 P 型和 N 型半导体材料构成的木制模型，中间放置测试电路，右侧绘有 25 安培可控硅整流器示意图。乔布斯还留下一张说明，要求评委把电路和示波器接通观察，并在测试后拔掉电源。

拍品由乔布斯的继兄 John Chovanec 提供，来自乔布斯家族在洛斯阿尔托斯的旧宅。Chovanec 此前也拍卖过乔布斯早年使用的海报、书桌和领结等物品。

曝小米测试智能防窥屏，可按应用和敏感页面自动启用

小米系统研究者 Kacper Skrzypek 公布的 HyperOS 界面显示，小米正在测试「智能隐私显示」功能：它会缩窄屏幕可视角度，并持续检测旁人视线；用户既可全局开启，也能只为指定应用和通知启用。

系统还出现了「页面隐私显示」和超级小爱应用分组。前者可在密码输入、支付、转账和消息等敏感页面自动开启；后者允许用户按「地铁」等场景组合相册、密码和笔记应用，再配置统一的触发规则。

截图同时列出几项边界：横屏时暂不可用，部分第三方主题可能不支持锁屏通知防窥；开启后可能略微增加耗电，省电模式会暂时关闭，播放 HDR 内容时也可能暂停亮度补偿。

百度智能云重组三大事业部，MaaS 并入基础设施、Agent 独立成军

据《晚点 LatePost》报道，百度智能云近日完成产研组织调整。原平台产品事业部更名为智能体事业部，MaaS 业务、千帆品牌及相关产品转入基础设施事业部；数据平台部更名为数据智能部，并入智能应用事业部。

调整后，侯震宇负责基础设施事业部，管理 AI Infra 和 Agent Infra；殷大伟负责智能体事业部，聚焦百度搭子、秒哒和伐谋等通用 Agent 产品；阮瑜负责智能应用事业部，管理百度一见、Hogee、胜算以及交通、金融等行业应用。三人均向百度集团执行副总裁、智能云事业群总裁沈抖汇报。

这轮调整从今年二季度开始酝酿，8 月正式落地，相关团队的编制和汇报关系同步变更。MaaS 与算力、芯片和云资源被放入同一事业部，以减少大型客户同时对接算力和模型团队的协调成本；通用智能体团队则会集中推进用户增长、产品体验和订阅制等商业化探索。

微信今年已处置 85831 个账号名称信息违规账号

微信珊瑚安全发布「整治账号名称信息乱象」专项行动第五期公告称，今年以来已处置 85831 个账号、关闭 1802 个账号，问题包括仿冒官方机构或媒体、未经认证添加专业头衔、伪装特定职业人员、蹭炒热点，以及在昵称和资料中夹带违规信息。

平台列举的案例包括使用「文旅发布」「融媒」等表述营造官方或媒体身份假象，以及未认证便在账号资料中添加财经、医疗、司法、教育等专业头衔。对应处置方式包括清空资料、禁言和封号。

微信提醒，账号名称、头像和简介不得冒用党政军机关、新闻媒体或名人身份，也不能嵌入导向色情、赌博等违规网站的外链及二维码。希望展示专业身份的账号，需要先完成平台资质认证，再添加相关头衔。

高通拉来三星与海力士推进 HBC，首代产品计划明年出货

据 TrendForce 援引高通高管在德意志银行 2026 科技大会上的发言，三星电子与海力士正参与高通 HBC 高带宽计算方案的商业化，首代 HBC 产品计划于明年出货。台积电预计负责技术整合与先进封装。

HBC 把多层 LPDDR 堆叠在计算芯片上，试图减少内存与计算单元之间的数据搬运。高通负责核心设计、系统整合和 TSV 方案，三星与海力士提供 DRAM 堆叠，并继续推进各自的 HBM 路线。

高通称，HBC 面向 AI 推理中的带宽、功耗和成本问题。现阶段公开性能数据主要来自公司估算，相关产品仍需等待实际芯片和第三方测试验证。

Dario Amodei：Anthropic 希望与软件公司共建产品，而非取代所有 SaaS

Anthropic CEO Dario Amodei 本周与 Salesforce CEO Marc Benioff 一同接受 CNBC 采访时表示，公司「无意摧毁任何人」，希望通过合作创造新价值，并让用户与合作伙伴共享收益。他把 Anthropic 与现有软件公司的关系描述为正和合作。

两家公司同日扩大合作，推出名为「Claudeforce」的产品组合。合作方案包括让 Claude 在 Agentforce 中作为 Atlas 推理模型，进入 Agentforce Vibes、Agentforce Coworker 和 Agent Builder，并成为 Slack 中的默认 AI 模型。这项合作也回应了市场对 AI 智能体压缩传统 SaaS 空间的担忧。

Amodei 还强调，合作已经是双向的：Anthropic 在内部使用 Salesforce，Salesforce 团队则使用 Claude Code 和 Cowork。Claude 进入 Slack 之后，企业员工可在现有沟通环境中调用模型，无需另建一套工作入口。

在这套分工中，Anthropic 提供模型的推理和代码能力，Salesforce 继续管理 CRM 数据、业务上下文、安全和权限。Amodei 认为，两者结合可以形成「一加一大于二」的产品，前提是与客户和软件伙伴一起创建业务流程。

Grok Bot 上线使用指南库、支持复制和分享 Bot 配置

SpaceXAI 上线 Grok Bot Guides，集中展示工程、产品、设计和销售团队使用 AI Bot 的实际流程，包括多 Bot 协作、移动应用开发、设计探索和企业客户管理。

Grok Bot 是运行在持久云端计算机上的 AI 队友，可使用浏览器、文件系统和终端执行任务。多个 Bot 共享同一台计算机上的文件与登录会话，也能彼此传递上下文；遇到登录、验证码或高风险操作时再请求用户接管或批准。

新文档还说明了复制与分享机制：复制 Bot 会保留身份、设置、skills、routines 和头像，但不复制对话历史、记忆与附件；公开分享链接会暴露 Bot 的身份、描述、skills 和 routines，官方提醒用户先移除 API Key、内部 URL 和客户数据。

中国地震局公布全国预警渠道，覆盖手机、应用和专用终端

中国地震局更新了全国地震预警信息公众服务渠道。公众可以通过华为、小米、vivo、OPPO、一加和 realme 手机的系统功能接收预警，也可使用微信小程序、腾讯 QQ、支付宝及各地地震部门提供的服务。

国家地震烈度速报与预警工程于 2024 年投入使用。两年来，官方累计公开发布地震预警信息 700 余次，服务超过 9000 万人次，公众服务规模突破 4.6 亿人。

Tavus 发布 Sparrow-2，让语音 Agent 学会等待和识别环境声

AI 视频公司 Tavus 发布实时对话理解模型 Sparrow-2，并已在 Tavus PAL、API 和企业平台中正式可用。它不再只用静音时长判断用户是否说完，而是同时分析语义、词汇结构、语调、停顿、说话人和环境声音，持续判断系统应当倾听、等待、说话还是继续说。

Sparrow-2 以 10ms 帧率流式处理音频，每秒可更新 100 次对话状态，粒度较上一代提高 4 倍；处理 80ms 音频约需 7ms，上一代约为 30ms。模型可区分「嗯」等附和与真正打断，在用户思考时等待 6～8 秒，并在声音无法可靠辨认时请求重复，而非基于错误转写继续回答。

Tavus 称，模型使用 1.6 万段真实对话和 2000 段合成对话训练。在 575 个真实对话事件测试中，Sparrow-2 的时机判断失败率为 2.1%，约为最佳对比模型的四分之一；面对超过 1 秒的思考停顿，它有 97% 的情况不会抢话。上述对比包含 Tavus 自建评测，LiveKit 仅采用可在设备端运行的 v1-mini，并非其最先进模型。

Terminal-Bench 4.0 发布，GLM-5.3 排名第三

Terminal-Bench 发布 4.0 版，用于衡量 AI 智能体在终端环境完成复杂任务的能力。新版重新校准了任务的执行时间、CPU 和内存配置，并移除 8 个存在饱和、拒答、公开解法或质量问题的任务；其余任务也按统一规范更新。

官方榜单显示，在最高推理强度下，Claude Code 搭配 Opus 5 以 51.8% 的准确率排名第一，Fable 5 以 44.5% 排名第二；Claude Code 搭配 GLM-5.3 获得 41.8%，排名第三。Codex 搭配 GPT-5.6 Sol 的准确率为 37.3%，位列第四。

不同组合使用的智能体框架、推理强度与资源消耗并不相同，名次不能单独视为模型能力的通用排名。官方榜单还保留每次评测的 token 消耗、误差范围与发布日期，便于比较相同配置下的结果。

交通运输部：ETC 不取消，年底扩大「手机+」无卡通行覆盖

针对网友建议取消 ETC 设备、改用车牌绑定支付软件的留言，交通运输部公路局回应称，ETC 仍是提高收费公路通行效率的重要技术手段，车主可根据需求自愿办理。

交通运输部已印发《高速公路「手机+」无卡便捷通行实施方案（2026—2028 年）》。该模式使用车牌识别还原行驶轨迹并核算通行费，未安装 ETC 的小型载客汽车可在 MTC 车道通过电子支付，省去领取和交还 CPC 卡。

按计划，2026 年底前，成渝、长三角区域高速公路入口 MTC 车道和全网出口 MTC 车道，将对 9 座及以下小型载客汽车实现「手机+」无卡便捷停车通行全覆盖。新模式将与 ETC、MTC 长期并行，高频出行用户仍可使用 ETC 全程不停车通行并享受 95 折通行费优惠。
