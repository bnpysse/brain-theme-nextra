### ADR：企业AI检测与响应系统

ADR（Agentic AI Detection and Response）是用于人工智能代理的网络安全系统。它帮助组织保护面向员工的代理，如Cursor、Claude Code和Codex，以及面向客户的代理，如AI支持代理。

ADR 在优步的生产环境中部署，并且相关的论文已被接受为 **MLSys 2026**：[Paper PDF](docs/adr-paper.pdf) · [Slides PDF](docs/adr-mlsys-2026-slides.pdf)

### ADR 如何保护企业AI代理

ADR 通过四种互补能力来保护企业AI代理：观察代理活动、评估防御措施、检测威胁以及防止不安全的操作。

1. **ADR 观察性：理解AI代理正在做什么及原因。**在生产环境中，ADR 捕获来自 Claude Code、Cursor、Codex 和其他代理的意图、工具使用和执行追踪，跨越7+种基于MacOS、Linux 和 Windows 的人工智能编程工具，以及内部自动化和面向客户的支持代理。
2. **ADR 测试基准：在现实的企业环境下测试代理的安全性。** ADR-Bench 包含300 多个任务、133 个 MCP 服务器及所有 17 种攻击技术的覆盖范围。
3. **ADR 检测：高效检测风险行为。**其两层架构结合了高召回率的初步筛选和深入的人工代理推理，用于可疑会话。
4. **ADR 防止：在它们导致伤害之前阻止不安全的操作。**这个组件未包含在当前的开源版本中。请稍后关注。

### 仓库布局

此仓库包含了论文中描述的开源 ADR 检测器、ADR 测试基准及 ADR 探险器。离线运行的 ADR 探险器引擎，通过预先部署红队活动来加固ADR 检测，未包含在此处。

| 路径                       | ADR 组件               | 描述                                                                                           |
| --------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------- |
| [Sensor/](Sensor/)         | ADR 观察性              | 收集并规范化来自 Claude Code、Cursor、Codex 等代理的 telemetry 数据                                                     |
| [Detection/](Detection/)  | ADR 测试基准 + 检测    | 双代理检测器，133个 MCP 服务器，303个测试基准任务、基线以及绘图脚本                                                   |

### 快速开始：ADR 检测

```bash
git clone https://github.com/uber/ADR
cd ADR/Detection
uv sync
export ANTHROPIC_API_KEY="..." OPENAI_API_KEY="..."
```

默认的检测器是 `adr`（ADR 双代理）。对于无密钥的烟雾测试，请使用 `--detector llamafirewall` （参见 [Detection/README.md](Detection/README.md)）。

请查看 **[docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md)**，了解完整的评估工作流程（扩展打包的基准 → 运行检测器 → 绘制图表）。

组件文档：

- [Sensor/README.md](Sensor/README.md)：telemetry 收集和统一 schema
- [Detection/README.md](Detection/README.md)：ADR 测试基准、基线检测器及 MCP 基础设施
