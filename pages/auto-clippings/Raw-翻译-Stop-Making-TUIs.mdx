Stop Making TUIs

Thomas Ptacek advocates for building real native user interfaces for even the smallest of personal tools, because coding agents have reduced the cost of getting a usable-enough GUI up and running to almost nothing.
Thomas Ptacek 主张即便是最小的个人工具也要构建真正的原生用户界面，因为编码代理已经把让一个足够可用的 GUI 启动并运行的成本降到了几乎为零。

I wrote about my vibe-coded bandwidth and GPU monitoring macOS task bar apps

back in March

, and I'm still using both of those on a daily basis.
我在三月份写过关于我用氛围编码方式制作的 macOS 任务栏带宽和 GPU 监控应用，而且我至今仍在每天使用它们。

I'm not habitually knocking out real UIs for my other projects yet, but I'm running out of excuses!
我还没有习惯性地为我的其他项目快速打造真正的 UI，但我已经快没有借口了！
