【文章标题】：PSSA: 一款用Rust从零编写的非Transformer语言模型

【文章正文】：

PSSA是一个小型非Transformer架构的语言模型。它通过循环状态空间层逐标记读取文本，维护一个可查询的情景记忆库，并在运行时动态重写部分自身权重。该模型完全使用Rust从零编写，底层没有使用PyTorch、TensorFlow或任何机器学习框架。

在参数规模相同且使用相同语料的情况下，其学习速度超越Transformer，在相同CPU上文本生成速度快约12倍。

Transformer需要计算上下文所有标记对的关系，因此单步计算成本随序列长度平方级增长，且每步都需重新读取整个上下文。PSSA采用固定尺寸状态从左至右单向处理序列，通过记忆库查询替代上下文重读，计算成本仅随长度线性增长。

两个模型使用相同语料、相同分词器、相同优化器配置、相同随机种子和相同参数数量。一个是PSSA，另一个是标准Transformer。在1270万标记的清洗版WikiText-103上：

PSSA最终训练交叉熵为3.98，Transformer为4.43，相差0.45纳特，困惑度分别为53.7对83.7。Transformer耗尽全部1270万标记预算才达到PSSA在约200万标记时已突破的损失值。

两条损失曲线始终无交点：

训练损失仅反映模型对输入流的拟合程度。因此我们对两个模型的检查点在从未接触过的198,939标记语料片段上进行评估：

两个训练过程的所有检查点（64个PSSA和43个Transformer）在未见过语料的9,934标记窗口上测试。曲线始终无交点：PSSA从首个检查点就保持领先，最终差距0.51纳特。下表为完整片段上两个模型的最终检查点表现：

| 保留测试片段(198,939未见过标记) | PSSA | Transformer |

|---|---|---|

| 交叉熵 | 3.997 | 4.429 |

| 困惑度 | 54.4 | 83.8 |

| 下一标记准确率 | 24.1% | 18.0% |

0.43纳特的保留测试差距与训练差距基本一致。PSSA并非记忆更强，而是泛化更优。

循环模型携带固定尺寸状态，因此新增标记的计算成本不随上文长度增长。Transformer每步都需重读整个上下文。

核心技术特征：

- 循环状态空间核心。通过可学习的连续状态矩阵在固定尺寸状态中传递信息，而非基于全上下文窗口的注意力机制

- 情景记忆库。512个存储槽配合双曲(Poincaré风格)检索与限位Top-4搜索，支持运行时读写

- 可塑性权重。快速更新强化有效模式，新颖性驱动增长， refractory门限机制防止重复矛盾输入造成过度破坏

- 闭式巩固。岭回归步骤将快速可塑性更新折叠回基础转移矩阵，类似睡眠巩固日间学习机制

- 无框架依赖。Rust手写线性代数，同时提供CUDA训练路径和标量CPU参考实现（最大梯度差异2.98e-8）

关于实验规模的说明（避免过度解读上述数字）：

- 这是1270万标记数据上的150万参数模型，属研究原型，不可与主流模型直接对比

- 该规模下两个模型的文本质量均较差。PSSA生成"普里安学院的barget"，Transformer生成"美国的物质循环"。比较重点在于学习效率而非流畅度

- 速度对比基于相同CPU环境公平测试。后文训练吞吐量数据因硬件不统一，不应视为架构优势

- 两项实验尚未进行：语料切换后早期技能的保留情况，以及移除记忆库对损失的影响

使用说明：

git clone https://github.com/Sparticle62ops/pssa.git

cd pssa

cargo build --release

./target/release/oxide_ai_pssa

无参数运行时将显示主界面，列出所有命令及工作目录下的检查点与语料。

上述结果均在免费托管笔记本（配备入门级GPU）上以20万标记为批次训练获得（因会话数小时后会被终止）。所有未解问题——该优势在10倍或100倍参数规模下是否保持、记忆库在大规模时的作用、与现代循环基线的对比——都需要配备真正显存GPU且能持续数天计算的资源支持。任何显著超越本次使用的入门级显卡的设备都将拓展研究边界。
