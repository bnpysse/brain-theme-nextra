# 📋 技术情报简报：Decision 3.0 开源多模态决策模型

## 📌 TL;DR

vLLM Semantic Router 团队发布了 **Decision 3.0 (d3)** —— 一个全新的开源（Apache-2.0）多模态决策模型系列，参数规模从 0.6B 到 27B 共 6 个版本，基于 Qwen3.5/Qwen3.8 构建，支持文本、图像和视频输入。该系列在 **Jev 决策指数（Jev Decision Index）文本和视觉两个榜单上均排名第一**，其中 27B 版本分别获得 64.7（文本）和 71.6（视觉）的高分，且所有尺寸模型均在其类别中领先。最引人注目的是其**视频零样本能力**——模型在训练中从未见过视频数据，却在 Perception Test 全部 19,140 个验证问题上取得了 77.4（27B）的高分。

## 🔍 核心观点与技术细节

### 模型架构与规格

| 特性 | 详情 |

|------|------|

| **基础模型** | Qwen3.5（0.8B / 2B / 4B / 9B）+ Qwen3.8-27B |

| **参数规模** | 0.6B ~ 27B（含视觉编码器：4B 含 0.33B，27B 含 0.46B） |

| **许可证** | Apache-2.0（完全开源） |

| **训练硬件** | AMD Instinct MI325X |

| **权重格式** | BF16，通过 Transformers 加载（trust_remote_code=True） |

### 核心技术创新

- **纯决策输出，无文本生成**：模型输出三种决策类型——选择（choice）、是/否（yes/no）、评分（score），每个答案附带概率值，不生成文本。这种设计大幅降低了推理延迟和计算开销。

- **批量问题处理**：对同一输入提出的多个问题可在一次调用中完成，每个问题通过各自的前向传播独立处理输入，提高了多任务场景下的效率。

- **多模态输入能力**：

- **图像**：单请求支持多张，最高 160 万像素（1.6 MP）

- **视频**：单请求支持多个（MP4、WebM、MOV、MKV），以 2 fps 采样，整个片段最多 32 帧，每帧最高 20 万像素（0.2 MP）

### 性能表现

- **Jev 双榜第一**：27B 版本文本得分 64.7、视觉得分 71.6，超越所有已列出的模型（包括 Jev 自家模型）

- **全尺寸类别领先**：0.6B、0.8B、4B、9B 各版本均在其尺寸类别中排名第一

- **跨代际超越**：9B 版本（d3-flash）已超越上一代 27B 版本（Decision 2.0），体现了架构效率的显著提升

- **视频零样本 SOTA**：27B 在 Perception Test 上得分 77.4，4B 得分 70.3——**训练中从未见过视频数据**，纯靠泛化能力达到此水平

## 🎯 核心痛点

1. **传统 LLM 在决策场景中的低效性**：通用大模型通过文本生成来完成决策任务，存在延迟高、计算开销大、输出不可控等问题。Decision 3.0 通过直接输出结构化决策结果（选择/是/否/评分）绕开了文本生成环节，从根本上解决了这一痛点。

2. **多模态决策模型的稀缺性**：现有开源决策模型大多局限于单一模态（纯文本），而现实世界的决策场景（如内容审核、视觉问答、视频分析）往往需要同时处理图像和视频信息。Decision 3.0 以 Apache-2.0 协议开源了全模态覆盖的决策模型，填补了这一空白。

3. **小模型性能不足的困境**：在边缘计算和资源受限场景中，小模型往往因性能不足而无法胜任复杂决策任务。Decision 3.0 通过架构优化实现了 9B 模型超越上一代 27B 模型的性能跃升，大幅降低了高性能决策模型的使用门槛。

4. **视频理解的高成本问题**：传统视频理解模型需要大量视频训练数据，且推理成本极高。Decision 3.0 展示了强大的视频零样本泛化能力，无需视频训练数据即可实现高精度视频决策，大幅降低了视频 AI 应用的开发和部署成本。

5. **决策过程不可解释性**：通用 LLM 的决策过程是黑盒，难以获取每个选项的概率置信度。Decision 3.0 为每个决策输出概率值，使决策过程更加透明、可审计，便于集成到需要置信度评估的业务流程中。
