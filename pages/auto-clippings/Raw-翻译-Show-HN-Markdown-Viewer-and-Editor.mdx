I built an online viewer and editor for .md files where the file stays on your machine. Free to use and code is available under MIT License here:  
我开发了一个在线.md文件查看器和编辑器，文件始终保存在您的本地机器上。完全免费使用，代码遵循MIT许可证在此处开放：  

https://github.com/hattray/markdown-editor  
https://github.com/hattray/markdown-editor  

You can also install it as a Chrome/Edge app so that it works for files on your desktop by double-clicking.  
您还可以将其安装为Chrome/Edge应用，通过双击即可直接打开桌面上的文件。

支持标准.md文件格式，包含代码语法高亮、目录生成、Mermaid图表、通过KaTex实现的LaTeX公式。同时支持导出为.html、.pdf和.png格式。  

Please give it a try and share your feedback for improvements.
