【文章标题】：用了阔直板华为，忘了回忆里的黑莓｜华为 Pura X View 评测

【文章正文】：
自从智能手机进入细长的全面屏时代，就不断有人想要回归当年黑莓全键盘的打字体验。

这种需求先是催生出了一些全键盘手机壳，又促成了 Unihertz Titan 2 Elite 和 Clicks Communicator 这样的全键盘智能手机：

Unihertz Titan 2 Elite｜ZDNET

但上面那些都是众筹级别的小打小闹——

在致敬黑莓这条赛道上，至今没有黑莓以外的真正大厂入局。

直到华为推出了它的 Pura X View：

作为 Pura 家族的新成员，Pura X View 在这个「细狗当道」的年代选择回归传统比例，用一块 16:9.5 的屏幕完成了一次视觉文艺复兴。

如果把键盘改成黑色，让 Pura X View 直接 cosplay 成黑莓 Classic、9720 甚至 Q10 也未尝不可：

当然文艺复兴只是一种表象。在深度使用了 Pura X View 之后，我们觉得这是 2026 年迄今为止第一台称得上「有趣」的手机。

先阔带后阔

其实单从形态来说，Pura X View 只做了一件事——

沿用 Pura X 展开后的竖向宽屏

，而没有选择 Pura X Max 那样的横向宽屏。

而事实证明，Pura X View 也只需要做好这一件事。

Pura X View 的对角线尺寸仅为 6.39 寸，从数字上看仿佛是个「小屏机」。

但在 16:9.5 比例下，它的

实际显示面积为 114.27 平方厘米

，超过了很多 Pro Max 机型：

Pura X View（左）与 Pura 90 Pro（右）

毕竟以对角线论面积的习惯，还是上世纪 50 年代比例统一的 CRT 时代形成的，已经不太适合如今长宽比迥异的 OLED 时代了。

这样一来，用 Pura X View 看视频，从流媒体到 IMAX，只要不是超宽幅，都可以获得相当沉浸的效果，优势和阔折叠一模一样。

同理，一个

比常规直板机更宽

的屏幕对于阅读电子书和漫画来说，也有着前者难以比拟的优势——接近纸质书开本的沉浸感：

更重要的是，Pura X View 的优势场景看似与阔折叠差不多，但它却规避了那个最致命的问题：软件适配。

换言之——

我们在阔折叠上看到的那些暴力拉伸、DPI 过大过小、控件错位的 app，哪怕是卓易通里面，在 Pura X View 上全都可以正常显示。

并且 Pura X View 的形态还有一个隐性优势：竖屏。

由于现在的 app 大多是信息流 UI，在我们使用 Pura X 和 Pura X Max 的时候，经常需要反复转动手机在横竖屏之间切换使用。

而在 Pura X View 上，由于它一开始就不存在折叠屏的横竖问题，我再也不需要向 Pura X 那样来来回回地转手机了——

就拿知名问题学生「美团」来说，它在 Pura X View 上完全不会出现三星 Z Fold8 与鸿蒙版发布初期的字比图大、图比脸大的问题。

因此目前，由于竖向信息流/视频流依然是 UI 绝对主流，Pura X View 这样的「阔直板」在使用时相比「阔折叠」，无疑是更加省心省事的。

让直板机重新有趣

有关屏幕形态的优势和短板，在今年阔折叠集中爆发的背景下，我们其实已经讨论过非常多相关的内容了。

而 Pura X View 的真正优势在于，

除了一块足够新奇和好用的屏幕之外，它本身的硬件功底同样扎实。

就拿续航来说，Pura X View 在 201g 的机身里塞下了足足 7000 毫安时的硅碳负极电池。

搭配鸿蒙 7 与麒麟 9030s 的优秀功控，在我的使用习惯下，它是一台

两天一充

的手机——

在极限情况中，这台 Pura X View 从我早上 7 点起床赶飞机、全程 5A 流量、蓝牙和热点混合到晚上 8 点半，

亮屏 6 小时 22 分钟

之后，剩余电量仍然有 60%：

虽然没有游戏这样的重负载应用，但一台

能刷六个半小时小红书

的手机，续航已经比我的命都要长了。

除此之外，Pura X View 的影像素质也没有掉队。

2 亿像素主摄可以在光线充足的情况下实现不错的细节还原，3.7 倍长焦的最近对焦距离也可以满足绝大多数微距场景：

再加上 XMAGE 智拍、新版本色卡、AI 姿势推荐与辅助构图，可以说 Pura X View 除了有点难拿稳之外，在影像能力上是完全不掉队的：

只不过在聊了这么久 Pura X View 特殊的机身比例带来的好处之后，我们也不得不面对它存在的一些问题。

比如宽阔的机身虽然带来了绝佳的打字体验，但也让长时间的握持比普通直板机更累人——

使用 Pura X View 的这几天里，我的手指出现了非常明显的酸痛，这还是在不戴壳的前提下。长期的主力机使用有可能会带来更多的手部疲劳：

另外 Pura X View 四种配色

全是亮面背板 + 亮面边框

，即使有背板疏油层的帮助，沾指纹的现象还是非常明显。

另外对于计划买来双持的用户来说，目前鸿蒙微信在 Pura X View 上

不支持平板模式登陆

，未来是否会调整策略还有待观察：

因此，Pura X View 相比它的折叠屏兄弟，在硬件上其实更像 Pura 数字系列的特殊分支——

想要入手，就必须做好当作主力机的准备。

为什么只有华为能做 Pura X View

从 2026 年整体来看，Pura X 系列无疑是日趋沉闷的手机市场里，难得的形态创新者。

这样一来，就有一个问题摆在了我们面前：

16:9 又不是什么外星科技，为什么只有华为第一个想起来造「阔直板」？

或者换个角度——为什么只有华为能在不景气的手机市场里，以一浪高过一浪的话题度，不断推出具有探索性质的新形态？

归根结底，无论 Pura X、Pura X Max 还是 Pura X View，本质上都是尝试突破市场陈规、寻求新形态话语权的产品。

而这种「试验」，真就只有苹果华为这样的头部厂商可以支撑得起——而苹果还在忙着研究折叠屏，已经很久没有推陈出新的大动作了。

另一方面，我们也可以认为，整个 Pura X 系列本质上都是鸿蒙成熟到一定程度之后所带来的创新性的必然。

对于那些想要尝试新形态产品、又不希望花小一万买折叠屏的用户来说，

Pura X View 就是 2026 年内最有趣的手机，没有之一。
