【帖子正文】：

I'm the developer of Dragon IDE. It's a Code - OSS editor with OpenCode embedded as the coding agent.

For local-model users, the idea is to connect Ollama and use an agent inside the editor without a required Dragon account or editor subscription. You can also bring cloud provider keys when you want another model.

The README documents local code search, local tab completions, inline edits, permission modes and an OpenCode terminal interface that shares sessions with the chat. The agent's edits appear as reviewable diffs.

Downloads are available for Mac, Windows and Linux. It's early, and I would especially like feedback on model selection, hardware fit and how reliably local models complete coding tasks.

If you try it, what model and hardware did you use, and where did it fail?
