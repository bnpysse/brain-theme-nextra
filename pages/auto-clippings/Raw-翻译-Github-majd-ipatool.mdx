# IPATool

[![Release](https://img.shields.io/github/release/majd/ipatool.svg?label=Release)](https://GitHub.com/majd/ipatool/releases/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/majd/ipatool/blob/main/LICENSE)

`ipatool` 是一个命令行工具，允许您在 [App Store](https://apps.apple.com) 上搜索 iOS、iPadOS、tvOS 和 visionOS 应用，并下载应用程序包的副本，即所谓的 _ipa_ 文件。

## 系统要求

- 支持的操作系统（Windows、Linux 或 macOS）
- 已设置可用于 App Store 的 Apple ID

## 安装指南

### 手动安装

您可以从 [GitHub 发布页面](https://github.com/majd/ipatool/releases) 获取最新版本的 `ipatool`。

### 包管理器 (macOS)

您可以使用 [Homebrew](https://brew.sh) 安装 `ipatool`。

```shell
$ brew install ipatool
```

## 使用说明

要验证 App Store 身份，请使用 `auth` 命令。

```
与 App Store 进行身份验证

用法：
  ipatool auth [命令]

可用命令：
  info        显示当前账户信息
  login       登录 App Store
  revoke      撤销您的 App Store 凭证

标志：
  -h, --help   显示帮助信息

全局标志：
      --format format     设置命令输出格式；可选 'text'、'json'（默认为 text）
      --non-interactive   以非交互模式运行
      --verbose           启用详细日志

使用 "ipatool auth [command] --help" 获取命令的更多信息。
```

要在 App Store 上搜索应用，请使用 `search` 命令。

```
搜索 App Store 上可用的 iOS、iPadOS、tvOS 和 visionOS 应用

用法：
  ipatool search <搜索词> [标志]

标志：
  -h, --help              显示帮助信息
  -l, --limit int         要检索的搜索结果最大数量；visionOS 最多支持 12 个（默认 5）
      --platform string   搜索平台：iphone (iOS)、ipad (iPadOS)、appletv (tvOS) 或 visionos

全局标志：
      --format format     设置命令输出格式；可选 'text'、'json'（默认为 text）
      --non-interactive   以非交互模式运行
      --verbose           启用详细日志
```

要获取应用的许可证，请使用 `purchase` 命令。

```
从 App Store 获取应用的许可证

用法：
  ipatool purchase [标志]

标志：
  -b, --bundle-identifier string   目标 iOS 应用的包标识符（必需）
  -h, --help                       显示帮助信息

全局标志：
      --format format     设置命令输出格式；可选 'text'、'json'（默认为 text）
      --non-interactive   以非交互模式运行
      --verbose           启用详细日志
```

要列出已验证账户拥有的应用，请使用 `list-purchases` 命令。结果按购买日期排序，最新的排在前面。

```
列出已验证 App Store 账户拥有的应用

用法：
  ipatool list-purchases [标志]

标志：
  -h, --help              显示帮助信息
  -l, --max-results int   每页返回的最大应用数量（默认 10）
  -p, --page int          要返回的拥有应用页数（默认 1）

全局标志：
      --format format               设置命令输出格式；可选 'text'、'json'（默认为 text）
      --keychain-passphrase string  解锁钥匙串的密码
      --non-interactive             以非交互模式运行
      --verbose                     启用详细日志
```
