### 核心总结
- 作者发布了一套面向真实工程（而非“氛围编程”）的智能体技能，强调小巧、易调整、可组合，适用于任何模型，并批评 GSD/BMAD/Spec-Kit 等重流程方法夺走控制权、难以排查问题。
- 提供两种安装方式：Claude Code 插件（只读、自动更新）与 skills.sh（可编辑、可定制），安装后需运行 `/setup-matt-pocock-skills` 配置问题跟踪器、标签和文档位置。
- 技能旨在修复编码智能体常见失败模式，首要问题是智能体未按用户意图执行，根源在于“没人确切知道自己想要什么”。
- 鼓励开发者改造技能为己用，并可通过 newsletter 跟踪更新。
