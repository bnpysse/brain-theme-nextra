# 精选简报：非洲“锁矿潮”下的中非资源贸易变局

&gt; **来源**：虎嗅网 / 环球零碳 | **原文链接**：[非洲又禁两种关键矿产，一年超10国“锁矿”，收入却翻倍](https://www.huxiu.com/article/4889899.html?f=rss)


## 📌 TL;DR

非洲正在集体告别“只卖原矿”的时代。以津巴布韦为代表，近一年至少10个非洲国家相继出台原矿出口禁令或管制措施，试图复制印尼的镍产业路径——用资源主权倒逼外资在本地建设加工产能、留下附加值。短期内这一策略已初见成效：津巴布韦2026年Q1矿产品出口量仅增长27%，出口额却大涨79%，锂出口收入更是翻倍。然而，非洲自身的电力、电网、交通等基础设施短板严重制约深加工发展。这一困境恰好催生了中非合作模式的结构性转变：中国企业开始将加工厂、配套电力设施直接建在非洲，配合中国对非洲53国全面零关税政策，一条“非洲资源+中国产能+中国市场”的新产业链正在形成。


## 🔍 核心洞察深度展开

### 1. 津巴布韦的“锁矿实验”：出口禁令的经济账

津巴布韦是这轮资源民族主义潮的急先锋。2026年9月8日，该国宣布即刻禁止锑与钨的原矿和精矿出口，此前已先后叫停锂精矿出口、罗列14种受管制关键矿产。禁令执行极为严苛——无过渡期、无配额、不允许特例，在途和港口待运货物一律不得出境。

**关键在于数据验证了策略的有效性**：据津巴布韦矿产营销公司（MMCZ）数据，2026年Q1该国矿产品出口量仅增长27%，出口额却增长79%至9.84亿美元；锂出口收入从8419万美元增至1.79亿美元，直接翻倍。“矿没多卖，钱多赚了”——这为其他非洲国家提供了极具说服力的示范效应。

### 2. 印尼“镍路线图”的非洲复制

文章点明了非洲各国的政策模板：印度尼西亚此前通过禁止镍原矿出口、强制外资建设冶炼厂、通过国企谈判获取股权，最终使其控制了全球超40%的镍精炼产能。这条路印尼走了10年，津巴布韦试图以“月”为单位加速复制。

其逻辑链是：**资源换加工 → 加工带走技术 → 技术沉淀为产业能力 → 产业能力转化为股权谈判筹码**。非洲坐拥全球30%关键矿产储量（刚果金钴资源占全球75%，津巴布韦锂矿品位高、成本低），过去低价出口原矿，却在高价值的电池、电动车环节中缺席。从2022年起，非洲国家“集体变脸”，2025年非盟启动《非洲矿业愿景2030》框架，近20个国家组建矿产战略联盟，统一要求外资“建厂、留技术、雇本地人、分红利”。

### 3. 硬约束：矿业深加工不是“挖出来烧一烧”

文章对津巴布韦“愿景与现实”的落差做了冷静分析，以钨为例展现了产业链门槛：

&gt; 钨矿石 → 破碎磨矿选矿（钨精矿）→ 化学冶炼（仲钨酸铵APT）→ 煅烧（氧化钨）→ 还原（高纯钨粉）→ 碳化钨/硬质合金/钨丝

每一步的技术、设备、环保和产业经验要求呈指数级上升。津巴布韦目前的加工能力停留在“选矿成精矿”层面，缺乏成熟的产业链和基础设施配套。

**最现实的瓶颈是电力**。津巴布韦《国家增长与就业报告》显示，电力供应不可靠是企业和家庭面临的最大制约因素，停电造成的经济损失约占GDP的6%。2021年至2026年Q1，津巴布韦累计花费约8.8亿美元进口电力。政府的目标是到2030年实现家庭全面通电——连居民用电都未解决，支撑工业化冶炼深加工的能源底座显然更加遥远。

### 4. 中非合作模式的静默重构

文章最富洞察力的部分在于揭示了中国角色的转向：

**旧模式**：中国企业在非洲投资矿山 → 矿石/精矿运回中国 → 国内加工 → 生产电池/产品。

**新模式**：中国资本、设备、技术直接落地非洲 → 当地完成更多加工环节 → 加工产品或成品进入中国（零关税）→ 连接中国新能源和制造业体系。

典型案例包括：
- **华友钴业**（全资控制津巴布韦锂业公司PLZ）：投资锂矿的同时建设加工设施，2026年4月首次出口高附加值产品硫酸锂，被称为“非洲创造历史”。
- **中航科创**承建的津巴布韦瑞德矿业光储柴微电网项目：11MW光伏+30MWh储能+4MW柴油备用，光储供电比例超85%，可脱离大电网独立运行，保障矿山24小时生产。这实际上是在用中国的方案直接“绕过”非洲基础设施的短板。
- 津巴布韦首座垃圾发电厂也将由中国企业建设。

配合2026年5月起中国对非洲53个建交国全面实施零关税（全球首个主要经济体的单边零关税待遇），新产业链的闭环正在打通：**中国的技术+非洲的资源 → 非洲加工 → 零关税进入中国市场**。


## 💡 启发与影响

### 对非洲/资源国的启示

| 维度 | 判断 |
|---|---|
| **短期收益** | 出口禁令可快速提升出口额（津巴布韦锂收入翻倍验证），但可持续性存疑 |
| **关键风险** | 缺乏电力、基建、技术工人和加工经验；贸然“锁矿”可能吓退中小投资者，推高融资成本 |
| **路径依赖** | 印尼成功的本质是“资源+中国资本+政府强制+长期耐心”，非洲若缺乏配套，可能只拿到“禁令”，拿不到“产业链” |
| **联盟博弈** | 非盟层面协调有助于增强集体议价能力，但各国资源禀赋、政治稳定性和利益诉求差异大，联合行动的执行力存疑 |

### 对中国企业和投资者的影响

- **“买矿运回来”的旧逻辑正在失效**：单纯获取资源的投资模式，在政策风险下面临被征收、被强制要求本地加工的挑战。未来在非洲矿业投资的核心竞争力不再是“拿到矿权”，而是**能否提供从采矿到加工、从微电网到物流的一体化解决方案**。
- **中国企业本身的优势恰好匹配非洲需求**：中国在光伏、储能、微电网、矿业装备和加工技术上均有成熟的供应链和工程能力。瑞德矿业项目表明，“自带电力系统”可以成为投资谈判中的关键筹码。
- **零关税窗口创造了新利润结构**：非洲加工产品以零关税进入中国市场，使“在非洲深加工”不再仅是政策合规，而可能成为具备经济合理性的商业选择（特别是考虑锂精矿长途海运成本后）。
- **需要警惕的风险**：政策反复性强（津巴布韦近期多次变更矿业政策）、地缘政治干扰（资源国可能在大国之间摇摆要价）、以及“锁矿”后的隐性成本（贿赂风险、合规复杂性上升）。

### 对全球关键矿产供应链的宏观影响

- 非洲占全球关键矿产储量30%，若更多国家效仿印尼，短期内可能推高锑、钨、锂、钴等小金属和锂电原料的全球价格。
- 全球供应链加速从“原矿全球流动”向“加工近源化”重构——冶炼和初级加工产能将被迫向资源国转移。
- 这一趋势强化了**中国作为技术输出者和终端市场**的战略地位：非洲需要中国产能来实现本地加工，而中国零关税则为非洲加工产品提供了最大单一市场。中非之间的经济互补性因此反而被“锁矿潮”进一步加深，而非削弱。


## 总结性判断

津巴布韦的禁令既是资源民族主义的声明，也是一场高风险的经济实验。非洲无法短期内复制印尼，但正在学习用“资源主权+强制本地化+联盟谈判”的新工具重塑与外部资本的关系。对于中国而言，旧的“拿矿就走”模式已走到尽头，但新窗口正在打开——以工程技术能力、能源配套能力和市场准入（零关税）为载体的深度嵌入模式，将是中国企业在非洲矿业下一阶段的核心竞争力。最终的赢家，不会是简单“占有资源”的一方，而是能帮助资源国“把石头变成产业”的一方。
