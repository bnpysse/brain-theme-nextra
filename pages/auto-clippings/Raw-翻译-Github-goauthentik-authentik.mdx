## 什么是authentik？

authentik 是一个开源的身份提供商(IdP)，适用于现代单点登录(SSO)。它支持 SAML、OAuth2/OIDC、LDAP、RADIUS 等协议，旨在从小规模实验室到大规模生产集群进行自我托管。

我们的 [企业版](https://goauthentik.io/pricing) 可供组织安全地替换现有的 IdP（如 Okta、Auth0、Entra ID 和 Ping Identity），以实现强大且可扩展的身份管理。

## 安装

- Docker Compose：推荐用于小型/测试环境。请参阅 [文档](https://docs.goauthentik.io/docs/install-config/install/docker-compose/)。
- Kubernetes (Helm Chart)：推荐用于大规模部署。请参阅 [文档](https://docs.goauthentik.io/docs/install-config/install/kubernetes/) 和 Helm chart 仓库[GitHub] (https://github.com/goauthentik/helm)。
- AWS CloudFormation：使用我们的官方模板在 AWS 上部署。请参阅 [文档](https://docs.goauthentik.io/docs/install-config/install/aws/)。
- DigitalOcean Marketplace：通过官方市场应用实现一键部署。请参阅[应用程序列表](https://marketplace.digitalocean.com/apps/authentik)。
