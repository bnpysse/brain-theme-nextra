# Gitea 28.0 版本发布精华简报

## 核心要点速览

1. **版本号革新**：Gitea 移除了历史遗留的"1."前缀，直接从28.0.0开始版本号体系

2. **安全增强**：包含未公开细节的安全修复（一周后公布），建议尽快升级

3. **架构支持调整**：不再提供32位x86、gogit构建和armhf架构的Snap包

## 关键新功能

- **安全管控**：

- 审计日志功能

- 管理员用户模拟能力

- HTTPS部署令牌支持

- **开发流程优化**：

- 代码所有者审批规则

- 差异文件过滤器

- Actions队列可视化

- **账户管理**：

- 新增机器人账户支持

- 默认关闭自助注册功能

## 重大变更警示

1. **网络代理架构**：

- Git网络操作(迁移/镜像)现通过内部代理执行

- 严格模式下仅允许80/443端口

- 域名匹配规则改为curl语法标准

2. **CI/CD清理策略**：

- Actions运行历史默认400天后自动清理

- 新增定时清理任务(默认午夜执行)

- 可配置保留期限(0=永久)

3. **系统依赖要求**：

- 最低Git版本要求提升至2.25+

- 启动时会进行版本校验

## 升级建议

1. **必须检查项**：

- 现有EGRESS网络规则配置

- Git版本兼容性

- 注册功能配置状态

2. **升级步骤**：

```

1. 阅读重大变更说明

2. 备份数据

3. 替换二进制/Docker容器

4. 重启服务

```

3. **注意事项**：

- 下载文件名格式变更(移除OS版本后缀)

- [server] DOMAIN配置项已废弃
