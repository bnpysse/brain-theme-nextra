# Muse Wonder 精华简报

## 一句话概括

Meta 发布新一代前沿模型 Muse Wonder 系列（Muse Wonder 与 Muse Wonder Full），主打个人与专业智能体任务，是迈向“个人超级智能”的关键一步。

## 核心亮点

- **定位**：目前 Meta 最强大的模型，在个人/专业智能体、记忆与编码基准上达到 SOTA（最先进水平）。

- **两大关键能力**：

- **Active Memory（主动记忆）**：跨对话携带重要上下文，并主动检索与当前任务相关的历史信息。

- **Active Focus（主动聚焦）**：面对复杂目标持续努力——尝试替代方案、克服阻碍、适应新信息，必要时主动澄清，并在重要操作前确认。

- **编码能力**：支持从小型应用到复杂软件项目的开发，覆盖需求追踪、跨代码库修改、测试与迭代全流程。

## 发布与可用性

- **Muse Wonder**：即日起通过 Meta Model API 和 Muse Code 提供。

- **Muse Wonder Full**：即日起向 Muse Code 订阅者开放。

- 后续将逐步接入 Muse 产品，优先服务订阅者，并用于工件生成及高智能流程；未来还将基于 Muse Wonder 开发专用模型，惠及所有 Muse 用户。

## 技术背景

- 14 个月前开始从第一性原理重建 AI 技术栈，本次发布是预训练与强化学习扩展的延续。

- 模型在 Meta 千兆瓦级 Prometheus 数据中心训练，整合了多个团队成果。

## 评估与能力泛化

- 评估覆盖法律、金融、健康等专业领域（如 Harvey 法律智能体基准 LAB），以及记忆、聚焦（FocusBench）、长时执行（SWE-Marathon）等专项测试。

- 文章特别指出：两个模型基准分相近时，实际泛化能力可能差异很大。Meta 通过对比“后训练目标任务”与“未目标任务”的表现，验证 Muse Wonder Full 在测试时计算扩展下，对陌生任务具备更强的泛化能力（即“大模型气质”，而非“刷分机器”）。

## 战略意义

- 这是 Meta 从“重建技术栈”到“推动前沿”的里程碑，目标是为数十亿用户带来个人超级智能。
