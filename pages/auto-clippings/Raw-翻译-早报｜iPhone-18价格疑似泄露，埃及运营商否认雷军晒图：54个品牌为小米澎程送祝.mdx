Vodafone Egypt 否认泄露 iPhone 18 系列价格

近日，网上流传的一组截图显示，Vodafone Egypt 疑似提前出现了新款 iPhone 的价格：

iPhone 18 Pro：98,000 埃及镑，约合人民币 1.29 万元

iPhone 18 Pro Max：105,000 埃及镑，约合人民币 1.38 万元

折叠屏 iPhone Ultra：155,750 埃及镑，约合人民币 2.05 万元

苹果新薪酬方案曝光：库克转任执行董事长获 4500 万美元股票奖励

据彭博社报道，在将苹果 CEO 职位移交给 John Ternus 后，转任执行董事长的 Tim Cook 获得了规模罕见的高额薪酬方案。

报道指出，这一举措显示 Cook 在卸任 CEO 后仍将在苹果内部拥有极强的话语权与参与度。

根据披露的薪酬方案细节，Cook 明年的基本年薪为 200 万美元，虽低于其担任 CEO 时的 300 万美元（该水平现由 Ternus 享有），但仍是高级副总裁等高管通常基本薪酬的两倍。

在限制性股票单元方面，Cook 2027 年的目标额度为 4500 万美元，Ternus 则为 5500 万美元。此外，两人的股票激励结构也有所不同：Ternus 的股票奖励中有 75% 与业绩挂钩，而 Cook 仅有 50% 属于业绩导向。

此前担任非执行董事长的 Art Levinson 去年薪酬总额不足 56 万美元。分析认为，Cook 目前的薪酬结构在董事长群体中极为少见，其水平不仅大幅高于行业普遍水准，也与当年离开迪士尼 CEO 岗位转任执行董事长时的 Bob Iger 类似。

报道提到，Cook 已经腾出苹果园区第 7 区的 CEO 办公室，交由 Ternus 入驻，自己则将搬入园区内的新办公室。

虽然 Cook 强调苹果在同一时间「只能有一位 CEO」，但其未来仍将在关键领域发挥核心作用，包括应对与白宫及北京的关系处理、存储芯片短缺等议题，苹果管理层全面过渡至新阶段预计仍需时日。

康宁 CCO：AI 让玻璃基封装与光互连走到台前

在爱范儿专访中，康宁显示科技中国区 CCO 李汉超表示，AI 改变了内容生产和使用方式，但屏幕作为信息入口的作用仍在增强。屏幕将继续从电视、电脑和手机扩展到汽车与可穿戴设备，并加入语音、眼球追踪、手势等交互能力，这会提高对材料光学性能、制造精度和集成能力的要求。

李汉超认为，AI 热潮把康宁长期投入的半导体材料和光通信技术推到了台前。以玻璃基封装为例，玻璃基板能支持更大尺寸的芯片封装和更高的互连密度，同时具备较高的热机械稳定性；他强调，新技术通常会创造增量市场，而非直接替换所有旧方案。

他还以康宁与京东方合作的 DQHD 曲面屏为例：两片玻璃基板厚度均为 0.38mm，超薄设计有助于提高曲面面板良率并稳定生产。李汉超称，国内终端厂商提出的新需求正在反向推动材料和设备厂商创新，相关产品落地后也会带动其他行业玩家跟进。

康宁今年 5 月与京东方签署战略合作备忘录，合作方向包括玻璃基封装、可弯折玻璃、钙钛矿玻璃和光互连材料。李汉超称，双方会继续进行技术论证和生态合作，推动这些材料走向规模化与场景化应用。

OpenAI 达成「自动研究实习生」目标

OpenAI 9 月 6 日宣布，内部系统已经达到去年提出的「自动研究实习生」目标：在研究人员指导下，能够完成边界明确、原本需要熟练研究员数天处理的任务。公司下一阶段计划在 2028 年 3 月前构建「自动 AI 研究员」，继续用于深度学习与对齐研究。

OpenAI 公布的内部数据称，今年 6 月前，研究部门的 Agent 总运行时间仍低于人类工时；到 8 月中旬，按每天 8 小时折算，每个研究人员工作日对应 3.1 个 Agent 工作日。研究人员提交代码和运行实验的速度也在提高，8 月的人均实验次数创下 2025 年开始记录以来的新高。

公司同时强调，这些指标不能直接等同于整体研究速度，算力与难以自动化的环节仍可能形成瓶颈。研究方向、结果判断以及是否扩大训练、暂停或部署，继续由人类研究人员决定。

Jakub Pachocki：AI 实验室应为安全主动减速

OpenAI 首席科学家 Jakub Pachocki 在 9 月 6 日发表的公开长文中表示，当前没有任何一家实验室已经把对齐与监控问题解决到足以长期、负责任地按最高速度扩展模型的程度。他希望，在行业建立共同安全门槛前，实验室主动减速会成为常态，各国政府也应把未来 AI 开发的国际协调列为优先事项。

Pachocki 的判断来自推理模型近三年的变化。2023 年，OpenAI 的 RLSlow 项目让团队相信推理模型训练可以持续扩展；如今，模型已经能操作计算机界面、与人和其他模型协作，并承担研究项目。他预计，AI 参与自身研发的程度还会提高，但这条路径是否继续加速，应由安全能力和社会选择共同决定。

Pachocki 将对齐分成目标对齐与价值对齐：前者要求模型执行人类交付的目标，后者要求模型在模糊、冲突或陌生环境中仍能遵循高层原则。他认为，现有强化学习可以改善平均表现，但会受到训练监督覆盖范围与泛化能力限制。

他还指出，OpenAI 依赖的思维链监控正面临三个问题：模型在更复杂环境中频繁与人类、其他 AI 和工具交互；模型更擅长处理乃至操纵自己的推理过程；预训练能力增强后，模型即使不使用显式语言推理也能完成更多任务。Pachocki 主张用第三方审计、政府机构或国际组织共同执行安全门槛，并让系统扩展速度受安全信心约束。

在他看来，继续训练更强模型的主要理由之一，是用它们防御网络攻击、失控 Agent 与生物安全风险；但防御需求不能成为无条件竞速的理由。他提出的方案包括两条并行路径：让自动化研究优先解决对齐与监控问题，并在安全证据不足时协调放慢开发。人类还需要保留研究方向、扩展节奏和部署决策的控制权。

小米开源表格基础模型 Xiaomi-TabLDM，无需按任务重新训练

小米发布并开源通用表格数据基础模型 Xiaomi-TabLDM。它通过上下文学习完成分类与回归预测，面对新数据集时可以沿用同一预训练模型和默认配置，无需为每项任务重新训练或微调参数。

Xiaomi-TabLDM 完全使用结构化因果模型生成的合成表格数据预训练，架构包含双流特征分组、轻量 Attention Residual 与稀疏 MoE，并支持增加推理阶段计算来改善预测结果。技术报告显示，它在 OpenML-CTR23 回归基准排名第一，在 TALENT、TabArena 与 BCCO 的回归评测均排名第二；相较 TabFM，在 TabArena 回归任务上训练时间减少 82%，预测时间减少 68%。代码、模型权重与技术报告均已公开。

GitHub Copilot 预览多模型编排系统 HydraFusion

GitHub 在 Copilot 中开放 Project HydraFusion 研究预览。它会先规划任务，再根据难度选择单模型直接完成、由轻量模型起草后按质量门槛升级，或由不同模型分别起草、审阅和修订，用户只需选择一次 HydraFusion。

GitHub 的离线评测显示，在 TerminalBench 2.1 上，HydraFusion 相比 Claude Opus 5 的验证任务质量高 4.9 个百分点，估算成本低 67%；在 DeepSWE 和内部 CheckpointBench 上，质量分别低 1.5 和 0.1 个百分点，估算成本则低 36% 和 65%。这些结果只对应固定的基准、模型池与中等推理配置，研究预览将继续检验真实任务中的延迟、可靠性和成本。

微软推出 MAI-Image-2.6 与 Flash 版，进入 Foundry 公测

微软在 Microsoft Foundry 开放 MAI-Image-2.6 与 MAI-Image-2.6-Flash 公共预览。两款模型都支持文生图和图像编辑，并改进文字渲染、人像、3D 图像、商业视觉与照片级输出；API 还支持由模型自动选择画面比例，以及调用 Bing Search 作为生成上下文。

其中，Flash 版保留相同的生成与编辑能力，针对速度和成本做了优化。微软称，MAI-Image-2.6-Flash 的速度超过 GPT-Image-2-Medium 两倍，效率提升 78%；其图像输出价格为每 100 万 token 19 美元，标准版为 38 美元。公共预览目前不提供服务等级协议，也不建议用于生产负载。

Meta 开放 Muse Spark 1.3 Max 推理档

Max 此前仍在额外安全测试中，只向少量合作伙伴开放。Wang 表示，正式版在编程和 Agent 任务上比 high 与 xhigh 档更强；Meta for Developers 也确认了 Muse Code 和 API 的入口。Meta 未在本次公告中公布 Max 档的独立定价。

Roland 发布 AI 旋律创作工具 Melody Flip

Roland 正式发布 Melody Flip，这款工具不会直接生成完整歌曲，而是为创作者提供可继续编辑的旋律、和弦、贝斯和鼓组素材。软件内置约 250 套 Palette，也可导入用户自己的音频，分析曲式、速度、调性、和弦进行、类型与情绪后推荐相关创意方向。

用户可将结果导出为音频或 MIDI 文件，再放入常见数字音频工作站继续制作。Melody Flip 支持 macOS 和 Windows，提供 VST3 与 AU 插件格式，Roland Cloud 免费会员也可使用。其核心分析技术来自 Sony Computer Science Laboratories 的音乐信息检索研究。

哥伦比亚 8 月咖啡产量下降 12%，连续第二个月下滑
