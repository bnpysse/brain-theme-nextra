### 核心总结
- MoonTV是一个基于Next.js 14 + Tailwind CSS + TypeScript构建的跨平台影视聚合播放器
- 主要功能包括多源聚合搜索、流畅在线播放、收藏同步、PWA支持、响应式布局和智能去广告
- 项目采用Docker部署，支持Kvrocks/Redis存储，提供一键部署方案
- 项目为空壳设计，需用户自行收集播放源和直播源
- 明确禁止在中国大陆主流社交平台宣传本项目
