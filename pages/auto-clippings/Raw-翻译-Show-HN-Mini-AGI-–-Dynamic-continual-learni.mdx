【文章标题】：Show HN: Mini-AGI – Dynamic continual learning model trained on 8GB VRAM  
【展示作品】：Mini-AGI——基于8GB显存的动态持续学习模型  

【文章正文】：  
mini-AGI - is a continual learning byte-level language model that assembles its own architecture, trains from scratch on a single 8 GB VRAM GPU, and keeps learning from everything it reads.  
mini-AGI 是一个持续学习的字节级语言模型，它能自主构建架构，在仅8GB显存的GPU上从零开始训练，并持续从阅读内容中学习。  

It stores its weights as ordinary files on disk and pages them onto the card as it needs them, so the parameter count is bounded by free disk space rather than by VRAM.  
模型权重以普通文件形式存储在磁盘中，按需加载到显存，因此参数量仅受磁盘空间限制而非显存容量制约。  

It grows new capacity while training when it runs short, prunes what nothing asks for, and reads through exactly the same code path it serves on.  
训练过程中遇到容量不足时会动态扩展，自动修剪无用部分，且始终通过相同的代码路径进行学习与推理。  

Targeted at a PC or laptop with at least an 8 GB VRAM GPU on the board.  
目标硬件为配备至少8GB显存GPU的PC或笔记本电脑。  

NOTE: as of now this is a small toy-level model. Do not expect a frontier level capabilities.  
注意：目前这仅是个玩具级小模型，暂不具备前沿能力。  

This is rather a small experiment to show, that continual learning from the single stream of data without catastrophic forgetting is possible.  
该项目旨在验证：从单一数据流持续学习且避免灾难性遗忘是可行的。  

Furthermore it is possible on a modest hardware. Which means that almost everyone could train their own version of the model (or simply continue training this one) exactly as they see it fit.  
更关键的是，普通硬件即可实现。这意味着几乎所有人都能按需训练个性化模型（或继续训练现有模型）。  

And the capabilities would be bounded by the actual hardware, scale and quality of the data available and the amount of time one willing to spend on training the model.  
模型能力上限取决于实际硬件配置、数据规模质量以及用户愿意投入的训练时长。

The weights are not published yet. The run is still reading its first pass over the corpus, the weights go up once it has been through all of it, which is a couple of weeks away at the current rate.  
权重暂未发布。模型正在首轮遍历语料库，完整遍历后权重将更新——按当前进度还需数周时间。  

Every language model you can actually own today is a model somebody else trained and then froze.  
当今所有可获取的语言模型本质都是他人训练后冻结的产物。  

You can fine-tune around the edges of it, but you cannot train one from scratch on your own hardware, and you cannot keep training it on what you do day to day - the moment you try, it forgets what it knew before.  
您只能进行边缘微调，无法在自有硬件上从零训练，也无法持续用日常数据训练——尝试瞬间便会遗忘既有知识。  

The result is that a personal model is always somebody else's model with a thin layer of you on top, and it stops learning the day it ships.  
最终所谓个性化模型，不过是他人模型覆盖着您的薄层数据，且从发布日起便停止学习。  

mini-AGI model has small enough GPU footprint that it is possible to train end-to-end on one consumer card, and it is built so that training never has to stop.  
mini-AGI的GPU占用极低，可在消费级显卡上完成端到端训练，且设计为永续学习架构。  

It reads a stream of characters one chunk at a time, takes a gradient step on each, and the same path serves generation.  
它以字符流形式逐块读取数据，对每个块执行梯度步进，生成过程复用相同路径。  

There is no separate fine-tuning regime and no frozen base: reading and being trained are the same event.  
不存在独立的微调阶段或冻结基座：阅读与训练是同一过程。  

Three constraints shape everything else in the design:  
三大核心约束塑造了整个设计：  

- It has to fit on 8 GB. Not with quantisation - training needs gradients and optimiser state, which is roughly three times the weights again. So the weights live on disk and only the working set is resident.  
- 必须适配8GB显存。不依赖量化——训练需保留梯度和优化器状态（约3倍权重体积）。因此权重常驻磁盘，仅工作集留存显存。  

- It has to not forget. A model that learns continually and overwrites itself is worse than one that does not learn at all.  
- 必须避免遗忘。持续学习却自我覆盖的模型比完全不学习的更糟糕。  

- It has to be able to read anything. The alphabet is the 256 byte values, so there is no tokenizer to fit and no data type that needs a new vocabulary.  
- 必须能读取任意内容。字母表涵盖256字节值，无需适配分词器或扩展词汇表。  

The model is genuinely yours: trained on your hardware, on your data, that keeps learning from every conversation you have with it, and that nobody else can take it away or switch it off.  
这是真正属于您的模型：用您的硬件和数据训练，持续从每次对话中学习，且他人无法剥夺或关闭。  

Characters (bytes) does not pass through a fixed stack of layers as it would be in a traditional LLM. Instead, it passes through two dense prelude blocks and then through one recurrent block applied up to 24 times, each application choosing its own experts from a shared pool.  
字符（字节）不像传统LLM那样通过固定层堆栈，而是经过两个稠密前导块后，循环通过某个块最多24次——每次从共享池自选专家组合。  

The latent state between applications is never decoded - it is merged with the embedded input by an adapter each time round, so the loop cannot drift away from the text it is reading.  
各次应用间的潜态永不解码，而是通过适配器与嵌入输入逐轮合并，确保循环不偏离当前阅读文本。  

Three distinct blocks, up to 26 block-applications per character.  
三个独特模块，每个字符最多经历26次模块应用。  

- Adaptive depth. A halting head scores every character at every row, and the character stops as soon as another row would not change the answer. Easy characters take one row, hard ones take many. This is the PonderNet recipe: while training, every depth is computed and weighted by its halting probability, so the halting head learns through those weights.  
- 自适应深度。停止头对每行字符评分，当新增行不再改变结果时停止处理。简单字符仅需1行，复杂字符需多行。采用PonderNet机制：训练时计算各深度加权停止概率，使停止头通过权重学习。  

- Routing per block-application, not per character. Each of the 26 applications picks its own top-8 experts, so one character touches far more of the pool than "top-8" suggests, and the same expert can be selected several times at different depths. What varies is which eight at each point.  
- 按模块应用而非字符路由。26次应用中每次自选Top-8专家，因此单个字符接触的专家远超"Top-8"表面数量，且同一专家可在不同深度被多次选用。变化的是每步的八专家组合。  

- No expert is assigned a subject. There are no labels anywhere. Soft top-k routing distributes capability across the pool by itself, and a character can combine fragments from several experts. The cost is that capabilities share parameters and so can interfere.  
- 专家不绑定特定主题。全程无标签。软性Top-k路由自主分配能力，单个字符可整合多专家片段。代价是能力共享参数可能相互干扰。

这是从实时模型中捕捉的架构自组装过程——逐字符构建，无人工绘制痕迹。
