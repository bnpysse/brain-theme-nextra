### 核心总结
- **多语言代码知识图谱构建**：利用 Tree-sitter 解析多语言代码库，在 Memgraph 中构建统一的代码结构知识图谱，全面支持 Python、Go、Java 等十余种主流编程语言。
- **自然语言驱动的代码交互**：结合 RAG 架构，将用户的自然语言转化为 Cypher 查询，实现对代码库的精准检索、AST 级别代码编辑、死代码查找及数据流追踪。
- **AI 生态集成与高级特性**：支持作为 MCP Server 与 Claude Code 等 AI 客户端无缝集成，并提供基于 ast-grep 的结构化搜索替换、数据流污点分析等高级工程特性。
