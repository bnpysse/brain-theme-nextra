Terminal email clients for every system

适用于各系统的终端邮件客户端

Read and send email from a terminal on Linux, macOS, Windows, BSD and Android. 19 maintained clients and 7 mail tools, each with install commands for every system and a config that works with Forward Email or any other provider.

在Linux、macOS、Windows、BSD和Android终端中收发邮件。19个维护中的客户端和7个邮件工具，每个都包含各系统的安装命令，以及适配Forward Email或其他邮件服务商的配置。

The screenshots show Forward Email's terminal app, made by the team behind this site. It is the only client here with its own calendar, contact list and task list, alongside mail.

截图展示的是本站团队开发的Forward Email终端应用。这是唯一集成日历、联系人列表、任务列表和邮件功能的客户端。

forwardemail

forwardemail（特色客户端）

Featured

特色功能

The forwardemail command runs the same application as Forward Email's webmail inside a terminal, drawn as text. Mail, calendar, contacts, tasks and settings all work, with keyboard shortcuts, mouse clicks and scrolling, and plain-text reading and writing by default. It installs as one standalone executable on Linux, macOS and Windows, or from npm anywhere Node.js 22 runs. It signs in to Forward Email accounts, including self-hosted servers.

forwardemail命令可在终端内运行与网页版相同的应用，以文本形式呈现。邮件、日历、联系人、任务和设置功能俱全，默认支持键盘快捷键、鼠标点击滚动、纯文本读写。在Linux/macOS/Windows上可安装独立执行文件，或通过npm在Node.js 22+环境运行。支持登录Forward Email账户（含自建服务器）。

- Calendar, contacts and tasks in the same terminal app as mail

- 邮件客户端内集成日历/联系人/任务功能

- Mouse clicks, scrolling and text selection work, and the bottom row always shows the keys for the current screen

- 支持鼠标点击/滚动/文本选择，底部常驻当前界面快捷键提示

- One self-updating executable with no setup files to write

- 单一自更新执行文件，无需配置文件

- Works with self-hosted Forward Email through --api

- 通过--api参数支持自建Forward Email服务

A Forward Email account with a mailbox (paid plans start at $3 a month). forwardemail --demo opens a demo account with no sign-in.

需拥有Forward Email邮箱账户（付费方案$3/月起）。forwardemail --demo可免登录开启演示账户。

Install

安装指南

Linux

Linux系统

curl -fsSL https://github.com/forwardemail/mail.forwardemail.net/releases/latest/download/install.sh | shnpm install -g forwardemail

Standalone builds for x64 and arm64 need glibc. On musl systems such as Alpine Linux, install with npm.

x64/arm64独立构建版需glibc支持。Alpine Linux等musl系统请通过npm安装。

macOS

macOS系统

curl -fsSL https://github.com/forwardemail/mail.forwardemail.net/releases/latest/download/install.sh | shnpm install -g forwardemail

Standalone builds for Apple Silicon and Intel.

支持Apple Silicon和Intel芯片的独立构建版。

Windows

Windows系统

irm https://github.com/forwardemail/mail.forwardemail.net/releases/latest/download/install.ps1 | iexnpm install -g forwardemail

Signed standalone builds for x64 and arm64. Windows Terminal is recommended over the legacy console.

已签名的x64/arm64独立构建版。推荐使用Windows Terminal替代传统控制台。

BSD

BSD系统

npm install -g forwardemail

Through npm, which runs anywhere Node.js 22 or later does.

通过npm安装（需Node.js 22+环境）。

Android

安卓系统

pkg install nodejs && npm install -g forwardemail

Through npm in Termux, which packages Node.js 24 and later. Not tested by the project.

通过Termux中的npm安装（含Node.js 24+）。未经项目组测试。
