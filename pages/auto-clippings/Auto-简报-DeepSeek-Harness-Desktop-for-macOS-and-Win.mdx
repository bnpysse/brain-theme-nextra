# DeepSeek Harness桌面端技术简报

## TL;DR

DeepSeek推出基于"万物皆插件"架构的开源工作台Harness，支持macOS/Windows双平台，通过模块化插件系统实现文档处理、编程开发、研究分析等全场景智能辅助，其"创造者模式"和定时任务功能展现了AI代理工作流的突破性设计。

## 核心洞察

### 技术突破

1. **Cordis插件架构**：采用"everything is a plugin"设计理念，所有功能（包括UI组件）均可通过插件动态扩展

2. **混合执行模式**：支持桌面应用/Web UI双形态，bash脚本执行与文件操作深度集成（如直接读取.md/.ts等工程文件）

3. **自演进系统**：通过"Creator mode"实现自然语言创建插件（如演示的番茄钟计时器），SKILL.md机制实现技能传承

4. **可观测性**：提供完整的执行轨迹记录（Turn/Calls/Duration），支持工具调用链路的调试

### 商业创新

1. **场景化AI代理**：突破传统聊天交互，实现"描述即创建"的工作流（如自动生成周报定时任务）

2. **开发者生态构建**：开源策略+插件市场形成双轮驱动，time_zone等细节体现全球化设计

3. **企业级特性**：workspace policy管理、环境快照等设计暗示未来团队协作方向

## 行业影响

1. **重新定义生产力工具**：将RPA+IDE+办公套件能力融合为统一AI工作台，可能冲击Zapier/Jenkins等自动化工具市场

2. **插件经济新范式**：自然语言编程创建插件可能催生新型开发者群体（如提示词工程师转型插件设计师）

3. **中国AI全球化样本**：亚洲时区优先支持+中英无缝切换，展现中国团队出海的技术自信

4. **开源战略深意**：通过可组合基础设施降低AI应用门槛，可能加速企业私有化部署进程

&gt; 特别关注：`shell.overlay`技术暗示未来可能实现OS级AI集成，或成为挑战Microsoft Copilot的差异化武器
