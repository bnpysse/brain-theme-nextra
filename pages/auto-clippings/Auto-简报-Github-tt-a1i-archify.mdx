### 核心总结
- **产品定位**：Archify 是一款适用于 Cursor、Claude Code 等主流 AI 编程工具的智能体（Agent）技能，能将代码库或系统描述直接转化为精美、可交互的系统架构图。
- **核心功能**：支持多类型图表与主题展示；提供精确的架构变更对比审查（变更前/差异/变更后）；支持基于真实代码的节点搜索与路由追踪，确保拓扑结构真实可靠、不凭空捏造。
- **输出与分享**：通过确定性检查生成独立的 HTML 文件及多种格式（PNG、SVG、WebM 等）的分享卡片，实现单文件的便捷信任、演示与分享。
