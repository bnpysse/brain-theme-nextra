经常上少数派的用户都知道，我们网站的用户头像其实是支持 GIF 格式的，确保头像文件在 5 MB 以内即可。Windows 不像我们网站这么先进，直接在 Windows 设置或微软账户管理页面上传 GIF 动图，只会得到一个包含其中一帧画面的静态头像——枯燥、死板，和你每次打开 Windows 上班干活时的心情格格不入。
事实上 Windows 是支持设置 GIF 格式文件为用户头像的。
（进行后续的操作前，请先注意备份。）
在注册表的 计算机\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\AccountPicture\Users\ 路径下，存储着各种尺寸、用于 Windows 各种界面的头像注册表值。
如果我们按照传统方法运行 regedit、找到键值、编辑保存，就会发现这些数值无法直接修改：
要修改用户头像相关的注册表数值，我们必须以 system 身份来运行注册表，这里我们选择 Windows 知识库中提到的 PsExec 工具，下载并解压得到 PsTools 文件夹，然后在开始菜单上右键，选择「系统」，然后在打开的设置界面中找到并进入「高级系统设置」。
然后在「环境变量」设置中参考下图操作流程，将 PsTools 路径添加至环境变量。
随后我们以管理员身份启动终端或 PowerShell，运行命令：
psexec -i -s regedit.exe
如果你好学看过上面的文档，应该就知道这里的 -i 代表启动可交互界面，-s 则是我们需要的以 system 身份启动。
启动后注册表编辑器页面弹出，我们就可以前往 计算机\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\AccountPicture\Users\ 路径，将所有头像的键值更改为事先准备好的 GIF 动图路径了。
