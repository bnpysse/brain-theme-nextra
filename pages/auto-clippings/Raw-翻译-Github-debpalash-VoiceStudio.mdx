## 概览

| | VoiceStudio |
|---|---|
| **工作流** | 语音克隆与设计、视频配音、听写、故事创作、有声书、批量生成 |
| **语言支持** | 646种TTS语言；实际覆盖范围和质量取决于所选引擎 |
| **引擎** | 16种TTS · 11种ASR · 可通过模型目录或&lt;kbd&gt;Ctrl&lt;/kbd&gt;/&lt;kbd&gt;Cmd&lt;/kbd&gt;+&lt;kbd&gt;E&lt;/kbd&gt;切换 |
| **平台** | Apple Silicon芯片的macOS 13.3+ · Windows 10/11 x64 · 支持glibc 2.39+的Linux x86_64 |
| **计算** | CUDA · Apple Silicon MPS/MLX · Linux ROCm · CPU · 可选远程工作节点 |
| **接口** | 桌面应用 · 本地REST/SSE/WebSocket API · OpenAI兼容音频API · MCP服务器 |
| **存储** | 默认将语音、项目、设置和输出保存在本地设备 |
| **许可** | AGPL-3.0应用程序；下载的模型遵循其上游许可条款 |
