# 技能
技能是一系列指令、脚本和资源的文件夹，Claude 可以动态加载这些内容来提高其在特定任务上的表现。技能教会 Claude 如何以可重复的方式完成具体任务，不论是创建符合公司品牌指南的文档、使用组织特有的工作流分析数据，还是自动化个人任务。

# 本仓库简介

本仓库包含展示了 Claude 技能系统可能性的技能。这些技能涵盖了从创意应用（艺术、音乐、设计）到技术任务（测试 web 应用、MCP 服务器生成）再到企业工作流（沟通、品牌等）等多种类型。

每个技能都独立存储在一个文件夹中，`SKILL.md` 文件包含了 Claude 使用的指令和元数据。浏览这些技能可以为您的自定义技能提供灵感或了解不同的模式和方法。

本仓库中的许多技能是开源的 (Apache 2.0)，我们还将支持 Claude 文档功能（[https://www.anthropic.com/news/create-files](https://www.anthropic.com/news/create-files)）的文档创建与编辑技能放在了 `skills/docx`、`skills/pdf`、`skills/pptx` 和 `skills/xlsx` 子文件夹下。这些是源代码可用但不开源的内容，但我们希望将其分享给开发者作为复杂技能的参考，这些技能正在实际生产 AI 应用中被积极使用。

## 免责声明

**本仓库中的技能仅用于演示和教育目的。** 尽管 Claude 可能提供某些功能，但从这些技能获得的行为和实现方式可能与您从 Claude 获取的结果不同。这些技能旨在说明模式和可能性。在依赖它们完成关键任务之前，请务必在自己的环境中彻底测试。

## 尝试在 Claude Code、Claude.ai 和 API 中使用

### Claude Code
您可以通过在 Claude Code 中运行以下命令将此仓库注册为 Claude Code 插件市场：
```
/plugin marketplace add anthropics/skills
```

然后，要安装特定的技能集，请按照如下步骤操作：
1. 选择 `浏览和安装插件`
2. 选择 `anthropic-agent-skills`
3. 选择 `document-skills` 或 `example-skills`
4. 选择 `立即安装`

或者直接通过以下命令安装插件：
```
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills
```

安装插件后，可以通过提及技能名称来使用它。例如，如果您从市场中安装了 `document-skills` 插件，可以要求 Claude Code 做如下的事情：“使用 PDF 技能提取 `path/to/some-file.pdf` 中的表单字段”

### Claude.ai

本仓库中的所有示例技能已经可供 Claude.ai 的付费计划用户使用。

# 创建基本技能

创建技能非常简单——只需一个包含 YAML 前置标记和指令的 `SKILL.md` 文件。您可以使用本仓库中的 **template-skill** 作为起点：

```markdown
---
name: my-skill-name
description: A clear description of what this skill does and when to use it
---

# My Skill Name

[在此处添加 Claude 在此技能激活时将遵循的指令]

## 示例
- 示例用法1
- 示例用法2

## 指南
- 指南1
- 指南2
```

前置标记只需要两个字段：
- `name` - 用于唯一标识您的技能（小写，空格用连字符替换）
- `description` - 对于技能所做的工作以及何时使用它的完整描述

下面的 markdown 内容包含了 Claude 将遵循的指令、示例和指南。更多详情请参阅 [如何创建自定义技能](https://support.claude.com/en/articles/12512198-creating-custom-skills)。
