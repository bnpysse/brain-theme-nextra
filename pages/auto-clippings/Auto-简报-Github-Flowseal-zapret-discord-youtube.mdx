### 核心总结
- 该项目基于 zapret 工具，用于加速 Discord 和 YouTube 访问，并提供 Windows 下的批处理脚本。
- 使用前需启用安全 DNS（Chrome/Firefox/Windows 11 或路由器设置），并注意 WinDivert 可能被部分杀毒软件误报为风险工具。
- 作者声明仅在本 GitHub 页面发布内容，其他平台同名账号均为假冒；所有二进制文件来自官方 zapret 仓库，可校验哈希。
- 使用方法为下载最新 release 压缩包、解锁文件、解压至无西里尔字符路径，然后运行相应 .bat 脚本。
