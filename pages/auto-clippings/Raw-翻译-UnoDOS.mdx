【文章标题】：UnoDOS

【文章正文】：
One source tree, one design, twenty-two machines, from an IBM PC/XT with an 8088 to the modern laptop on your desk.
同一套源代码，同一种设计理念，适配从搭载8088处理器的IBM PC/XT到现代笔记本电脑等22种设备。

UnoDOS is a family of graphical operating systems. It began as a GUI-first, 16-bit real-mode OS written entirely in x86 assembly, fitting a kernel, a window manager, two filesystems, cooperative multitasking and a full application set on a single 1.44 MB floppy. It has since grown into a contract-driven family of ports spanning home computers, consoles, handhelds, single-board computers and a phone, and its flagship is now pc64: UnoDOS running bare-metal on any modern 64-bit PC, on its own drivers, with its own network stack, browser, office suite, compiler and hypervisor.
UnoDOS是一个图形操作系统家族。最初它是完全用x86汇编编写的GUI优先16位实模式系统，将内核、窗口管理器、两种文件系统、协作式多任务处理和完整应用套装全部塞进一张1.44MB软盘。如今已发展成涵盖家用电脑、游戏主机、掌机、单板计算机和手机的契约式移植家族，其旗舰版本pc64可在任何现代64位PC上裸机运行，自带驱动、网络协议栈、浏览器、办公套件、编译器和虚拟机监控程序。

Prebuilt images for every platform are on the releases page: a hybrid ISO and USB disk image for modern PCs, cartridge ROMs for the consoles and handhelds, disk images for the home computers, and SD-card payloads for the boards. Most of them run in an emulator within a minute; the user manual walks through booting real hardware, including one-click USB flasher apps for Windows and macOS.
所有平台的预构建镜像均发布在下载页面：现代PC用的混合ISO/USB镜像、游戏主机和掌机用的卡带ROM、家用电脑用的磁盘镜像、单板计算机用的SD卡镜像。多数镜像能在模拟器中一分钟内启动；用户手册详细指导如何在真机上启动，包括Windows和macOS的一键刷机工具。

What has actually been verified is a separate question from what builds, and PLATFORMS.md is the ledger that answers it: per platform, what has booted on real hardware (and on which physical machine), what is emulator-verified only, and every known gap.
实际验证情况与构建成功与否是两个问题，PLATFORMS.md就是解答这个问题的台账：按平台记录哪些已在真机（及具体设备型号）上启动成功、哪些仅通过模拟器验证，以及所有已知缺陷。

pc64 boots bare-metal on essentially any x86-64 PC made since ~2007.
pc64版本基本能在2007年后生产的任何x86-64 PC上裸机启动。

UEFI plays the role the BIOS plays for the classic OS: the firmware hands over a framebuffer, a keyboard and the boot volume, and then, on most machines, UnoDOS calls ExitBootServices and the firmware leaves. From that point the OS runs entirely on its own drivers. A hybrid disk image boots the same OS on legacy-BIOS machines too.
UEFI扮演着传统BIOS的角色：固件移交帧缓冲区、键盘和启动卷后，在多数设备上UnoDOS会调用ExitBootServices让固件退出。此后系统完全运行在自有驱动上。混合磁盘镜像也能在传统BIOS机器上启动同一系统。

The shell is built on unoui, the family's cross-platform widget toolkit: a windowed desktop with a taskbar, virtual desktops, window snapping, an animated Alt-Tab switcher, desktop icons and a programs menu. Ten themes are live-switchable, from Aurora (the modern flat default, in light and dark) to faithful retro looks (Mac OS 7, 1-bit Mac Plus, Windows 3.1, Amiga Workbench, C64, Apple II, NeXTSTEP). Text is kerned, anti-aliased TrueType with bundled open fonts, and every control is reachable by pointer or keyboard.
外壳基于跨平台组件工具包unoui构建：带任务栏的窗口化桌面支持虚拟桌面、窗口吸附、动态Alt-Tab切换器、桌面图标和程序菜单。十种主题可实时切换，从极简现代的Aurora（含浅/深色模式）到忠实复刻的经典外观（Mac OS 7、1位色Mac Plus、Windows 3.1、Amiga Workbench、C64、Apple II、NeXTSTEP）。文字采用字距调整和抗锯齿的TrueType字体（含开源字体包），所有控件均可通过指针或键盘访问。

- UnoWord, UnoCalc, UnoShow: an Office 97-class suite that reads and writes the real Microsoft binary formats (.doc ,.xls ,.ppt ) through the in-tree unodoc library.
- UnoWord、UnoCalc、UnoShow：通过内置unodoc库读写真实Microsoft二进制格式（.doc/.xls/.ppt）的Office 97级套件

- Browser: HTML, Markdown and CSS rendering with cookies, cache, find and save, HTTP and CA-validated TLS 1.2 HTTPS, and two switchable JavaScript engines: the in-tree unojs bytecode VM and vendored quickjs-ng, with a libcss-based layout engine option behind the same seam.
- 浏览器：支持HTML/Markdown/CSS渲染，含cookie、缓存、查找保存功能，支持HTTP和CA验证的TLS 1.2 HTTPS，配备两种可切换JavaScript引擎（内置unojs字节码虚拟机与第三方quickjs-ng），同一接口下可选基于libcss的排版引擎

- Studio: an IDE that runs on the OS itself, with syntax highlighting, a build-and-run loop, an AI assistant, and UnoC, a built-in C compiler that compiles native UnoDOS apps on UnoDOS.
- Studio：原生IDE，含语法高亮、构建运行循环、AI助手，以及能在UnoDOS上编译原生应用的UnoC编译器

- Python: MicroPython as a first-class runtime (PYRT.UNO ) with auno API into the shell, filesystem and network.
- Python：MicroPython作为一等运行时（PYRT.UNO），通过auno API接入外壳、文件系统和网络

- Music, UnoAmp, Photos: from-scratch WAV, MIDI, MP3 and AAC-LC decoders (unomedia); UnoAmp is a Winamp 2 clone that loads classic skins; Photos views the common image formats.
- Music、UnoAmp、Photos：自研WAV/MIDI/MP3/AAC-LC解码器（unomedia）；UnoAmp是支持经典皮肤的Winamp 2复刻版；Photos可查看常见图片格式

- SSH: a native SSH client (ed25519, in-tree crypto).
- SSH：原生SSH客户端（ed25519，内置加密库）

- Plus Files, Editor, Paint, Tracker, Clock, Control Panel, System, a log viewer, the games (Dostris, Pac-Man, OutLast) and Runner3D, the showcase for the uno3d 3D library.
- 另含文件管理器、编辑器、画图、追踪器、时钟、控制面板、系统工具、日志查看器、游戏（Dostris、吃豆人、OutLast）以及展示uno3d库的Runner3D

Apps are loadable .UNO modules carrying their own descriptors: drop one into APPS\ and the shell discovers it. No rebuild, no reboot.
应用是可加载的.UNO模块（自带描述符），只需放入APPS\目录即可被外壳识别，无需重编译或重启。

Everything below the firmware line is native, written for this tree:
固件层以下的所有组件均为本系统原生开发：

- Storage: AHCI, NVMe, SDHCI/eMMC and USB mass storage under a common block layer, a native FAT16/FAT32 driver, GPT/ESP authoring.
- 存储：通用块层下的AHCI/NVMe/SDHCI/eMMC/USB大容量存储设备支持，原生FAT16/FAT32驱动，GPT/ESP创建工具

- USB: a polled xHCI host stack with hubs, HID keyboards and mice, mass storage, and USB Ethernet (ASIX AX88179, Realtek RTL8152).
- USB：轮询式xHCI主机栈，支持集线器、HID键鼠、大容量存储和USB以太网（ASIX AX88179、Realtek RTL8152）

- Networking: wired NICs (Intel e1000/e1000e/igb, Realtek r8169) and Wi-Fi (Intel, Realtek, Marvell drivers) with WPA2, over a from-scratch TCP/IP stack: ARP, IPv4, ICMP, UDP, TCP, DHCP, DNS, TLS (BearSSL), sockets and syslog in both directions.
- 网络：有线网卡（Intel e1000/e1000e/igb、Realtek r8169）和WPA2 Wi-Fi（Intel/Realtek/Marvell驱动），基于自研TCP/IP协议栈（ARP/IPv4/ICMP/UDP/TCP/DHCP/DNS），双向TLS（BearSSL）、套接字和syslog支持

- Input: PS/2, I2C-HID (native laptop trackpads) and USB HID.
- 输入：PS/2、I2C-HID（原生笔记本触控板）和USB HID

- Audio: Intel HDA with AC'97 fallback into a 48 kHz DMA ring.
- 音频：Intel HDA（AC'97回退），48kHz DMA环形缓冲区

- ACPI: an in-tree AML interpreter (unoacpi).
- ACPI：内置AML解释器（unoacpi）

unovirt enters VMX operation on Intel hardware and runs guests behind EPT with virtio devices: a real Ubuntu kernel boots under UnoDOS, reaches userspace, answers at its shell, and mounts an ext4 disk served from a file on a UnoDOS volume. The Appliances app and VM manager front it; an AMD/SVM backend is written and awaiting hardware proof.
unovirt在Intel硬件上进入VMX模式，通过EPT和virtio设备运行客户机：真实的Ubuntu内核能在UnoDOS下启动至用户空间，响应shell命令，并挂载来自UnoDOS卷文件的ext4磁盘。Appliances应用和虚拟机管理器提供前端界面；AMD/SVM后端已开发完成，待硬件验证。

- Installer: non-destructive install onto an existing disk's ESP, or a whole-disk clone; a running machine can also be reinstalled over the network.
- 安装程序：无损安装至现有磁盘ESP分区或整盘克隆；运行中的机器还可通过网络重装

- unosecure: local accounts, RBAC and an audit trail.
- unosecure：本地账户、基于角色的访问控制和审计追踪

- URC：远程控制通道（故障关闭式指令门，一次性控制台激活），支持无头操作真实设备：部署构建、运行...
