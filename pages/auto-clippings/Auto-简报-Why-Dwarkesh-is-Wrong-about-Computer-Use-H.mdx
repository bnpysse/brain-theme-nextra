### **精华简报：OpenAI 的技术突破与计算机应用的未来**

**来源**：Latent Space（AI 工程师社区深度分析）

**文章标题**：[Why Dwarkesh is Wrong about Computer Use + How OpenAI shipped its Jev competitor in 1 Week](https://www.latent.space/p/devday-2026)

---

#### **核心观点**

1. **计算机应用的范式转变**

- OpenAI 的 Ari Weinstein 指出，计算机应用（Computer Use）在过去几个月发生了 **“180度转变”**，主要得益于智能体（Agents）技术的突破。

- 现代智能体能够 **自主调试、故障恢复**，并整合 **截图、无障碍数据、DOM、Playwright 和生成代码**，显著提升任务执行速度。

- 未来目标是让智能体达到 **“超人类”** 的软件使用水平。

2. **OpenAI 的极速开发能力**

- OpenAI 在一周内推出了 **Jev 的竞品**（Decisions API），展示了其快速迭代能力。

- 技术栈包括：

- **异步工具调用**（模型无需停止推理等待工具响应）

- **转向中调控**（Mid-turn steering）和 **WebSockets**（实现高响应智能体）

- **超快速推理**（UltraFast inference）和 **决策API**（低延迟结构化输出）

- **提示缓存**、**预热**和 **压缩**优化长时运行线程。

3. **智能体的革命性进步**

- 每个智能体可拥有 **专属 Linux 计算机**，实现更高自主性。

- 智能体已能 **比人类更快完成某些任务**，并逐步实现从 **人类水平到超人类水平** 的跨越。

- **应用快照（App Shots）** 提供比普通截图更丰富的上下文，帮助模型更好地理解界面。

4. **OpenAI 的战略方向**

- 从 **原始模型 API** 向 **高阶抽象（如 Agents API）** 演进，目标是成为 **“AI 云”**。

- Decisions API 不仅用于外部开发，还优化了 OpenAI 内部的 **分类和工作流**。

---

#### **关键洞见**

- **计算机应用的未来**：智能体将深度融合开发、测试和运维，形成 **闭环自动化**。

- **OpenAI 的竞争优势**：快速工程能力（如一周内推出竞品）和 **基础设施优化**（如低延迟推理）。

- **开发者机遇**：利用 **Agents API** 和 **Decisions API** 构建更强大的自动化应用，但需权衡 **自主开发框架 vs 依赖 OpenAI 高阶抽象**。

---

#### **行动建议**

- **关注 Agents API**：探索如何将智能体集成到现有工作流，尤其是在 **自动化测试、实时交互和故障恢复** 场景。

- **优化延迟问题**：利用 **UltraFast 推理** 和 **提示缓存** 提升应用响应速度。

- **安全与权限管理**：当智能体能 **支付和操作网站** 时，需设计严格的信任与安全机制。
