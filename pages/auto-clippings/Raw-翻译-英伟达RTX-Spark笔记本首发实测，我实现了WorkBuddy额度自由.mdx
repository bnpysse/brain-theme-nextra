【文章标题】：英伟达RTX Spark笔记本首发实测，我实现了WorkBuddy额度自由

【文章正文】：

刚刚，首批搭载英伟达 RTX Spark 超级芯片的 Windows 笔记本电脑开售了。

APPSO 也提前拿到华硕 ProArt 创16 RTX Spark，这款笔记本 16 寸的 64GB 统一内存版本价格为 28999 人民币，128GB 统一内存版本则是 37999 人民币。

这是英伟达第一次以这样的方式进入 Windows PC 的核心硬件平台。以前的 Windows 电脑，大多数是使用 Intel 或者 AMD 的处理器，英伟达只是向电脑厂商提供显卡。

现在，

英伟达开始把自己的 ARM CPU、Blackwell RTX GPU 和统一内存结合起来，推出一套能够运行 Windows 的完整计算平台

。

在体验了一段时间后 APPSO 给大家挖出了更多细节，作为 AI PC 跟 Mac 对比如何，是不是可以当「理财产品」来等着它增值……

把大模型装进一台最薄 12.9 mm 的电脑

我们拿到的是 64GB 统一内存版本，由于是统一内存的形式，实际可用的 GPU 显存大约在 46.7 GB 左右，LPDDR5X 的内存类型，让它的内存带宽速度峰值理论在 300GB/s，但这也能让它运行像 Qwen 3.8 270 亿参数这样的模型。

另一方面，过去的 Windows ARM 架构的笔记本电脑，主要想回答的是「能不能像 MacBook Air 一样轻薄、省电、续航长」。

而 RTX Spark 的 ARM64 架构则让这台电脑能获得类似 Apple Silicon Mac 的高能效和统一内存优势，

又保留了 Windows 的应用生态和 NVIDIA 的 CUDA 能力

。

图｜华硕 ProArt 创16 H7607BA，处理器为英伟达 RTX Spark N1X

在续航上，这台华硕 ProArt 创16 RTX Spark 的电池是 99.9Wh，我们找了一个本地 270 亿参数模型持续生成文本和推理，拔掉电源，能看到电池的放电功率大约在 86.5W 左右，而剩余的电量几乎是在 2 分钟的时间里，就从 98.5Wh 掉到了 96.1Wh。

图｜十分钟左右的时间，跑一个 27B 的本地推理大模型，电量从 100% 掉到 85%；DischargeRate 通常以毫瓦（mW）表示，88493 表示大约 88.4W 的电池放电功率。 88108 表示电池剩余大约 88Wh 的能量。

图｜显卡功率大约是 30W，位于 P4，根据英伟达 RTX Spark 技术文档，P0 为最高性能，P4 平衡性能与功耗，P8 则是更侧重省电。插上充电器之后，显卡性能会更新为 P0。

假设整机平均功耗是 80W，99.9Wh 理论续航也能达到约 1 小时 15 分钟。也就是说，如果你正在持续运行一个 27B 或更大的模型，能够在不插电的情况下坚持约一个小时。

对于一台能在本地运行大型 AI 模型的笔记本，一台最薄 12.9mm

，

重约 1.77kg

的笔记本

，这意味着即使离开电源，它还能继续承担一段时间的高负载计算任务。

图｜GPU 利用率达到了将近 100%

续航之外，这台华硕 ProArt 创16 RTX Spark 笔记本电脑配备了丰富的外部接口，3 个 USB4 Type-C，每个最高 40Gbps，支持视频输出和 USB PD 供电。

1 个 USB-A 接口，使用 USB 3.2 Gen 2，最高 10Gbps；1 个 HDMI 2.1 FRL 接口用来连接外部显示器，以及 1 个 SD Express 7.0，用于高速存储卡和 1 个 3.5mm 音频接口。

这些接口最大的意义，也是让它可以成为一台移动工作站：外接高速硬盘、4K 显示器、相机存储卡，以及各种创作设备。

64GB 统一内存，能让 AI 干多少活

前几天，在微软的特别活动上，他们把 Windows PC 分成了开箱即用的迷你台式电脑、具备混合智能，本地和云端 AI 的 Copilot + PC，以及能利用云端和本地 AI 进行创作的 Builder PC。

这台华硕 ProArt 创16 RTX Spark笔记本电脑正是位于 Builder PC，即创作者个人电脑的类别下，而眼下最热门的创作，自然是用 AI 来进行，生成游戏、3D 建模，还有简单的网页应用等，AI 都必须参与其中。

对华硕 ProArt 创16 RTX Spark来说，引入 AI 的方式之一就是本地部署，因为这样才能充分利用英伟达 RTX Spark 的能力。

我们下载了 LM Studio，并安装了 Qwen 3.8 27B 的模型。将思考深度调整为极高，问一句「你好」，这台笔记本总共花了 18 秒，能看到模型读取、处理输入内容的速度 Prompt Speed 是 615.7 token/s，生成 token 速度在 14.3 token/s，首 token 的时间是 2.83s。

而当我们尝试要求它做一些网页项目时，例如为一个 AI PC 的活动设计网页。

可以看到生成 Token 的速度还是稳定在 14 token/s 左右，首 token 的时间是 12.05s，总的用时为 609.67s。

对于 64GB 的统一内存来说，30B 左右的模型大概就是这类电脑的舒适区。

Qwen3 32B（NVFP4）的推理速度在每秒 55–60 tokens 上下，日常对话、文案写作、代码辅助完全流畅；喂入长文档做总结时，十万 token 级的上下文也没有明显衰减。

WorkBuddy，我的智能体现在 0 元/月

除了单独的本地部署，这台 Windows 电脑最有意思的地方是和 WorkBuddy 的配合。

打开我 MacBook Air 上的 WorkBuddy，能看到在设置的模型配置里，只有自定义模型这一栏。

而在这台华硕 ProArt 创16 RTX Spark 上，多出来了一个 Beta 功能，我们可以直接下载并管理本地运行的 AI 模型。

点击下载之后，电脑会自动开始下载模型，并解决好本地部署对应的规则，我们只需要开启，并让它常驻后台，回到 WorkBuddy 的任务界面，就可以选择该本地模型进行对话。

之前的 Three.js 屋顶游戏，现在通过 WorkBuddy 也能实现，虽然这个效果看着比不上当下最前沿的模型，但用来做一些初步的项目验证，观察可行性还是可以试试。

整个任务用时是 13m59s，对比使用 WorkBuddy 的云端模型，时间可能还更少。

也能看到任务管理器里，性能部分，GPU 的使用率开始上升到 100%，风扇转动的声音同样明显。

虽然在 WorkBuddy 内没有直接告诉我们这款本地模型是来自哪家模型厂商，但是和它简单的聊天，就能从模型的文件头部里找到相关信息。

这款模型是腾讯优化过的本地模型，500 亿参数的 MoE 模型，模型大小为 16GB，使用 CUDA 13 加速，在 GPU 上的推理速度能做到更加流畅。

针对腾讯优化过的本地模型的能力，我们也能找到更适合这款模型的任务，配合 WorkBuddy 这套 Harness 的能力，一些日常的简单办公，像是数据分析、数据可视化、报告总结等繁琐型工作，都会有不错的表现。

未来随着软硬件的配合，以及当前开源模型超越闭源，且都在做更快更小的 Flash 模型趋势下，在 WorkBuddy 内可直接下载的本地模型也肯定不会只有这一个。

当前我们也可以通过 LM Studio 本地模型 API 的方式，将 LM Studio 内下载的本地模型，以 API 的形式加载到 WorkBuddy 内。

加载成功之后，在 WorkBuddy 内就能显示对应的自定义模型。

采用同样的方式，也可以将本地模型加载到其他你常用的 Harness 工具里，像是 DeepSeek Harness。

算力很强，Windows 也在变得更好

如果前面 WorkBuddy 的体验让我们觉得，在 Windows 上使用本地 AI 已经足够简单，但针对 Windows 开发，又总是会有各种各样的问题。

这也是 Windows、Linux 和 macOS 三大系统用户经常纠结的原因。一方面

很多开源开发工具最初就是围绕 Unix/Linux 工作流构建的

，例如 Bash 脚本、Git、OpenSSL、编译器和各种命令行工具，在 Linux/macOS 环境中往往使用相似的调用方式。

另一方面，Linux 同样也会遇到驱动、系统库和不同发行版之间的兼容问题；macOS 也可能缺少 Python 包的 Apple Silicon build 版本，还可能需要安装 Xcode Command Line Tools。

好在现在我们看到的是，Windows 一直在解决这些问题，从前几天的 Windows 更新，正在推进的 Microsoft Execution Containers MXC 项目，能为执行文件操作、调用工具的 AI 智能体提供更安全、可控的运行环境。

在本地模型方面，微软也宣布为 Windows ML 引入 llama.cpp 支持，让开发者能够通过 Windows 的 AI 运行时调用更多开源模型。

以及之前就有的 WSL 提供 Linux 开发环境，到 Windows Terminal、WinGet，持续完善的 ARM64 原生开发工具，Windows 已经比过去更适合开发者使用。

同时，Windows 日常使用体验也在更新，新版 Windows Search，除了搜索文件和应用，还可以让系统执行对应操作，不必再进入设置菜单逐项查找。

Copilot 也准备加入更多本地能力，在获得用户许可后，它可以读取电脑里的相关文件、执行系统操作，或者调用本地模型完成任务。

所以，AI 能成为下一次换机的理由吗

以前，一台配备大容量 NVIDIA GPU 的 AI 工作站，往往意味着体积不小的主机、独立显卡和持续供电的桌面环境。

而现在，英伟达已经把一套能够运行大型本地模型、支持 CUDA 的计算平台，放进了一台不到 1.8kg 的 Windows 笔记本里。

我们可以把它带去办公室，放在咖啡店的桌子上，甚至拔掉电源，让一个 27B 模型继续运行。

但这台电脑也很清楚地暴露了现阶段本地 AI 的另一面：

硬件已经能够运行大型模型，软件却还没有完全做好让每个人都轻松使用它的准备。

WorkBuddy 这样的产品正在减少部署门槛，

更多

智能体

也开始尝试直接利用本地算力。另一方面，软件适配、模型能力、性能与续航之间的取舍，依然会影响最终体验。

所以，如果你每天都需要运行本地模型、开发 AI 应用，或者处理不方便上传云端的资料，这一代华硕 ProArt 创16 RTX Spark 笔记本电脑确实提供了一个值得考虑的新选择。

但如果你平时只是使用 ChatGPT、Gemini 等云端 AI 工具，现在还没有必要为了本地运行一个大模型，就专门换掉手里的笔记本。

眼下对于个人电脑来说，整体的趋势一定是往越大内存、越强算力、越多 AI 的方向发展。

当 AI 智能体越来越多地参与我们每天的工作，电脑本身的计算能力就会重新变得重要。以前我们可能只需要一台电脑连接云端 AI，以后也可以让一部分任务直接留在电脑里完成。
