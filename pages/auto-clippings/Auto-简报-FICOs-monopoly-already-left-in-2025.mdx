# 技术情报简报：FICO垄断格局瓦解分析

## TL;DR
FICO在信用评分领域的垄断地位将于2025年7月正式终结，核心触发因素是VantageScore获得房利美/房地美(GSE)认证，叠加FICO自身定价策略失效（抵押贷款查询费降至$0.99+$65/笔），行业试点已从50家机构扩展至全行业，但VantageScore需在2028财年前证明其能作为10%以上合规贷款的主要评分模型。

## 核心观点/技术细节
1. **政策转折点**：GSE对VantageScore的认证打破FICO在抵押贷款领域的排他性
2. **定价策略失效**：FICO将抵押贷款查询费降至$0.99+$65/笔的防御性定价已无杠杆空间
3. **市场渗透路径**：试点范围从50家机构向全行业扩展，但存在渐进式替代特征
4. **关键考核指标**：VantageScore需在2028财年前实现>10%的合规贷款主评分占比
5. **市场提前反应**：二级市场已对垄断终结完成定价（反映在周四股价走势）

## 核心痛点
1. **行业垄断僵局**：FICO长期把持信用评分基础设施产生的系统性风险
2. **替代方案验证**：VantageScore作为挑战者需要证明其模型稳定性与泛化能力
3. **转换成本困境**：贷款机构需承担系统改造和双模型并行期间的运营成本
4. **监管平衡难题**：GSE在促进竞争与维持风控标准之间的政策权衡
5. **定价权转移**：信用评分服务可能进入价格战阶段，影响行业利润率格局

> 注：需持续跟踪VantageScore的模型采用进度及FICO的应对策略（如技术升级或并购活动）
