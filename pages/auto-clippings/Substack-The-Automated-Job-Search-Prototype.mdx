# 📰 The Automated Job Search Prototype

**来源**: The Wondrous Mind of Dereck Bearsong
**链接**: https://dereckbearsong.substack.com/p/the-automated-job-search-prototype

## 📝 核心主旨 (TL;DR)
作者分享了利用 n8n 和 Google Gemini 构建自动化求职与资讯聚合工作流的原型经验。通过设计结构化的 Prompt 和一套 100 分制的多维量化评分系统（Rubric），AI 能够自动筛选并推送高度契合个人技能栈的职位，从而大幅提升求职效率；同时，作者指出了依赖传统招聘邮件提醒的局限性，并规划了向包含主动网页抓取在内的全自动化求职平台演进的架构路径。

## 💡 关键知识点 / 核心观点

- **n8n 与 LLM 结合的自动化数据管道设计**：利用 n8n 构建定时触发工作流，拉取邮件后将其合并为单一 JSON 对象输入给大模型。通过 JavaScript 节点清洗 LLM 返回的 Markdown 代码块（如去除 ````json ```` 标记）并解析为结构化数据，最终渲染为 HTML 邮件。在模型调用上，作者使用了 `gemini-2.5-flash`，并设置了较低的采样参数（Temperature: 0.4, Top K: 5.0, Top P: 0.4）以抑制幻觉，保证信息提取的稳定性和确定性。
- **基于多维量化 Rubric 的 AI 职位匹配算法**：摒弃了简单的关键词匹配，作者为 AI 设计了一套总分为 100 分的量化评估标准。该标准包含五个维度：核心标题相似度 (30分)、功能技能重叠度 (30分)、领域/行业相关性 (20分)、资历/级别匹配度 (10分) 以及技能可转移潜力 (10分)。AI 依据此标准对职位进行深度打分，并设置 70% 的阈值进行自动过滤，仅向用户推送高匹配度的高优职位。
- **结构化 Prompt 工程与垂直领域上下文注入**：文章展示了极佳的 Prompt 设计范式，采用 `&lt;INPUT&gt;`, `&lt;DO&gt;`, `&lt;DONT&gt;`, `&lt;OUTPUT&gt;` 的模块化结构严格约束 AI 行为。同时，通过 `&lt;MY JOB SKILLS&gt;` 标签精准注入作者的垂直领域技能树（如 SaaS 故障排查、Atlassian Rovo AI Agent 构建、API 集成、Python/Node.js 自动化等），使 AI 能够基于真实的业务场景和技术栈进行深度语义比对。
- **从“被动聚合”到“主动抓取”的架构演进逻辑**：作者敏锐地指出了当前原型（依赖 Indeed 等平台的邮件提醒）的系统性缺陷：邮件往往缺乏完整的职位描述，且无法保证推送所有新职位。为此，作者规划了向“全自动求职平台”的架构演进，计划引入主动网页抓取（Web Scraping）、更细粒度的标题比对和职位描述深度审查模块，以彻底摆脱对第三方被动通知的依赖。

## 🏷️ 提及的重要概念/公司/模型

- **AI 与大模型**: Google Gemini (具体使用 `models/gemini-2.5-flash`), Prompt Engineering (提示词工程), AI Agent, LLM 参数调优 (Temperature, Top K, Top P)
- **自动化与开发工具**: n8n (工作流自动化平台), JavaScript/Node.js, Python, RegEx (正则表达式), JSON Parsing (JSON 解析与清洗), Web Scraping (网页抓取)
- **业务与产品概念**: SaaS 故障排查 (SaaS troubleshooting), API 集成与排障, RBAC (基于角色的访问控制), 自动化工作流设计, 内部知识库构建, 数据科学 intake 优化
- **相关公司/平台**: Indeed (招聘平台), Anthropic, OpenAI, Atlassian (Jira Cloud, Rovo), WorkOS, GitHub
