# 精华简报：更优秀的 AI 代码注释分类器

**来源**：Hacker News Top / Entropic Thoughts  
**标题**：Better AI code comment detector  
**链接**：https://entropicthoughts.com/better-ai-comment-classifier  
**类型**：技术博客 / 工具发布 + 方法复盘

---

## 一、概述

作者重建了上一版 AI 代码注释分类器，解决了旧版依赖私人数据、代码与数据无法公开的问题。新版完全基于公开数据，并提供了可在浏览器本地运行的试用页面——粘贴内容不会离开用户设备，隐私安全。

该分类器的目标是判断一段代码注释是**人类编写**还是**AI生成**。相较于旧版只能笼统判断，新版在 UI 上支持逐段查看激活特征，可解释性显著提升。

---

## 二、核心性能数据

### 1. 交叉验证结果（平衡基准）

| 指标 | 数值 |
|---|---|
| 平衡准确率 | 77% |
| 准确率（Accuracy） | 77% |
| 精确率（Precision） | 75% |
| 召回率（Recall） | 80% |
| 敏感度（Sensitivity） | 80% |
| 特异度（Specificity） | 73% |
| F1 分数 | 77% |

混淆矩阵（“机器人”为正类）：

|  | 判定：人类 | 判定：机器人 |
|---|---|---|
| 输入：人类 | 73% | 27% |
| 输入：机器人 | 20% | 80% |

表面看错误率约 25%，但作者强调**分类器输出的是校准概率**，个体判断的可靠性与置信度直接相关：
- 置信度 ≥ 80% 时，假阳性风险降至 **5%**
- 置信度约 50% 时，错误率约一半

### 2. 非合成真实世界测试（更优）

作者额外用更接近真实分布的样本测试，表现显著提升：

| 指标 | 数值 |
|---|---|
| 准确率 | 88% |
| 精确率 | 89% |
| 召回率 | 86% |
| F1 分数 | 87% |

说明分类器在真实场景中可能比训练数据表现更好。

## 三、构建方法与关键设计

### 数据收集策略

1. 选取**宽松许可或 copyleft** 的代码仓库；
2. 检出其 **2021 年的最新 commit**，随机抽取若干文件；
3. 这些文件中的注释作为**人类样本**；
4. 剥离所有注释后，让多个 LLM 为同一批文件重新生成注释，作为**机器人样本**；
5. 尽量平衡每个文件在不同类别间的 token 数量，避免“题材泄漏”——即分类器靠文件内容而非注释风格来判断。

作者理想估算：若一次规划正确，数据集成本约 **$30**，即可达到收益递减点。分类器能力与**花费的对数**大致成正比，因此后续追加投入的边际收益会迅速下降。

但实际过程中，作者因数据质量问题反复推翻重来，付出了远高于 $30 的成本（原文以 💸 符号自嘲），凸显**数据质量验证的重要性**。

### 可解释性

新版 UI 允许点击任意文本片段，查看哪些特征被激活及其对最终判断的贡献。这种透明度是旧版所不具备的。

### 校准机制

分类器输出经过温度参数校准，能适应不同长度文本带来的置信度变化，使得概率值可直接解读为“判断正确的可能性”。

## 四、局限与边界

- **仅针对代码注释**：对其他类型文本的检测能力虽有，但作者不承诺准确性。
- 交叉验证误差约 25%，在低置信度场景下不可靠。
- 数据基于 2021 年的代码仓库，可能无法完全反映最新 AI 模型的注释风格。

---

## 五、技术与商业洞察

1. **校准概率比单一准确率更有价值**  
   在内容审核、AI 检测等应用中，给出“置信度 80%”比“准确率 77%”更具可操作性——用户可以自主决定在何种阈值下采取行动。

2. **数据质量是隐藏成本大头**  
   作者多次因“数据是垃圾”而推翻重来。实际项目中原型搭建往往快，但构建可靠训练数据的时间与金钱成本容易被低估。

3. **对数收益规律意味着“够用就好”**  
   分类器性能随投入呈对数增长，强行追求极致准确率性价比极低。$30 级别的数据集即可接近实用水平。

4. **可解释性助力用户信任**  
   特征激活可视化让用户理解判断依据，对技术工具的采纳和调试有显著帮助。

5. **本地推理满足隐私敏感场景**  
   对于企业代码审查等场景，数据不离开浏览器是一个重要卖点。

---

**一句话总结**：作者用公开数据重建了一个可解释、校准良好的 AI 代码注释分类器，真实场景 F1 达 87%，并揭示了数据质量与成本控制才是此类项目的真正难点。
