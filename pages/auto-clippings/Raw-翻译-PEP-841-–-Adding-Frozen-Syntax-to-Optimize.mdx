摘要

本PEP提议添加

冻结显示

语法：
```
f{1, 2, 3}
```
评估为一个
```
frozenset
```
，而
```
f{'a': 1}
```
评估为一个
```
frozendict
```
。由于不可变性是通过语法本身保证的而非从使用中推断出来的，编译器可以将冻结显示视为其优化管道中的头等公民：常量显示在编译时被折叠为单一的
```
LOAD_CONST
```
操作，并且具有确切的结果类型，在
```
.pyc
```
文件中缓存。
