【帖子标题】：My first run of Kimi K3 locally.

【帖子正文】：
使用 llama.cpp 通过 RPC 在两个集群上运行。
 
两个集群都未能将所有内容保留在内存中，因此主集群仍然部分卸载以运行。我的目标是将所有的 GPU 集成到一个系统中，在没有 RPC 的情况下，我应该可以看到 2-3 倍的速度提升。运行 IQ1_M，目标是达到 Q2_K_XL。我希望 Qwen3.8 和 DeepSeekV4Pro/GLM5.3 都会有更好的表现、更快的速度和更小的体积，并且大小相当。我打算给它一个硬编码的问题来检验结果的质量，但想法可能是用它来进行规划并把工作分发给 DeepSeekV4Flash 和 Qwen3.7-27B。

有志者事竟成。我们永远不要放弃本地 llama！“预算”级构建一路走到底。
