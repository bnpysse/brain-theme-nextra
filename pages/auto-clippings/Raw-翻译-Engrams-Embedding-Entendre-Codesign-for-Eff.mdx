Engram extends standard token embeddings with learned multi-token lookups. Recurring local patterns retrieve vectors directly, reducing the need to reconstruct them through attention and feed-forward layers.  
记忆印痕通过学习的多令牌查找扩展了标准令牌嵌入。重复出现的局部模式直接检索向量，减少了通过注意力层和前馈层重构的需求。  

With Engram model architecture optimization, it allows for lower HBM capacity to be needed for models at the same quality.  
通过记忆印痕模型架构优化，可在保持相同模型质量的前提下降低对HBM容量的需求。  

This does not mean there won’t be an insane demand for HBM but it just means that model architecture will continue to innovate around constraints.  
这并不意味着HBM需求会减少，而是表明模型架构将持续围绕硬件限制进行创新。  

This model architecture design is naturally codesigned for parameter offloading: each token accesses a few embedding rows whose addresses depend on token IDs, not hidden states. The runtime can prefetch those rows from host DRAM while earlier layers compute, keeping the table outside HBM without transferring entire weight matrices.  
该架构天然适配参数卸载设计：每个令牌访问的嵌入行地址仅依赖令牌ID而非隐藏状态。运行时可在前层计算时从主机DRAM预取数据，无需转移整个权重矩阵即可将表保留在HBM之外。  

Our Memory model contains our latest estimates of quarter by quarter HBM, DRAM, & NAND supply and demand.  
我们的内存模型包含HBM、DRAM和NAND最新分季度供需预测。

Offloading frees HBM for model weights and KV cache, potentially supporting larger batches or more concurrent sessions. When DRAM becomes the next constraint, NVMe offers another tier. Recommendation systems already cache frequently or recently accessed embedding rows in faster memory while backing colder rows with SSDs.  
卸载机制为模型权重和KV缓存释放HBM空间，可能支持更大批次或更高并发。当DRAM成为下一瓶颈时，NVMe可提供额外层级。推荐系统早已将高频/近期访问的嵌入行缓存于快速内存，同时用SSD存储冷数据。

What is Being Memorized?  
模型记忆了什么？  

Like the original Engram paper, it is possible to probe Engram’s gate scores to see what n-grams DeepSeek-V4.1-Flash makes the most use of. Our gate scan finds names, code fragments, relational phrasing, and boilerplate. These examples prioritize interesting-ness over gate strength.  
如原论文所述，可通过门控分数分析DeepSeek-V4.1-Flash最常使用的n-gram。我们的扫描发现姓名、代码片段、关系短语和模板文本。这些示例优先展示趣味性而非门控强度。  

One unexpected result was Wright : Ace Attorney.  
出人意料的结果包括《逆转裁判》中的"成步堂"（Wright）。

These examples suggest learned memory optimizes the training objective, not a judgment of which facts deserve storage. Licenses, bibliography fragments, API scaffolding, and website furniture can provide prediction shortcuts, so the value of additional Engram capacity may depend on what survives data preparation. This does not show that table capacity is "wasted": the evaluation-corpus scan establishes neither training exposure nor the capacity occupied by each category.  
这些案例表明学习到的记忆服务于训练目标，而非判断哪些信息值得存储。许可证、参考文献片段、API框架和网页模板能提供预测捷径，因此额外记忆容量的价值取决于数据预处理后的幸存内容。这并非表明表容量被"浪费"：评估语料扫描既不能确认训练曝光度，也无法确定每类内容所占容量。  

For offloading, strong gates do not identify cache-hot rows. Low gates do not automatically save reads either: computing the gate requires the retrieved key and undoes the performance gain of a fused kernel. Skipping reads would require a separate usefulness predictor before retrieval.  
就卸载而言，强门控不意味着缓存热行。弱门控也不会自动节省读取：计算门控需检索键值，反而抵消融合内核的性能收益。跳过读取需在检索前单独预测有用性。
