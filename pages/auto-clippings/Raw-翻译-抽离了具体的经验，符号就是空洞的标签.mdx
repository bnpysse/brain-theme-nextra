【文章标题】：抽离了具体的经验，符号就是空洞的标签

【文章正文】：

当摄政公园 (The Regent's Park) 的落叶开始在草地上厚厚堆起，也宣告着伦敦艺术圈重头戏的开场。走过23个年头的弗里兹艺术博览会，照例在十月中旬支起两座巨大的白色帐篷：南边的Frieze London专攻当代艺术，穿过一条林荫道往北，则是聚焦古代至上世纪创作的Frieze Masters。这里当然是一个以促成交易为终极目标的商业卖场。但自2003年创办以来，弗里兹就一直试图在买卖的喧嚣里替艺术史与学术研究留出一席之地。今年，北京中间美术馆馆长卢迎华受邀策划特别单元“The Code Universe”（“符号的宇宙”）。在商业交易最密集的博览会现场，她顺着一条始自1980年代中期的历史线索，回溯五六十年代波普艺术与观念艺术兴起之后，当代艺术与大众流行文化、商品图像机制半个多世纪以来的纠缠与对话。

所谓的“符号”，一面是人们每天一睁开眼，就被各种商品包装、商标、广告和屏幕信息塞满的现实世界，这些东西早就写满了社会身份与消费暗示；另一面则是艺术家怎样把这些满大街都是的流行符号拿过来，拆开观察、再重新拼贴回去。

伦敦的greengrassi画廊与东京Take Ninagawa画廊共同呈现的日本艺术家大竹伸朗出生于二战结束十年后的1955年，彼时战败的日本正经历美式大众文化如海啸般涌入的冲击，铺天盖地的商业图像与印刷品成了他成长中最刺眼的视觉记忆。1977年他第一次离开日本前往伦敦，便开启了贯穿毕生创作的拼贴项目《剪贴簿》（Scrapbooks，1977年至今）。半个世纪以来堆叠的旧照片、车票、商品包装与印刷残片，在这位艺术家的手下被层层糊实、风干并重构。

展位现场既有1978与1979年的早期册页，也带来了2016年完成的第68号《剪贴簿》，甚至延伸至2025年刚做好的最新纸本。商业广告费尽心机用具象画面勾引人掏钱，大竹伸朗则反过来，将这些大家早就看惯的消费符号硬生生剥离出来，转化为带有雕塑般厚重手感的物质档案。画廊展位上那本要价高达30-40万美元的巨型《剪贴簿》，与两三万美元的小尺幅早期手稿并置，让人看清大众文化如何成为艺术家手里的现成工具，并在这场漫长的积累中被重新定义。

同样聚焦于消费流行符号与身体异化的，是伦敦TINA画廊展出的卡里姆•鲍姆吉马尔(Karim Boumjimar)。这位生于1995年的艺术家长年关注身体畸变与身份重塑，他将陶瓷塑造成近乎变异的器官组织，以带着戏谑却又不安的质感，直面数字时代对肉身的重塑与围剿。

而在北京马刺画廊，学金融出身、后来靠自学转向全职艺术创作的朱昶全则把这种拼贴逻辑直接推进到了当下的算法与神经感知中。这位生于1989年的中国艺术家骨子里并不执着于去道德评判消费主义。展位上的数字影像装置收录了他从微信、微博到Instagram等平台截取的一千余条短视频：5秒钟造好一艘下海的远洋巨轮、高速运转的工业机械臂，以及各式各样在屏幕前重复敲击、滑动的肉身特写。在他看来，当代人每天被过剩的极速制造与爆炸性短视频塞满，身体和大脑早就不堪重负。当传统劳动被机器取代，人反倒退化成了一种表演者，在屏幕前靠手指与眼球的配合完成一场场“表演性生产”。他借这些短片，逼问观众在信息早已过载的后网络时代，究竟该靠怎样的智慧去消化这套强加给肉身的算法代码。这套限量5版的影像装置，在博览会现场要价约20，000英镑。

朱昶全拼贴逻辑并未止步于数字屏幕。他的的架上绘画不用传统的画布，而是用干制海藻皮作为底材，再混合废弃鱼油与螃蟹油调成的特制颜料绘制。走近时，甚至能隐约闻到画面散发出来的一股鱼油腥味。不同于昂贵的数字影像装置，展位里的这些海藻皮绘画单幅标价为8,500英镑。

柏林Trautwein Herleth画廊则带来了1987年出生的美国艺术家卡罗琳•拉扎德 (Carolyn Lazard)。拉扎德长年受慢性病所困，创作大都与医疗机制紧密纠缠。展位展出的三件作品中，包括两组以圆珠笔为主要材料的墙面装置，每支笔身都印着不同药品的名称与医疗符号，拉扎德巧妙地将它们分别命名为《肖像一号》（Portrait I）与《肖像二号》（Portrait II）。

基辅的Voloshyn Gallery呈现的44岁乌克兰艺术家尼基塔•卡丹 (Nikita Kadan)，直接将战火烧灼下的基辅现实硬生生切片呈现。展位最显眼的位置挂着一幅宽达3米的纸本双联木炭大画《日间黑夜》（Night During the Day，2026）。画面记录的是当前基辅严酷军事宵禁下的魔幻景象：因为深夜禁止出门，年轻人被迫在白天聚进防空地下掩体，举办充斥着强烈节拍的 Techno 锐舞聚会，借此寻找高压下的片刻喘息。这件作品要价90,000 欧元，已被多家国际美术馆与重要藏家密切问询。

这一单元同时呈现了两位巴厘岛艺术家。巴厘岛的Nonfrasa画廊带来了1984年出生的本土艺术家纽曼•达马万 (Nyoman Darmawan) 的个展“不可见之物的方言”(The Idiolect of the Unseen)。达马万出身三代艺术世家，但他没有沿着古典巴厘岛绘画，而是在水墨与丙烯之间留出大片呼吸的空白。展位上的作品从几百英镑的小尺幅水墨，一直延伸到七千余英镑的大画。那些被拉长、扭曲的男女肢体与植物藤蔓紧密缠绕，将印度教中掌管繁衍与万物原力的“林伽-约尼”(Linga Yoni)符号，化解为当代个体在家庭责任、欲望与世俗清规之间的拉扯。

与之相对，由数家画廊联合以Valentine之名呈现的已故巴厘岛艺术家德瓦•拉拉姆 (Dewa Raram)，展现了完全另一套民间生命力。这位生前不识字、全靠自学成才的创作者，在当地更为人熟知的名字是奥托托尔 (Oototol)。他留下的画作记录着神话图腾与乡野日常，带着未经规训的纯粹与粗粝。令人意外的是，展位里的全部作品均不出售。画廊工作人员表示，现场这批作品纯粹作为文献与文化遗产呈现，而回顾以往的过往交易记录，他的画作价格大抵落在数千美元区间。

在布达佩斯acb画廊的展位前，生于1991年的波斯尼亚艺术家塞尔玛•塞尔曼 (Selma Selman) 带来的几乎全是硬碰硬的废旧金属。具有波斯尼亚罗姆人 (Bosnian Roma) 背景的塞尔曼，年少时为了对抗族群里买卖妇女的陋习，主动向家人追问自己“自由的代价”，靠自己的劳动早早赎买了人身自由。她的家族长期靠拆解西欧报废汽车与电子垃圾为生，这些带有凹痕、锈斑甚至机油味的工业残件，被她直接在表面施以油彩，搬进了博览会。现场作品的定价跨度很大，从 2,200 欧元的小型金属残片，到展位中央一件由废弃浴缸底板改造成的装置作品，上面用油彩画着她赤身躺在其中的自画像，标价高达40,000欧元。

从日本街头的废弃印刷品到巴厘岛的古老图腾，再到巴尔干半岛的工业残件，八位艺术家的展位呈现出各自迥异的地域拼图。卢迎华之所以将展线拉回1980年代并把八位背景迥异的艺术家聚拢在一起，核心意图正在于用具体、鲜活的个体经验，击碎那种用单一西方理论模具套用全球创作的偷懒分类法。

这种警惕直接来自她对中国当代艺术史的研究积累。1980年代全球商业贸易全面铺开，波普与观念艺术伴随消费图像传向世界各地，却在不同土壤里长出了截然不同的生命形态。正如1990年代初中国出现的“政治波普”，西方评论界习惯性套用冷战意识形态与社会反叛的现成标尺进行解读，而回到当时的真实历史语境就会看清，画布上反复出现的工农兵与红色符号，背后真正的驱动力并非概念化的政治对抗，而是在市场化转型猛烈砸碎原有生活时，人们对旧日集体经验的一种复杂感怀。

一旦抽离了具体的生活经验，符号就会沦为空洞的标签。从大竹伸朗对战后日本消费狂潮的物质封存，到朱昶全对算法时代过剩信息的机械消化；从拉扎德将慢性病患者的身体管理代码公之于众，到卡丹与塞尔曼在战火废墟和边缘社群中抢救出的真实创伤；再到达马万与奥托托尔深植于巴厘岛神话、信仰与反商业法则的在地生存，这八位艺术家没有一个人在顺从既定的全球图像秩序。他们借用人们早已习以为常的符号，却又毫不留情地将其拆解开来。正是地域内部的抵抗，构成了“The Code Universe”最核心的策展力量。

在博览会里做策展，除了艺术史层面的较劲，还得直接面对画廊的生存现实。卢迎华这次挑选的合作对象跨度很大，既有扎根数十年的资深中型画廊，也有刚创办两三年的年轻空间与自发联合的画廊组合。

当前的全球艺术市场正经历着剧烈分化，顶层资源被少数超级跨国蓝筹画廊高度占据，无论一级市场的成交体量、美术馆的展览推手还是公共舆论的话题走向，几乎全被资本巨头牢牢牵引。但在头部画廊依靠体量与雄厚资金推进大型项目的同时，这些扎根于不同本土语境的中小型画廊，同样为维系艺术生态的丰富度与前沿敏锐度扮演着不可或缺的角色。无论是一步步陪伴艺术家漫长成长的中坚力量，还是初生牛犊般挑战规则的新锐空间，如今都在承受着经济下行与地缘政治动荡带来的双重挤压，生存缝隙肉眼可见地收窄。

在竞争残酷且高度资本化的博览会丛林里，“The Code Universe”以严谨的学术思考与历史脉络，在买卖的喧嚣之中撑开了一扇透气的窗口。平心而论，这里的参展艺术家未必人人都会成为明天的市场巨星，部分作品在走出策展语境后，也难免面临商业流通上的严苛考验。但将其聚拢在聚光灯下的价值恰恰在于此：它并不急于制造下一个交易神话，而是提供了一处难得的沉淀空间，令身处消费狂欢中的人们回过神来，重新审视那些无孔不入的代码究竟如何重塑了我们的身体、知觉与日常生活。
