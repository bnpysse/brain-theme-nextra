# 精华简报：HN热帖引发的AI爬虫流量风暴与基础设施反思

## 核心摘要

独立开发者Sammy在Hacker News发布产品后，网站遭遇了以AI爬虫为主的异常流量冲击——近半流量来自单一AI摘要服务，另有Claude、OpenAI、Google等各类爬虫及漏洞扫描器蜂拥而至。这次事件促使他完成了基础设施性能优化，并引发了对AI时代网站流量生态的深刻反思。文章同时分享了利用LLM改造Emacs浏览器的大胆实验。

## 一、事件复盘：HN发帖后的流量异变

### 1.1 事件经过

- **背景**：作者开发的sprinklz.io（可定制RSS阅读器，支持话题降权）在HN获得约100个赞，热度不错

- **异常信号**：网站持续缓慢，且热度消退后反而恶化；活跃用户不多，但服务器负载极高

- **关键发现**：通过端点级日志发现**大多数请求根本不执行JavaScript**（SPA应用的核心渲染逻辑），说明流量来源并非真实用户

### 1.2 流量解剖：AI爬虫的“饕餮盛宴”

| 流量类型 | 特征 | 占比/说明 |

|---------|------|----------|

| **单一AI摘要服务** | 自称“监听网站变化并生成AI摘要通讯”，**每分钟多次查询** | **近半流量** |

| **已知AI爬虫** | Claude bot、OpenAI bot等，按robots.txt规范标识身份 | 显著比例 |

| **搜索引擎爬虫** | Google索引器等 | 允许保留 |

| **漏洞扫描器** | 尝试访问`/wp-content/phpinfo.php`等路径（网站并非WordPress） | 偶发 |

### 1.3 应对措施

1. **配置robots.txt**：屏蔽AI扫描器，保留Google等搜索流量

2. **安全自查**：模拟漏洞扫描器路径，确认无信息泄露

3. **限流策略**：增加合理的速率限制

4. **基础设施升级**：数周内完成多项底层优化，显著提升整体性能

## 二、技术要点与商业启示

### 2.1 AI爬虫的“野蛮生长”已成常态

- **无差别抓取**：AI服务商为保持内容更新，对中小网站进行高频轮询，**完全无视服务器负载**

- **身份隐匿**：部分爬虫不遵守robots.txt，或不标识自身身份

- **流量占比惊人**：单一AI服务即可占据半壁江山，对独立开发者构成实质性资源消耗

### 2.2 对独立开发者的警示

- **性能弹性是刚需**：任何一次公开曝光都可能引来非人类流量，**基础设施必须为“最坏情况”设计**

- **日志分析不可缺**：顶层日志+NGINX聚合分析是识别异常流量的关键手段

- **robots.txt效力有限**：仅对“守规矩”的爬虫有效，需配合限流等多层防护

### 2.3 商业层面的深层思考

- **AI摘要服务的“搭便车”问题**：第三方AI服务通过抓取网站内容生成摘要通讯，**不产生点击回流**，却消耗原网站资源——这是AI时代内容分发的结构性矛盾

- **“AI垃圾内容”的讽刺**：用户用该工具过滤AI内容，而AI爬虫却在消耗网站资源生成更多AI摘要——**技术解决方案与问题本身形成了闭环**

- **小站点的生存压力**：若AI爬虫流量持续增长，独立网站需在“防护成本”与“内容价值”间重新权衡

## 三、延伸实验：LLM驱动的Emacs浏览器改造

### 3.1 问题背景

Emacs浏览器仅支持纯文本渲染，对现代JavaScript重载网页几乎不可用。

### 3.2 技术方案

```

现代网页 → Firefox加载并执行JS → LLM生成转换程序 →

注入Firefox提取简化HTML → 转发至Emacs浏览器

```

### 3.3 价值与意义

- **LLM作为“翻译层”**：将复杂网页结构转化为可复用的简化规则，而非一次性转换

- **反哺内容生态**：作者希望借此“减少世界上的垃圾内容”——让文本浏览器重新可用，降低对重前端页面的依赖

- **效果初评**：可用性显著优于默认体验，计划打包发布

## 四、行动建议

| 受众 | 建议 |

|------|------|

| **独立开发者/小站长** | 部署请求级日志监控；配置robots.txt白名单策略；为公开曝光提前做压力预案 |

| **内容平台** | 关注AI爬虫流量占比，建立识别与限流机制；评估与AI服务商的合作/授权模式 |

| **AI服务商** | 遵守robots.txt与抓取频率规范；考虑对高频抓取提供缓存/API合作方案 |

| **基础设施团队** | 将“非人类流量”纳入容量规划；利用CDN/边缘层拦截已知爬虫 |

## 五、一句话总结

&gt; **AI爬虫正在重塑网站流量的底层生态——独立开发者不仅要防“人潮”，更要防“机潮”；而LLM既是问题的制造者，也可能成为解决方案的一部分。**
