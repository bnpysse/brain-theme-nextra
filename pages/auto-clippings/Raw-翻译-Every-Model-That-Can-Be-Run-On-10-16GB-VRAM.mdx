It's been 4 years since

c.ai

first hallucination model, and yet, we're nowhere good enough at LLMs in terms of spontaneity/interesting hallucination features. Fortunately, last year brought new architecture that allow those within 10-16GB VRAM range to run something usable up to 64k Context Windows via Kobold or LLAMA.

【帖子正文】：

距离

c.ai

推出首个幻觉模型已经4年了，然而，我们在LLM的自发性/有趣幻觉特性方面还远远不够好。幸运的是，去年出现了新的架构，让那些拥有10-16GB显存的人能够通过Kobold或LLAMA运行一些可用的模型，上下文窗口最高可达64k。

Requirements:

10-16GB VRAM - 26-32GB RAM.

要求：

10-16GB显存 - 26-32GB内存。

How I Evaluated:

Speed;

If tokens per second are at least 10t/s.

Coherency:

If dialogue/monologue/POV makes any internal sense asides from basic logic (robotic feeling) or behaviorism.

JP/PT-BR/US-EN:

If it can handle/interpret typos, nuance or harsh verbiage.

Slop Patterns:

From "casting long shadows" to "smells like ozone and burnt sugar" frequency.

MOE vs FULL:

If rather pick a MOE instead of a FULL model.

Censorship;

All these models have either none or too low refusal rates even at NSFL topics, worry not.

Instruction/Engineering:

I've tested WITH and WITHOUT Pandora Instructions, if a model can handle 23 intertwined rules it can handle anything/not need a prompt at all.

我的评估方式：

速度；

每秒令牌数是否至少达到10t/s。

连贯性：

对话/独白/视角是否除了基本逻辑（机械感）或行为主义之外，在内部有逻辑意义。

日语/葡萄牙语/美式英语：

是否能处理/理解拼写错误、细微差别或粗俗用语。

“俗套模式”：

从“投下长长的影子”到“闻起来像臭氧和焦糖”这类表述的出现频率。

MOE vs FULL：

是否更倾向于选择MOE而不是FULL模型。

审查机制；

所有这些模型即使面对NSFL话题，拒绝率也极低甚至为零，不用担心。

指令/工程：

我测试了有和没有Pandora指令的情况，如果一个模型能处理23条相互交织的规则，它就能处理任何事情/根本不需要提示词。

Side Note:

I've ignored all CoT models, waste of tokens, slower, not needed, not at all. Do prompt nicely and it's the same. Just pick any quant higher than Q_4_K, size doesn't matter ( ͡° ͜ʖ ͡°).

附注：

我忽略了所有CoT模型，浪费令牌，更慢，完全不需要。好好写提示词效果一样。只要选择任何高于Q_4_K的量化版本，大小无所谓（ ͡° ͜ʖ ͡°）。

The Catch:

I've done a small knowledge test involving animes/manga/movies/music on 70B, 120B and 300B models and found out only models above 200B actually have this sort of data, even a 120B will rarely have the information about the media you're interest at. But who can even run it?

关键点：

我在70B、120B和300B模型上做了一个涉及动漫/漫画/电影/音乐的小型知识测试，发现只有200B以上的模型才真正拥有这类数据，即使是120B也很少有你感兴趣的媒体信息。但谁又能运行它呢？
