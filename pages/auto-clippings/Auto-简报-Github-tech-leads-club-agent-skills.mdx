### 核心总结
- Agent Skills是Tech Leads Club推出的专业AI编码代理安全验证技能库，定位为可信的AI编码助手插件，可为Antigravity、Claude Code、Cursor等主流工具扩展能力，解决公开技能市场超13%技能含高危漏洞的安全痛点。
- 项目搭建了多层安全防护体系：全开源无二进制、CI/CD流程静态分析、内容哈希与锁文件保障完整性、人工审核提示词、发布前经Snyk Agent Scan扫描，CLI侧采用路径隔离、符号链接防护等纵深防御措施。
- 技能以结构化目录打包指令与资源，包含说明文档、文件模板、参考资料等模块，项目基于TypeScript开发，采用Nx Cloud、语义化发布等工程化方案，配套官方文档站。
