【文章标题】：macOS Golden Gate Is a Buggy Mess

【文章标题】：macOS金门大桥系统漏洞百出

【文章正文】：

In June 2008 Apple announced Mac OS X Snow Leopard, proudly boasting that it would have "no new features". Instead of piling on new things, Snow Leopard aimed to build on the success of its predecessor, Leopard, opting to focus on under-the-hood performance and stability improvements throughout the system.

2008年6月，苹果发布了Mac OS X Snow Leopard（雪豹），自豪地宣称该系统"没有任何新功能"。雪豹没有堆砌新功能，而是旨在延续其前身Leopard的成功，选择专注于系统底层性能和稳定性的全面改进。

18 years later, Apple is taking a similar approach with macOS 27. Golden Gate aims to fix the missteps of last year's Tahoe, promising an expansive set of improvements and "a more responsive and delightful experience".

18年后，苹果对macOS 27采取了类似策略。金门大桥系统旨在修正去年Tahoe系统的失误，承诺带来一系列广泛改进和"更灵敏愉悦的体验"。

Does it hold up? Here are just some of the bugs I’ve encountered in my daily use over the past couple of weeks.

实际情况如何？以下是我过去几周日常使用中遇到的部分漏洞。

Alignment is hard

对齐难题

Let's start with some good old alignment bugs. Centring things is the hardest problem in computer science, after all.

先从经典的对齐漏洞说起。毕竟，居中显示堪称计算机科学领域最棘手的难题。

Take the QuickTime record button. Hey, at least it's vertically centred.

看看QuickTime的录制按钮——嘿，至少它垂直居中了。

And here are the window tiling icons. These were centred at some point, I'm sure.

再看窗口平铺图标。我确信它们曾经是居中对齐的。

Text is affected, too, but I'm not sure this is even attempting to look centred.

文字同样遭殃，但我怀疑这些文本连居中尝试都没有。

And this is the first thing you see when you open System Settings. A little bit more padding under the heading wouldn't hurt, no?

这是打开系统设置时首先看到的界面。标题下方多加些留白会更好吧？

Things they forgot

遗漏之处

Opening the Mac User Guide, I was quite surprised to find that it was for last year's OS. This made me wonder: what else did they forget?

打开Mac用户指南时，我惊讶地发现这竟是去年系统的版本。这让我不禁怀疑：他们还遗漏了什么？

We're bound to find things Apple overlooked poking around the Touch Bar settings. Sure enough, here's Siri's old logo.

在Touch Bar设置里翻找，果然发现了苹果的疏忽——看，这是Siri的旧版logo。

The Network app, too, can’t make up its mind whether to use its new icon or not.

网络应用也陷入纠结，无法决定是否使用新图标。

And I know I'm nitpicking (I'll indulge myself some more later), but the window controls now have a glossy sheen. Nobody seems to have told the Mission Control app.

我知道这有些吹毛求疵（稍后还会继续），但窗口控件现在有了光泽效果——似乎没人通知过Mission Control应用。

Bugs

系统漏洞

In this release, Apple changed the architecture of the menu bar, breaking a number of third-party menu bar management apps.

本次更新中，苹果修改了菜单栏架构，导致多款第三方菜单栏管理应用失效。

It also introduced several bugs, and even the occasional crash. Let's have a look!

还引入了若干漏洞，甚至偶发崩溃。一起来看看！

I know my machine's getting old, but does it really need a second to load in the Profiles menu when I open a new Firefox window?

我知道我的设备老了，但打开新Firefox窗口时，配置菜单真需要加载一秒钟吗？

And why does it keep highlighting the File menu for me?

为什么总是自动高亮文件菜单？

This is a fun one. Try moving the green camera icon. Oops! You've crashed the menu bar.

这个很有趣：试着移动绿色相机图标——哎呀！菜单栏崩溃了。

Bugs are elsewhere in the system, too. Sometimes the search bar in System Settings simply refuses to work.

系统其他部分也有漏洞。有时系统设置的搜索栏直接罢工。

Not that it's much use when it does function. Here's me trying to move down the search results with the arrow keys.

即便能用也不太好使。看我用方向键浏览搜索结果的样子。

Also new in this release: links are only clickable for a split second. Miss it and it's gone!

新"特性"：链接仅在瞬间可点击。错过就消失！

I'm still not sure what this button is actually meant to do. I've been pressing it for over an hour now.

至今没搞懂这个按钮的功能。我已经按了它一个多小时。

About as much time as I've been waiting for this volume slider to auto-hide itself. It never took this long in the past.

就像我等这个音量滑块自动隐藏的时间——过去从不需要这么久。

Now onto Mission Control. Here's a fun fact: You can find references to NeXTSTEP, the ancestor of macOS, in its UI! You're not supposed to, mind.

现在看看Mission Control。冷知识：你能在界面里找到macOS祖先NeXTSTEP的痕迹——虽然本不该看到。

I'm not sure this is supposed to happen, either. Capturing these bugs is hard work when you can’t even trust the tool you’re using to behave properly.

这也不该发生。当你连截图工具都无法信任时，捕捉这些漏洞真是艰难。

Window sizes can also be miscalculated.

窗口尺寸也会计算错误。

And window controls can disappear altogether.

窗口控件还可能集体消失。

Tiling has always been a struggle in macOS.

窗口平铺在macOS里向来是个难题。

If you want a challenge, try to recreate whatever's going on here. Go on, give it a go.

想挑战的话，试着复现这个画面吧。来试试看。

Nitpicking

吹毛求疵

I can't in good faith include these as regular bugs. I'd like to think there was a time when you could expect macOS to be obsessively polished, but I recognise no software is perfect, and you have to draw a line somewhere. But if I was promised refinements...

这些不算严格意义上的漏洞。虽然怀念macOS曾经极致打磨的时代，但我也明白没有完美软件，总要有取舍。不过既然承诺了优化...

Returning to the Touch Bar, why does this one icon not match the UI on screen?

回到Touch Bar，为什么这个图标与屏幕UI不匹配？

Another one for you fact fans: try using the screenshot app to capture an app window and you'll discover the only straight corner in the entire OS. Don't tell the Apple design team.

给考据党的彩蛋：用截图工具截取应用窗口，你会发现整个系统中唯一的直角——别告诉苹果设计团队。

This one just irks me. Show me one oval camera lens anywhere in the world. I'm waiting.

这个真让人恼火。给我找出世界上任何一款椭圆形相机镜头。我等着。

And here, shouldn't there be some sort of visual feedback when I click on this menu item? A hover effect? Anything?

还有，点击这个菜单项时不该有点视觉反馈吗？悬停效果？随便什么都行？

And lastly, something I find unintuitive. I have a folder open in the Dock. If I click on another folder, shouldn't that then open?

最后这个设计不够直观：Dock里已打开一个文件夹，点击另一个文件夹时，难道不该自动打开吗？

Conclusion

结语

Okay, I admit it. Once I started to notice a few, I did purposely go looking for bugs. But not very hard, promise.

好吧我承认，发现几个漏洞后，我确实刻意去找了更多——但没太费力，真的。

And that's the point. In a release where "nothing was off limits, no enhancement too small", it shouldn't be this easy to find bugs in daily use.

问题就在这。在号称"无所不优化，细节皆改进"的版本里，日常使用不该这么容易发现漏洞。

Perhaps there's hope yet. Snow Leopard had nearly two years of refinements to achieve the level of polish and stability its name has become synonymous with today. Maybe the annual release cycle has become a burden, and Golden Gate just needs more time.

或许还有希望。当年雪豹经过近两年打磨才成就今日"精稳代名词"的美誉。或许年度更新周期已成负担，金门大桥系统只是需要更多时间。

If AI has really sped up software development as much as we're told, this shouldn't be a problem.

如果AI真如宣传那般加速了软件开发，这应该不成问题。
