# 📰 Inside the Model Factory — Eiso Kant, Poolside AI

**来源**: Latent Space
**链接**: https://www.latent.space/p/poolside

## 📝 核心主旨 (TL;DR)
Poolside AI 联合创始人 Eiso Kant 揭示了大模型研发正在经历的底层范式转移：**大模型构建本质上是 90% 的系统工程**。通过自研端到端的“Model Factory”，Poolside 以不足百人的核心团队实现了每月 1万-2万次实验的工业级吞吐，将模型迭代周期从数月压缩至 8 周，并成功推出参数高效（MoE架构，总参118B/激活8B）且性能越级的 Laguna S 系列。文章同时论证了开放权重与深度开源研究的战略必要性（坚决反对技术寡头垄断），指出未来能力突破将更多依赖数据工程、RL 前置、低精度计算与智能体自动化闭环，而非单纯的参数缩放或 Next-Token 预测。

## 💡 关键知识点 / 核心观点
1. **“Model Factory”工业范式中台：从科研到流水线的跨越**
   - **工程压倒算法**：模型训练已被重构为高度标准化的分布式生产流程。Poolside 拒绝 Fork 现有开源栈，从零搭建涵盖流式数据注入、不可变数据集管理、分布式调度、自动评估与管道修正的完整基础设施。
   - **实验吞吐量与自动化**：系统优化的核心指标是“想法到可信结果的流转速度”。借助 AI Agent 接管发任务、跑实验、出报告、改代码的全流程，&lt;70 名研究员可支撑每月 1万-2万次实验迭代，并将单模型上线周期压缩至 5-8 周。这标志着行业竞争壁垒已从“单次训练能力”下沉至“稳定、可复现、高速迭代的算力与数据流水线”。
2. **能力跃迁路径：小模型潜能与训练机制重构**
   - **结构效率优先**：Laguna S 凭借 MoE 架构实现极低激活参数下的高基准表现，证明更小/更精调的模型足以处理大量知识工作。单纯依赖 Next-Token Prediction 无法充分榨取 Web 数据的隐含知识，蒸馏与交互式环境训练正成为新主流。
   - **训练阶段融合与 RL 前置**：传统 Pre-training 与 RL 的界限正在模糊。RL 将显著前移至 Pre-training/Mid-training 阶段，此时期的微调实质是“早期课程学习（Curriculum Design）”。此外，**低精度训练、通信网络瓶颈优化、以及强化“持久性、验证与回溯（Backtracking）”机制**，比单纯追求“原始智力/参数规模”更能决定模型上限。
3. **产业生态观：开源对抗寡头，高能动性重塑组织**
   - **反内卷的开源战略**：Kant 强烈反对全球仅存 3-5 家闭源巨头的“反乌托邦”路径，认为只有百家齐鸣的基础模型生态才能保障地缘政治与企业层面的选择权与安全性。开放权重（Open Weights）仅是起点，共享实验数据、失败经验与架构决策的“开源研究（Open Research）”才是真正推高行业水位的关键。
   - **全球化人才与抗脆弱文化**：刻意避开硅谷薪资战，采取全球分布式招聘（欧洲、拉美、亚洲等）+ 强工程文化驱动，构建了极强的组织韧性。在经济性上，最终的大规模训练往往是“水到渠成”的；真正的杠杆在于数据清洗效率与计算利用率。面对监管风险，单边安全主义无效，开放竞争与技术扩散才是避免双寡头锁定、维持创新活力的唯一解。
