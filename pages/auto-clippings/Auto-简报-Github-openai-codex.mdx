### 核心总结
- Codex CLI 是 OpenAI 推出的本地运行编码代理，可在终端中使用。
- 支持多种安装方式：官方脚本、npm、Homebrew 或 GitHub Releases 二进制文件。
- 可通过 ChatGPT 账户（Plus/Pro/Business/Edu/Enterprise）登录使用，也可使用 API 密钥（需额外设置）。
- 如需 IDE、桌面或云端体验，可安装 IDE 插件、运行 `codex app` 或访问 Codex Web。
