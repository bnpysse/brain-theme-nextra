## 概述

文章围绕 OpenAI 新发布的 **GPT-6 Astra** 展开，作者开篇即点出三个公众关注的焦点：模型性能、**循环 Transformer / 递归深度** 架构，以及 Astra 是否“隐藏”思维链（chain of thought）的传闻。作者先给出了对 Astra 的实测印象与基准分析，随后预告将详细解释“循环 Transformer”是什么，以及它是否与隐藏推理有关，并介绍近期相关研究。

## 关键要点

### 1. GPT-6 Astra 总体印象
- 作者认为 Astra 是 **迄今用过的最佳模型**，尤其在 **3D 渲染与动画任务** 上表现突出，远超其他模型。
- 相对前代 GPT-5.6，Astra 在写作、数学、编程等几乎所有类别都有提升，但 **图形演示能力提升最为显著**。
- 基准亮点：**ARC-AGI-3 得分 99.9%**，而 GPT-5.6 Sol 仅 7.8%，体现强大的逻辑推理与泛化能力。
- 作者强调，数学、编程和计算机使用等更贴近实际应用的基准更具参考价值。

### 2. 独立基准与评测框架
- **Artificial Analysis Coding Agent Index v1.4** 显示 Astra 处于前沿，但并未大幅甩开竞争对手；综合性的 **Artificial Analysis Intelligence Index** 也呈现类似结论。
- 独立基准相对开发商自评基准**更可信**，但评测 harness 的差异会影响结果：
  - GDPval-AA、AA-Briefcase 使用开源 **Stirrup** harness；
  - Terminal-Bench v2.1 使用 **Terminus 2**；
  - τ³-Banking 使用 **τ-Bench** harness。
- 共享 harness 利于公平比较，但模型训练通常围绕某一 **主要 harness** 调优，因此某些 agentic 评估可能 **低估** Astra 在其主 harness 上的真实能力，需要跨 harness 对比同一任务来验证。

### 3. 对指令文件的建议
- 作者同事（及 Claude Code 负责人）建议：**删除或归档部分旧的 `AGENTS.md` 和 `SKILL.md` 文件**。
- 原因：新一代 LLM 理解提示的能力更强，旧的、过于详细的指令可能**限制模型发挥**，反而产生更差方案。
- 并非完全弃用这类文件，而是部分工作流无需过度描述；旧描述可能已过时，应**更新或重新生成**。

### 4. 计算机使用能力
- Astra 在 **图像与渲染任务** 上尤其强大，并能通过 Codex/ChatGPT 应用 **操作本地软件**（computer use）。
- 图形类演示在社交媒体上直观且受欢迎，例如 **Blender 渲染纽约市**、**虚拟看房**。
- 作者用浏览器版 MS Paint 测试：让 Astra Medium 和 High 使用鼠标重绘作者照片，既展现艺术能力，也体现工具操作能力（未使用 Extra High/Max 以节省 token）。

## 分析与洞察

- **差异化优势**：Astra 的核心亮点并非在所有维度碾压对手，而是在 **3D 渲染、动画、GUI 操作** 等视觉与代理能力上明显领先。这可能成为 OpenAI 吸引创意工作者、自动化用户的关键卖点。
- **评测可信度与偏差**：独立基准虽更客观，但 **评测 harness 的差异** 会造成偏差。评估新模型时应关注其主 harness 与独立 harness 的分数差异，避免单一分数导致误判。
- **指令工程动态**：随着模型能力提升，静态的 `AGENTS.md`/`SKILL.md` 指令可能从“帮助”变为“束缚”，团队需定期审查、简化或重新生成这些文件。
- **隐藏推理传闻**：文章开篇提到 Astra 被传“隐藏”思维链，但截至已提供内容未见展开。这一话题涉及模型透明度、安全性与用户体验，是后续关注重点。
