【文章标题】：12天下载量超ChatGPT的Muse，字节阿里谁能先跟上？

【文章正文】：
出品｜虎嗅科技组

作者｜苗正卿

题图｜视觉中国

在 9 月 22 日～9 月 24 日杭州云栖大会期间，我见了多位 AI 创业者、投资人，Meta 的 Muse 无疑是那几天最热门的词。

大家关注的焦点集中在四个方向：

大厂人士和 AI 从业者的议题普遍围绕两个方向：

・一个确定性：Personal Agent 是接下来最具确定性的方向，也是一个比 AI 办公更广阔的市场。

・一个狐疑：大厂或 AI 创业者，照搬 “Meta 的 Muse” 去做产品，可能会走不通。

硬件从业者，普遍关心另外两个议题：

・Meta 发布的钥匙扣等新形态，能不能带火新品类，这会不会让 “挂饰、挂件” 这个品类在未来几个月热度更高一些？要不要尽快跟进？

・集成在眼镜上的 Personal Agent 看似是一个非常好的硬件入口，但在国内生态复杂，到底该如何走通这件事？

让我们先把时间拨回早些时候。

在 9 月 23 日的 2026 年 Meta Connect 开发者大会上，Meta 公布了 Muse 的多项更新，其中最让中国 AI 从业者瞩目的有以下几点：

・进行了针对 Mac 电脑的 Muse 升级，在升级并获得权限后，Muse 可以操作用户的 Mac 电脑，不仅能调用电脑上的 App，还能在后台持续执行任务。

・Muse 将拥有独立的专属邮箱账号，可直接加入用户的邮件线程，自动处理往来邮件、梳理内容，并基于邮件触发后续任务；同时支持绑定用户的个人邮箱进行统一管理。

・通过大量新的连接器，渗透到各种场景，包括电商、本地生活、支付、社交等第三方平台、App。

以上三点，可以总结为 “Personal Agent” 方向的升级。

・发布了 Muse Charm 挂件：可以理解为新形态的 AI 硬件，这些硬件的形态类似钥匙扣，内置 Muse，用户可以通过语音与挂件实时交互。

・宣布 Muse 未来几个月全面接入 Meta 旗下所有的智能眼镜，并能够通过眼镜完成物品的视觉识别、购买等功能。

以上两点，可以总结为 “AI 硬件” 方向的升级。

这些升级，是 9 月 8 日 Meta 正式发布 Muse 后的延续动作。如果说此前 OpenClaw 等开源项目在开发者圈子带火了 Agent 技术概念，Muse 则第一次把 Personal Agent 推向了大众消费市场，引发了全行业的普及热潮。

我觉得有必要先界定一下，到底什么是当下硅谷和国内热议的 Personal Agent，因为在 Muse 火了之后，一些尚未达到 Personal Agent 标准的产品也开始强调相关概念，寻求市场关注度。

实际上，我们目前市面上的 Agent 可以简单分为四类：

・对话式的基础 Agent：随着各个产品的进化，已经逐渐变少了。比如你在 ChatBot 里面查询一张机票，它只是给你推荐和几个选择，并不会帮助你完成后续比价、下单，需要你自己操作。

・Copilot 型 Agent：常见于一些 App 里，比如你打开一个出行 App，基于 Agent 功能，它能够自动帮你填写好信息，甚至帮助你比价，但它并不会帮助你完成下单。

・调用型 Agent：这是目前国内最常见的解决方式。一个 Agent 产品，当你告诉它需求后，它会调用第三方的 API，然后给出你几个最佳选项，它可以帮助你下单，但每一步都会寻求你确认。

・Personal Agent：委托式执行代理。用户只需要提出目标与边界，它会自主拆解步骤、调用工具、处理异常，全程完成完整事务并对结果负责；它并不是只依赖预置 API，而是在安全运行环境中像 “真实用户” 一样去完成查阅、评估、下单，也不需要你一步步确认，只是最后付款这一步需要你确认。进阶形态可基于用户画像主动预判需求。

不难看出，实现 Personal Agent 的一个关键前提是，它能够拿到你大量授权，且对你非常了解。

我自创了一个概念，

Personal Agent 本质上已经接近于你的 “虚拟人格” 了

。

我和一个阿里技术高P 在杭州交流，他说 Personal Agent 进一步进化，通过海量上下文，可以非常清晰地预判用户的潜在需求。

在行业的畅想中，未来成熟的 Personal Agent 可以做到：比如你的 Personal Agent 发现你最近半年喜欢某动 Kpop 组合（

你经常在音乐平台听该组合新曲，并在电商平台多次查询购买相关周边

），Personal Agent 又发现你这几个月拿到了一笔不错的额外奖金，此时 Personal Agent 发现几周后在首尔该组合有 20 周年全球演唱会。

这个时候 Personal Agent 会主动询问你是否要规划一个高性价比的两天一夜首尔之旅。当你对它的方案感兴趣后，它并不需要你再提供各种信息 —— 你早已授权给它你的基础信息，它对你的订票、订酒店、行程喜好也了如指掌 —— 几分钟后，它会给你一个完整的方案、报价，只需要你确认付款。

引申出的潜在机会是：在 AI 时代，每个用户会更喜欢和 AI 交流，AI 可能会比你所有朋友更理解 “真实的用户人格”，当它拥有你完整的信息、权限后，它会像你的 “赛博分身”“虚拟人格” 一样，去主动帮你消费 —— 那些你真实肉身没来得及留意的需求和消费，可能在 Personal Agent 时代被 “面面俱到” 地覆盖。

这意味着巨大的市场。

从数据上，可以感受到这股热潮的烈度。

截至 9 月 24 日，来自 Apptopia 等渠道统计显示，Muse 自发布后迅速登顶各大应用榜下载量第一，并稳居美国 App Store、Google Play 免费应用总榜第一位，此前长时间锁定这两个榜单第一名的是 ChatGPT。

Apptopia 统计显示，上线前 12 天美加市场累计安装量约 280 万次，而同口径下 2023 年 ChatGPT 移动端同期仅为 130 万次。

这也推动了 Meta 股价上升，截至 9 月 24 日，Meta 收盘价为 777.59 美元，这是 2025 年 9 月以来的最高峰。9 月以来（

截至 9 月 24 日

）Meta 累计涨幅已达 36%，Muse 的产品爆火是其中最核心的驱动因素。

这是国内多个互联网大厂梦寐以求的时刻：推出了一款出圈的 AI 超级产品，并通过 AI 叙事成功拉动股价高涨。

但我要先泼一盆冷水：

Meta 的路，国内的大厂和创业公司，并不能直接复制

。

在硅谷，Meta、OpenAI、微软、谷歌都在过去一年布局 Personal Agent 类产品，诸如 Instinct AI、MultiOn 等创业型公司也在这个领域迅速崛起。

但这类产品，有非常浓郁的 “美式 Agent 特征”。以 Muse 为例，它有两个非常典型的特点：

・云端运行环境中的浏览器是重要 “基座”：它通过安全运行环境内置的浏览器去替用户打开第三方网页、处理邮件。因为美国大部分 App 都有功能完整的网页版，加上反垄断监管环境下，平台普遍不敢随意限制第三方浏览器的正常访问，这就让 Muse 可以通过这种方式，登录用户大部分 App 的网页端完成任务执行 —— 这和国内的生态是本质区别。

・连接器是构建生态的解决方案：通过连接器，嵌入到更多的第三方电商、社交场景里，而非在某一个固定生态内长出 Personal Agent—— 这和目前大厂的 “闭环” 逻辑并不相同。

此外，Meta 还有一个独特优势：它的社交流量。

目前 Muse 已经嵌入到了 Meta 生态内的 WhatsApp、Messenger、Instagram，用户可以在社交聊天窗口直接调用，不用单独下载 App。社交生态带给 Muse 的另一个优势是天然的用户使用场景与交互习惯，用户可以在熟悉的聊天界面直接发起任务，大幅降低使用门槛。

我的预判是，

Personal Agent 在年内就会成为几个互联网大厂新的 “战略级方向”，但最终的呈现路径会和 Meta 的 Muse 有巨大差异化

。

我个人感觉，在 Personal Agent 这件事上，腾讯的先机优势很明显：

・腾讯目前灰度测试的微信 “小微” 是一个很好的思路 —— 它没有选择沉迷于打造一个新的 App 入口，而是选择嵌入到既有的产品里，这和 Meta 的 Muse 方式很像。

・Meta 目前的社交流量，给 Muse 带来海量引流，这会不会是腾讯也能复制的事情？起码在办公智能体赛道，腾讯的 WorkBuddy 已经验证了独立产品的增长路径。

・腾讯的生态其实是完整的，它如果想搭建一个类似 Muse 通过连接器实现的 “消费生态”，腾讯投资了京东、美团等头部消费平台，具备生态协同的潜在基础。

但这里面的考验，可能是用户隐私以及权限。Meta 在这件事上走得非常谨慎，它采用了给每个用户匹配一个 “单用户 VM” 模式，这其实是一种 “单租户逻辑隔离” 设计，给每个用户分配一台独立的专属云端虚拟机，相当于每人一间独立的 “数字办公室”。

这个模式，考验的是算力成本 —— 如果想走通这条路，需要该厂商有雄厚的算力基础能力，并且能够通过规模化实现 “单用户降本”。

我还有另一个判断，在硅谷，Personal Agent 其实是一场 “全新战争”，它不是 AI 办公大战的延续。

但在国内

，Personal Agent 大概率会成为大厂之间 “AI 办公大战” 的延续

—— 但这可能是一种最坏的走向。我的意思是，剧情可能会变成，各大厂让 AI 办公团队、产品，扩展到 Personal Agent 方向继续作战。

实际上，Personal Agent 和 AI 办公，是完全不同的两类产品，甚至可以说是两件事。Personal Agent 所承载的激情、想象空间，也不是 AI 办公能比拟的。

Personal Agent 会形成一种基于用户个人的 “数据闭环”——AI 充分了解用户的完整信息、权限，深度参与生活和消费 “决策”，这些轨迹会成为新的数据，反哺 AI，进一步强化 AI 对个人的理解，最终完成 “虚拟人格” 的打造。

这也是为什么这段时间，硅谷和国内很多从业者认为 Personal Agent 是 Agent to Agent 的必经之路，也最终是通往个人超级智能（

Personal Super Intelligence, PSI

）的必经之路。

Personal Agent 势必会带来另一个机会：大量面向 Agent 的产品，比如目前国内很热的无头浏览器、Agent 专用运行环境，这些产品的服务对象不再是人，而是 AI Agent，是 Personal Agent 时代的 “原子工具”。
