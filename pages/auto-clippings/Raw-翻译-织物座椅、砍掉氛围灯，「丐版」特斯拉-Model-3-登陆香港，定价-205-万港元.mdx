【文章标题】：织物座椅、砍掉氛围灯，「丐版」特斯拉 Model 3 登陆香港，定价 20.5 万港元

【文章正文】：
8 月 30 日，特斯拉在中国香港和中国澳门上架了一款更便宜的 Model 3，香港起售价 20.5 万港元（约 17.6 万人民币），澳门起售价 25.2 万澳门元。原本的后驱标准版 Model 3 如今被称为「Model 3 Premium 后轮驱动版」，相当于被动升了一级。

相比两地的 Model 3 Premium 后轮驱动版，新车分别便宜 1.91 万港元和 2.6 万澳门元。

其实更便宜的平价版本 Model 3 并不是新鲜事，去年 10 月，特斯拉便在美国推出过类似的入门版本，后来又陆续带到欧洲、韩国等市场，如今它也来到了港澳地区。

除了这款平价版 Model 3，特斯拉还在北美推出了平价版 Model Y，前脸去掉了贯穿式大灯。而相比之下，平价版 Model 3在外观上并没有太大变化，除了轮毂之外，你很难看出和更高级版本的差异，这对于打算入手的消费者来说可能是一件好事。

值得一提的是，从特斯拉的车型数据看，这款平价版 Model 3 由上海超级工厂生产，香港和澳门页面显示的工厂代码均为「GF03」。既然已经在上海投产，未来顺势引入内地市场，也并非没有可能。

砍了面子，留了底子

香港版的平价 Model 3 只提供神秘灰、珍珠白和星钻黑三种车漆，其中后两种各需加价 9600 港元，车轮也只有带全封闭轮毂盖的 18 英寸「Prismata」这一种选择。

作为对照，贵 1.91 万港元的 Premium 后驱版提供六种车漆，且均为免费选择（这一点与内地版本不同），轮毂方面则有 18 英寸 Photon 和 19 英寸 Nova 车轮可选。

来到车内，映入眼帘的是前排的织布座椅，相比高配版本，织布座椅取消了座椅通风，但仍保留了座椅加热。方向盘同样保留加热功能，但由电调改为手调，音响则缩减为 7 个扬声器，本就仅有点缀作用的氛围灯也被直接砍掉，甚至前排的杯托盖板也被减配。

而在后排，8 英寸的触控屏也被取消，取而代之的是手动出风口。不过考虑到这个后排屏幕本身的用处并不大，减配了说不定还能省点电。

平价版 Model 3 采用单电机后驱，0—100km/h 加速为 6.2 秒，最高时速 201km。超级充电峰值为 175kW，低于 Premium 后驱版的 225kW，官方给出的补能数据是充电 15 分钟增加最多 286km。

其他部分基本保持原样，15.4 英寸中控屏、基础版 Autopilot、主动安全功能等等均得到保留，特斯拉的精准刀法砍掉了这台车上的不少舒适性配置，但依然保留了这台车的核心，即特斯拉一直引以为傲的软件和安全。

过去几年，特斯拉已经无数次证明，调整价格比调整产品更快，市场需要刺激，就改动官网上的价格。已经交付的车通过 OTA 继续更新，生产线上则尽量维持少版本、低复杂度。

值得肯定的是，特斯拉没有在核心计算硬件上动刀：这款平价版 Model 3 依然保留 HW4.0 智驾硬件和 AMD Ryzen 座舱芯片，这也意味着这台新车依然能在软件能力上保持与其他车型一致，而软件升级和付费也是特斯拉一直以来的「算盘」。

特斯拉一直以来的售卖逻辑，都是先降低一次性购车门槛，让更多车辆搭载并接入这套软件，再通过选装和订阅，从其中一部分用户身上获得持续收入。尽管港澳地区尚未支持 FSD，但对特斯拉而言，每多卖出一辆保留软件升级能力的 Model 3，便多了一个以后可以收费的入口。

给硬件做减法，给软件做加法。只要软件能力和后续付费空间还在，织物座椅、7 个扬声器等等带来的体验落差，在特斯拉看来就能被软件价值填平，这款车依然卖得出去。

不过，价格门槛下移可以换来更多用户，也会改变人们对特斯拉的判断和印象，本就被诟病「毛坯」的极简内饰进一步减配，特斯拉的「科技豪华」属性扮演起来可就更难了。

国产向上，特斯拉向下

内地 Model 3 后轮驱动版 23.55 万起，CLTC 续航 634km。港澳平价版 Model 3 折合人民币约 17.6 万，比内地便宜近 6 万。如果这台新车按港澳的定价逻辑折算进入中国内地，很多人预估定价会落在十几万的范围。

2025 年 12 月 31 日的工信部减免车辆购置税目录里出现过一款「Model 3 标准续航升级版」，52.9kWh 电池、CLTC 续航 480km，不过特斯拉此前曾经表示过「暂无引入中国市场计划」。

但即便这台平价版 Model 3 真的入华，下探到十几万的它，也会撞到中国品牌密度最高的价格带。从小鹏、乐道到比亚迪，中国市场上并不缺既有智驾能力，又有完整的内饰和座舱的车型。同样的钱，国产车给得更多。

此外，特斯拉目前最大的问题，是 FSD 在中国内地和港澳地区的缺位，软件收不上钱，平价版 Model 3 在中国剩下的，就只有一张被削过的配置表。

定价同样是个两难，定得过高，同价位国产车配置全面占优，而如果价格偏低，压缩特斯拉本就承压的毛利会进一步被压缩。可以说，平价版 Model 3 的价值在于它验证了特斯拉的全球低价策略，但中国恰好是最不买账的那个市场。

不过话又说回来，特斯拉作为全球头部车企的规模与经营韧性、Model 3 依然出色的机械素质，以及独有的超级充电网络，仍足以让这台平价版找到自己的消费人群。
