# 美国军方禁用设备广告追踪功能：精华简报

**来源：** Solidot / Slashdot  
**原文链接：** https://www.solidot.org/story?sid=85318

## 1. TL;DR

美国军方正在系统性禁用设备上的广告追踪功能，原因是商业广告追踪数据已被对手利用，用于锁定驻扎在中东的美军人员位置。据披露，Windows PC 上的广告 ID 早在 2021 年之前已被禁用，而 Android 与苹果移动设备上的广告 ID 则“至少从 2026 年 2 月起”默认禁用。此外，美国军方还在考虑对手机使用实施更严格的限制。这意味着，原本面向营销归因的广告标识符，已实质成为可被低成本武器化的情报获取渠道。

## 2. 核心观点与技术/商业洞察

### 2.1 广告 ID 从营销工具升级为国家安全攻击面

广告 ID（如 Google 的 GAID、苹果的 IDFA）设计的初衷是用于广告归因、频控和用户画像，通常被视为“非直接个人身份信息”。但现实是，应用内广告 SDK 会将广告 ID 与位置、IP、设备型号、使用行为等数据一并回传，数据经纪商再将这些碎片聚合为高精度轨迹。对手无需入侵军方系统，只要从公开或灰色渠道购买商业位置数据，即可实现对敏感目标的识别与追踪。这是典型的“合法数据获取、非法情报用途”问题。

### 2.2 桌面端与移动端的政策时差暴露出治理难度差异

美国陆军声明显示，Windows PC 的广告 ID 在 2021 年前就已经被禁用，但移动端直到 2026 年 2 月才默认禁用。这一时间差反映出几点：

- **移动设备管理更分散**：军人个人手机、BYOD 场景较多，设备归属与策略执行比政府统一配发的 PC 更复杂。
- **移动广告生态阻力更大**：广告 ID 是移动广告产业的核心基础设施，平台和开发者长期依赖，军方级禁用需要与 OS 厂商、MDM/EMM 供应商协调。
- **默认开启机制难以绕过**：移动系统层面广告 ID 默认开启，企业策略若无法深入系统设置，就难以真正关闭。

### 2.3 禁令只能缓解，不能根除位置泄露风险

禁用广告 ID 是必要的一步，但并非充分条件。移动设备仍会通过 IP 地址、Wi-Fi、蓝牙、基站信号、应用后台定位等多种方式泄露位置。美国军方考虑“更严格手机限制”，说明其已认识到广告 ID 只是最易于识别和利用的标识符之一。真正的问题在于：在部署环境中，消费级手机本身就是一个不可控的传感器与信标。

### 2.4 匿名化的承诺正在失效

广告行业长期以“可重置、非持久、非个人身份”为理由，弱化广告 ID 的隐私风险。然而，跨数据集关联分析证明，广告 ID 配合位置和时间特征可以稳定重识别个体。美国军方的禁令从国家利益角度证实：所谓的匿名标识符，在高风险场景下已不具备足够的隐私保护能力。

## 3. 行业启发与影响

### 3.1 数据经纪与位置数据产业将面临更严格审查

商业位置数据的买方不再是单纯的营销公司，还可能包括情报机构、武装组织和其他非国家行为体。美国军方此次动作会进一步推动对数据经纪商的监管，尤其是禁止向外国对手出售美国公民或军事人员位置数据。数据经纪商可能被迫建立更严格的买方审查、数据脱敏和用途限制机制，否则将面临国家安全层面的法律与合同风险。

### 3.2 移动广告生态面临“去广告 ID”的结构性压力

军方、政府等安全敏感客户率先禁用广告 ID，会形成示范效应。若更多企业、机构跟进，广告平台将面临更大压力：基于广告 ID 的个性化投放和归因能力进一步削弱。这客观上会加速上下文广告、隐私沙盒、聚合归因、差分隐私等替代方案的发展。对苹果和谷歌而言，广告 ID 的“安全漏洞”属性可能促使其在未来版本中默认关闭或提供更严格的系统级管控。

### 3.3 企业移动管理与安全基线升级

广告 ID 禁用正在从“隐私选项”升级为“安全基线”。MDM/EMM、移动威胁防御（MTD）和统一终端管理（UEM）供应商需要提供细粒度的广告 ID 关闭能力，并将应用内位置共享、广告 SDK 行为纳入检测范围。政府、国防、能源、金融等高安全行业会重新评估 BYOD 政策，甚至转向更封闭的受控设备方案。

### 3.4 国防与作战安全面临开源情报防御挑战

本次事件说明，对手获取高价值位置情报的成本远低于传统侦察手段。商业数据已成为一种“接近武器级”的开源情报来源。军方未来不仅要加强设备管控，还需要在人员训练、行动安全、数据供应链审查、公开数据采购监控等方面建立防御体系。专用安全手机、通信隔离设备以及在部署区域限制消费电子产品的需求将上升。

### 3.5 法律与政策可能加速收紧

美国已有针对“防止外国对手获取美国人敏感数据”的行政与立法动向。军方因广告追踪数据而遭定位的案例，很可能成为推动更严格数据销售限制、位置数据出口管制、以及禁止政府部门设备启用广告 ID 的政策依据。长期来看，商业数据的国家安全属性将越来越受到立法者重视。

**结论：** 美国军方禁用广告追踪功能，表面上是设备策略调整，实质上是商业数据武器化、广告标识符崩坏与移动安全治理滞后三重问题的集中暴露。它将不仅改变军方设备管理，也可能成为全球隐私合规、广告科技与移动安全行业的一个重要转折点。
