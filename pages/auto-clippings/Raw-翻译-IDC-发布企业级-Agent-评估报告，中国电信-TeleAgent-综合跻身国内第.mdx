【文章标题】：IDC 发布企业级 Agent 评估报告，中国电信 TeleAgent 综合跻身国内第一梯队

【文章正文】：
近日，国际数据公司（IDC）发布《中国企业级通用 Agent 产品技术评估》报告，对国内多款主流通用智能体产品开展标准化实测。中国电信星辰超级智能体 TeleAgent 综合得分 6.85 分，成本效率、安全可控、任务表现等多个维度高于行业普遍水平，面向高频办公场景的常规任务能力进入国内第一梯队。

本次评估在统一的仿真测试环境中进行，覆盖任务表现、成本效率、交互体验、安全可控、生态开放性等九大维度，并加入脏数据、权限约束、模糊指令等真实工作中常见的干扰条件。测评显示，TeleAgent 在 Token 消耗方面优于同类产品。对于需要高频调用、规模化部署智能体的企业而言，这意味着使用成本有望进一步降低。

支撑 TeleAgent 的，是中国电信在算力、平台、数据、模型和应用上的全栈布局。中电信人工智能公司依托这一体系，连接基础研究、工程研发与产品落地。其中，星辰通用人工智能实验室基于国产算力和国产框架，自主完成了十亿、百亿、千亿参数语义基础大模型的预训练和后训练，并将模型开源。据中国电信介绍，相关模型在 Hugging Face 等主流开源社区的总下载量已突破百万，实验室也已助力多家央企建设行业基座大模型。在模型能力上，星辰大模型覆盖多种尺寸，支持端、边、云协同，并融合语义、语音、图像、视频四类模态。在此基础上，TeleAgent 围绕基础模型、执行框架、技能记忆、资产通信构建安全防护策略，并经过多轮安全测评，应对智能体执行任务时可能出现的越权、误操作和数据泄露等风险。

这些底层能力最终需要落到具体的办公任务中。TeleAgent 围绕「写、查、数、管」四类能力，将自然语言指令转化为可执行的办公业务操作。目前，产品已完成 Windows、macOS 及 Linux 信创环境的多终端适配，取得银河麒麟、统信 UOS 官方兼容性认证，面向个人和政企用户提供服务。据中国电信披露，TeleAgent 自发布以来注册用户已突破 120 万，Skill 技能数量从数千个扩展至 5 万余个。IDC 调研显示，国内近半数企业用户已经涉足通用 Agent 选型，智能体也正从对话问答工具，转向能够自主拆解任务、调用工具并完成作业的新型办公入口。随着企业开始将 Agent 接入实际业务，复杂任务能否稳定交付、能否对接现有系统，以及权限治理和运行过程能否有效管理，将成为包括 TeleAgent 在内的智能体产品需要持续回答的问题。
