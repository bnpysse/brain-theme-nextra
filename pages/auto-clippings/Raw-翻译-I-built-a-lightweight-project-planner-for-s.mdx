【帖子标题】：I built a lightweight project planner for solo developers in Cursor

【帖子正文】：

When you’re building a project on your own, keeping track of what to do next shouldn’t require a separate project management tool.

I built

Plan: .pln Editor

, an extension that lets you manage project plans directly in your editor, including Cursor.

Organize tasks and nested subtasks

Track progress with Todo, In Progress, and Done statuses

Keep your plans alongside your code in simple

.pln

files

Edit plans through a visual editor while keeping existing file formatting intact

The idea is to keep project planning close to the code, without the overhead of a separate tool.

I’d love feedback from solo developers and indie hackers. How do you currently organize your projects?
