【文章标题】：Google Has Removed MV2 Extensions from the Chrome Web Store, Including UBO  
【文章标题】：谷歌已从Chrome应用商店移除MV2扩展程序 包括uBlock Origin  

【文章正文】：  
Google today reached the final milestone in a browser-extension transition that has been years in the making, all remaining Manifest V2 extensions were removed from the Chrome Web Store. Among them is uBlock Origin, one of the most capable and widely respected content blockers ever built for the web.  
谷歌今日完成了历时数年的浏览器扩展程序转型最终阶段，所有剩余的Manifest V2扩展程序均已从Chrome应用商店下架。其中包括被誉为最强效、最受推崇的网页内容拦截器uBlock Origin。  

Google also noted that, "Manifest V2 extensions installed on Chrome 138 or earlier will remain installed, but will be unable to receive any updates and cannot be reinstalled from the Chrome Web Store once removed from Chrome.".  
谷歌同时声明："已安装在Chrome 138及更早版本的Manifest V2扩展程序会保留运行，但无法接收更新，且从浏览器移除后无法通过Chrome应用商店重新安装"。  

Moreover, Chrome Web Store (CWS) team has informed the affected extension developers regarding this removal action.  
此外，Chrome应用商店团队已就此次下架行动通知受影响的扩展程序开发者。  

Removal Affects More Than Google Chrome  
下架影响不仅限于谷歌Chrome  

It is important to note that the Chrome Web Store is the dominant extension marketplace for Chromium-based browsers. Users of non-Chrome Chromium browsers, including Brave, also rely on the CWS to discover and install extensions.  
需注意的是，Chrome应用商店是Chromium内核浏览器的主要扩展市场。包括Brave在内的非Chrome系Chromium浏览器用户同样依赖该平台发现和安装扩展程序。  

As a result, the removal has consequences beyond Google Chrome. Users can no longer find or install these Manifest V2 extensions through the Chrome Web Store, even if the Chromium-based browser they use continues to support Manifest V2.  
因此此次下架的影响远超谷歌Chrome本身。即使用户使用的Chromium内核浏览器仍支持Manifest V2，也无法再通过Chrome应用商店查找或安装这些扩展程序。  

Brave Keeps Select Manifest V2 Extensions Alive  
Brave浏览器保留部分Manifest V2扩展  

Brave browser team has decided to host four popular MV2 extensions on its own backend, and let users easily enable them in their browser installation. These extensions are AdGuard, uBlock Origin, uMatrix, and NoScript.  
Brave浏览器团队决定自主托管四款热门MV2扩展程序，允许用户轻松启用。这些扩展包括AdGuard、uBlock Origin、uMatrix和NoScript。  

Google’s argument for Manifest V3 is straightforward. The company says the newer extension platform, MV3, provides stronger security, privacy, performance, and tighter control over what extensions are allowed to do. Considering how much access browser extensions can have to a user’s browsing activity, those are legitimate problems to solve.  
谷歌对Manifest V3的立场很明确。该公司表示新版扩展平台MV3能提供更强的安全性、隐私保护、性能表现，并对扩展程序权限实施更严格管控。考虑到浏览器扩展可获取用户浏览活动的深度权限，这些确实是需要解决的合理问题。
