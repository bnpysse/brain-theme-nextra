【文章标题】：怀旧手记｜25 年前的笔记本，如何兼顾轻薄、时尚与性能？

【文章正文】：
Matrix 首页推荐
Matrix 是少数派的写作社区，我们主张分享真实的产品体验，有实用价值的经验与思考。我们会不定期挑选 Matrix 最优质的文章，展示来自用户的最真实的体验和观点。
文章代表作者个人观点，少数派仅对标题和排版略作修改。
如果你问我一台「标准」的办公笔记本应该是什么样的？我可能会说「机身轻薄，外观简约时尚，性能还不能差。」但在「轻薄」几乎已经是办公本标配的当下回看 25 年前，2001 年的「标准」办公本是什么样的？
IBM 在那一年发布了 ThinkPad X 系列的最新款 X22，配备 12.1 英寸 TFT 液晶显示屏（分辨率为 1024x768）搭载的是当时便携笔记本当中性能相对强悍的 Intel Pentium III-M 733MHz/800MHz 处理器。但即便是兼顾便携办公的 X 系列，ThinkPad X22 的重量也有 1.6~1.7kg。
所以回到标题那个问题：25 年前的笔记本，如何做到轻薄时尚又兼顾性能？索尼给出的答案是，在兼顾以上所说的要素的同时，将笔记本大小做到便于携带的 B5 尺寸，同时笔记本整体含电池的重量控制在 1.26kg 左右。
25 年前的索尼 VAIO SRX
本期《怀旧手记》为大家带来的是索尼于 2001 年底发布的 VAIO PCG-SRX 笔记本电脑。
2001 年底，索尼发布了 SR 系列的后续型号 SRX。这并不是一次型号命名的简单升级，而是一次全面的型号更替：SRX 在设计、功能与定位都跟前代 SR 系列有着明显不同，具体到我手上的这一台，型号则是 PCG-SRX7。
根据索尼官网现存有关 PCG-SRX 系列的介绍，可以得知 SRX 系列首批设备在 2001 年 11 月上市，并且日本本土一共提供了三款型号：
- PCG-SRX3（标配款）：CPU 使用 Intel Celeron 650MHz，配备 128MB 运存和 20GB 硬盘，支持 2.4GHz 频段 Wi-Fi，搭载 Windows XP Home Edition
- PCG-SRX3/BD（标配小改款）：这一款型号硬件配置和SRX3完全相同，唯一不同的地方是电脑额外搭配一台CD-RW/DVD-ROM的光驱（非内置）
- PCG-SRX7（高配款）：CPU 使用 Intel Pentium III-M 800MHz，配备 128MB 运存和 30GB 硬盘，支持 2.4GHz 频段 Wi-Fi，高配款额外支持蓝牙（内置），搭载 Windows XP Home Edition，并没有额外搭配光驱
从官网所展示的三款主力型号，可以发现 SRX 系列对应不同价格有着不同程度的减配。虽说在 2001 年就已经实现了机身内置 2.4GHz 频段 Wi-Fi，但只有高配款 SRX7 才会额外搭载蓝牙。
机器外观
回到我这一台机器上，刚到手时机器的外观成色非常新。已经 20 余年的机器外观没有明显划痕，内部键盘也没有明显使用痕迹。
根据我的观察，同型号机器在不同程度使用、存放后，或多或少都会出现 A 面亮银色涂层脱落的情况。好在我这台机器目前没有遇到。机器整体外观部分，A 面采用亮银色涂层，B 面和 C 面则是索尼当年最标志性的蓝紫色；笔记本尺寸很小，大约只有 B5 纸张的尺寸。
机身尺寸在做到足够小、便于携带的同时，屏幕大小也仅有 10.4 英寸。在这块 10.4 英寸屏幕上，索尼也有一些很有意思的设计：笔记本屏幕并没有做到边框四边等宽，而是有意设计成两边宽、上下窄。因为对称，肉眼观感十分协调。
虽然机身尺寸紧凑，键盘布局却并未过度缩水，打字反馈依然清脆。只不过经历了 20 多年的岁月侵蚀，键盘中框架构出现了轻微老化，用力按压局部键帽时，整片区域会随之产生小幅度的下塌。
键盘下方的蓝紫色掌托上，索尼还藏了一个非常漂亮的设计：掌托位置使用了半透明聚碳酸酯材质，电源指示灯和硬盘读写指示灯的光会透过掌托散发出来。
在暗光环境下，你能看到掌托上亮起微弱的蓝紫色光芒，既有科技感又很精致。这个设计在当年就引起了不少用户的讨论，也是 SRX 外观上很有辨识度的一处细节。
在掌托的中央，还能看到一个类似圆形的触摸板。VAIO SRX 系列并没有像我们之前介绍的 C1 系列那样使用指点杆，而是配备了一块圆形的 SmartPad 触摸板，这也是当时 SR/SRX 系列外观的一大特点。
在触摸板的下方，你还能看到一个类似于现在鼠标滚轮的部分。这个就是千禧年间索尼在诸多笔记本系列当中使用的 Jog Dial（飞梭旋钮）——别小看这一个小小的旋钮，它除了可以像鼠标上旋钮一样滚动页面，还通过索尼的驱动深度集成到了系统当中。具体的使用场景和方式会在下文的软件体验部分详细展开。
翻到笔记本背面，我们可以看到可拆卸电池以及散热风扇的出风口，还有左下角硬盘位置的快拆设计。这里值得一提的是，SRX 系列搭载了索尼专门为小机身开发的「卡斯卡德冷却单元（カスケードクーリングユニット）」。
这套散热系统采用了极薄的热管，通过优化内部布局，在仅 10.4 英寸的机身里实现了对 Pentium III-M 处理器的有效散热。这也是 SRX 能在 1.26kg 的机身内塞进当时性能相对强悍的处理器的重要原因之一。
虽然是小尺寸、高度集成化的便携笔记本，但只需要使用十字螺丝刀卸下螺丝就可以打开硬盘盖，从而更换硬盘。我这一台笔记本除了机器本体以外，还有配套的原装电源适配器，外观颜色是和笔记本一模一样的。同时在笔记本侧面的 PCMCIA 插槽当中还有一张前任主人留下来的索尼无线网络 PCMCIA 扩展卡。
详细配置
配置方面，前面已经对照官方资料把三款型号的核心参数说清楚了，这里只补充我这台机器上几个具体细节：
- 屏幕：10.4 英寸（1024x768）
- RAM：256MB
- 系统：Windows XP Professional 简体中文版
这个配置跑 Windows XP Professional 倒谈不上卡死，但也别指望能有多流畅。机器刚到手时，系统处于一种近乎「毛坯房」的状态：没有乱七八糟的第三方软件，也没有前任主人留下的照片或文档。这反而省去了我重新刷系统的麻烦。毕竟索尼的笔记本想要安装系统是出了名的困难，在早期的型号上亦是如此。虽然我们并不打算安装原装的 OEM 系统，但是哪怕是原版 Windows XP 系统，想要安装在这台笔记本上也很困难。
这台笔记本为了便携没有内置光驱，虽然配有一个 USB 接口，但是所使用的 BIOS 并不支持通过 USB 启动。这就意味着我们没有办法通过 USB 启动，不能使用 USB 接口的外置光驱或者是 U 盘。
那看到这里你可能会好奇了：当年这台笔记本如果系统坏了，是怎么安装的呢？这里其实就要提到当年的「特殊」配件了。在官方推出的配件当中其实是有外置光驱的，就像我们看到的、三款型号中 SRX3/BD 捆绑外置光驱一样。
根据我查到的资料，这个光驱接口并非 USB，而是当时索尼常用的 i.LINK（IEEE 1394）接口。使用方法也很简单，几乎就和 USB 一样。把光驱的 i.LINK 接口插进笔记本侧面的 i.LINK 接口就行了。
这也是当年索尼官方推荐的使用方式之一，有趣的是，索尼还专门为这个外置光驱搭配了一个很可爱的小架子，通过这个架子你可以把光驱立起来。非常可爱是不是？
补全驱动
回到我这台机器，除了几乎没有使用痕迹，它的「毛坯房」状态在于驱动并不完整。虽然基础驱动都已经打上，分辨率正常，声音也没问题。但我上手的第一时间就已经发现快捷键以及我刚刚提到的飞梭旋钮，这类索尼的特色硬件是完全没办法使用的。
这个情况其实很常见，因为一台完整的索尼 VAIO 笔记本应该是「机器本身的硬件驱动」搭配「索尼专门为笔记本部分软硬件适配的驱动」。如果你想像我一样复刻当年的使用状态，并且功能都不缺失，复刻当年的原厂系统的使用状态，把驱动补全就没问题了。
只是 20 多年前的机器驱动属实不好找。这里分享一个我经常使用的网站 VAIOLibrary，很多复古数码设备，特别是索尼的笔记本，相关的驱动跟资讯几乎都能在这儿找到。
只需要在网页中找到具体的型号，就可以找到详细的驱动以及对应的官方恢复光盘。因为我没有原厂的驱动配件，想要完全恢复系统肯定是不现实的。我们就老老实实的安装驱动吧。
驱动下载完之后，根据整理好的安装顺序，前前后后一共安装了 10 多个驱动，没错，就是这么多，因为除了底层驱动还有必备的软件，而且安装顺序不可前后颠倒，不然的话部分功能会无法激活。
Jog Dial 实测体验
在漫长的驱动补全之后，这台 VAIO 终于回到了完美状态。不论是键盘上的快捷键、触摸板，还是下方的飞梭旋钮都已经可以正常使用。让我惊喜的是，我所下载的驱动包含了飞梭旋钮配套的软件，所以现在我们可以好好看一看这个飞梭旋钮在 VAIO 的系统下到底能够做什么了。
除了可以在网页浏览时上下滚动，在正常使用系统的过程中，几乎所有地方你都可以使用它操控。比如在开始菜单，如果没有外接鼠标，只需使用飞梭旋钮上下滚动，就可以框选对应的程序或者文件。
当然这个操作在文件夹、图片预览等过程中都可以生效，而且在使用的过程当中会有一个对应的软件弹窗，通过弹窗你可以清晰地看到目前状态。桌面待机状态下，且没有打开任何程序的时候，滚动飞梭旋钮软件菜单依旧会弹出，这时软件菜单弹出的是映射的开始菜单目录，里面有一些 Windows 自带软件以及索尼原生配套软件。
另外我觉得配合飞梭旋钮最好使用的方式还有：使用 Fn 快捷键调出音量以及亮度，不用反复按键盘，拨动飞梭旋钮就可以快速调节。
联网情况和软件体验
讲完系统部分，我们来看看软件的情况。
因为笔记本内置 Wi-Fi 和蓝牙，在驱动安装好之后就可以正常使用无线上网了。
但在真正的使用过程当中，我发现常用的 Wi-Fi 已经不能被正常识别和连接了，就算偶尔一两次能识别连接，也会提示该网络无法正常上网。
其实我有想过是不是因为系统时间紊乱，或系统内根证书失效，导致 IE 等浏览器连不上现代网页。但当我打上了对应的根证书 KB 补丁之后发现情况还是一样——更根本的原因是，2001 年的无线网卡仅支持早期的 802.11b 协议和 WEP 加密方式，而现代路由器普遍采用了 WPA2/WPA3 安全加密协议，并且默认关闭了老旧协议的向下兼容。这块 20 多年前的网卡自然无法连上现代 Wi-Fi 网络。
虽然没有办法通过内置 Wi-Fi 正常上网，但我在收到这台笔记本的时候，就有一张对应的索尼无线网络 PC 扩展卡，同时机器的接口部分也是有预留 RJ45 网线接口的。
所以如果你真的想让这台笔记本连上现代网络，最简单的方法其实是直接使用机器自带的 RJ45 网线接口，通过一根网线连接到路由器。
但是不要忘了，如果系统时间以及内置的根证书没有设置正确和更新的话，使用浏览器访问网页的时候依旧会弹出错误哦。
因为当年索尼对这一台便携小笔记本的宣传跟定位，并并非完全是办公笔记本，这台设备更多还强调了便携和影音结合。
所以我通过 U 盘传输了很多的 mp3 音乐，并且下载了完整的 Office 2003。
实际使用下来发现这台小笔记本的音响效果着实让人惊喜，可能也是因为我这一台的使用程度不强，喇叭并没有明显的老化，声音洪亮，听着还有一点点立体感。
Windows XP 配合 Office 2003 也非常有怀旧的感觉，256MB 内存在仅保留 Office 以及后台运行的 Windows Media Player 的情况下，系统资源占用并不会频繁爆满或调用虚拟内存。
一些「趣闻」
其实 SRX 系列当年除了在日本本土发售，也有对应的国行版本。只不过国行版本在当时的环境下对应阉割掉了日系全套标配的 2.4GHz 频段 Wi-Fi 以及蓝牙。
同时，这台经典的索尼小电脑还曾出现在 2003 年《憨豆特工》真人电影当中，并且还不只是一闪而过的道具。跟随剧情推进，它发挥了完整且重要的作用，包括拼凑嫌疑人图像、策划对反派 Sauvage 总部的攻击行动等。
这也并不是索尼电脑第一次出现在影视作品当中，很多好莱坞大片都喜欢使用索尼电脑作为道具，后来的 UX 掌上电脑系列更是凭借着炫酷外观出现在众多电影当中，印象最深的应该是《终结者 2018》。
回看 25 年前，在绝大多数便携本还在为重量与性能相互妥协的年代，索尼用 PCG-SRX7 交出了一份惊艳的答卷——它不仅用 B5 尺寸、1.26kg 轻量化机身和 Pentium III-M 处理器堆叠出了工业奇迹，更在那个黄金时代，阐释了索尼对「时尚与科技结合」的浪漫。
