I hate you Microsoft
The rare moment when I need to open a powerpoint document is here. As usual, I have my institutional account logged into their “services”, because my university pays microslop something in the ballpark of hundreds of thousands of euros in contracts with this large software provider.
The first thing this nice software greets me with is:
LIKE REALLY? Like WHAT THE ACTUAL FUCK REALLY?
“Your account does not allow editing on a mac,” so fuck you? Like go get a fucking windows machine, or that’s it for you?
This is disrespectful at best. In reality this is unethical, buried money making schemes buried into the fine lines of some obscure contract that also steers our institution into using windows machines. Again the windows machines which you pay the license for and still are “greeted” with ads in the apps, a calculator app consuming hundreds of MB of RAM, bugs everywhere, and espionage. Let’s not talk about copilot and windows recall. The reality is bleak.
Please stop using windows. Please stop using proprietary document formats. We need to unite or we are in deep shit.
I know I am hosting this website on github pages, but I will do better in the future. Thank you.
