# AI 即将接管流量，而广告正在疯狂「末日反扑」精华简报

**来源：** 爱范儿 ifanr  
**文章链接：** https://www.ifanr.com/1676208?utm_source=rss&utm_medium=rss&utm_campaign=

---

## 一、TL;DR

文章揭示了一个荒诞而真实的对照：互联网正从“眼球经济”转向由 AI Agent 主导的“无眼球流量”时代，传统以人类注意力为核心的广告商业模式面临根基性动摇。然而，在范式转换前夜，硬件厂商、操作系统平台与 AI 产品却在疯狂反扑——将广告植入汽车中控屏、HDMI 暂停画面、系统开始菜单、锁屏壁纸，甚至 AI 生成答案的内部。其核心警示在于：技术革命未必自动带来更文明、更平等的体验，若不重新界定“屏幕所有权”与商业边界，用户可能被新的数字范式再次套牢。

---

## 二、核心观点与技术/商业洞察

### 1. 从“眼球经济”到“无眼球流量”：广告商业模式的根基正在被抽空

传统互联网建立在注意力收割之上：免费内容吸引停留，无限滚动的算法流锁定用户，再在碎片时间中填充广告与付费机会。每一次点击、每一次浏览，都在同时完成两件事——展示广告，以及积累数据用于更精准地展示广告。

但 AI Agent 时代改变了逻辑。用户只需发号施令，Agent 会自行搜索、阅读、总结、比价、下单，以毫秒级速度调用接口、抓取网页、对比数据，几秒到几十秒内返回结果，并跳过所有中间过程。手机 GUI Agent 甚至能代替用户完成复杂操作。

这意味着未来的互联网流量仍会爆发式增长，但绝大多数是“无眼球流量”——发生在 Agent 与 Agent、服务器与服务器之间的隐秘对话里。人类不需要抬一下眼、动一下手指。广告赖以生存的注意力被消弭，再精密的广告算法也不过是对着空气发力。

**商业后果：** 如果得不到一丁点注意力，广告又该卖给谁？这是科技行业前所未有的焦虑。

### 2. 广告向物理实体与操作系统底层“末日反扑”

既然注意力的获取通道难免被 Agent 堵死，广告便开始向那些人类无法委托给 Agent、也无法轻易避开的物理实体和操作系统底层疯狂反扑。

**宝马中控屏广告：**  
多位海外宝马车主在车辆启动时发现，车载中控屏弹出索尼与漫威电影《蜘蛛侠：崭新之日》的广告。宝马官方曾多次承诺不会将仪表盘、中控屏等核心部件用于营销，高级副总裁甚至公开表示“中控屏幕是用户的私人空间”。但宝马仍然这么做了。这与宝马此前将座椅加热功能做成付费订阅的策略同源：利用软件和互联服务，创造售后阶段的持续收益。用户虽然购买了硬件，但设备的控制权并未完全属于用户。

**Roku 的 HDMI 广告专利：**  
Roku 在 2024 年获批一项“HDMI 定制广告插入”专利，可直接监控 HDMI 接口的外部信号，识别到暂停事件时插入广告。即使用户只是把电视当作 PS5 的显示器，也逃不过广告。虽然 Roku 表示该专利仅作技术储备、暂无上线计划，但它暴露了硬件厂商寻找广告位的激进程度。

**操作系统与手机广告：**  
微软在 Windows 开始菜单加入“推荐应用”，在锁屏界面插入 MSN 信息流、游戏推广和必应广告。用户即使为正版系统付费，仍需在设置深处手动关闭分散的广告开关。国内安卓手机市场更是将锁屏、壁纸、桌面信息流广告做到极致，每一次点亮屏幕都形成微小的视觉刺激，诱导用户点击混杂在壁纸和有用信息中的推广内容。

**核心洞察：** 软件定义硬件时代，消费者买到的设备并不只属于自己，它可以随时变成厂商的广告牌。物理屏幕和数字入口的控制权，正在从用户向厂商/平台转移。

### 3. AI 本身成为广告新宿主：从“内容之外”到“流式嵌入”

AI 推理的昂贵算力成本和巨大营收压力，迫使 AI 平台在答案生成与呈现过程中开辟广告位。

**Google AI Overviews：**  
传统搜索结果中，用户还能清晰区分标有“赞助”标签的广告与自然结果。而现在，Google 明确将赞助商广告直接缝合进 AI 生成的答案内部。例如询问如何挑选咖啡机，AI 一边给出专业回答，一边插入特定品牌的商品卡片。AI 确实帮到了用户，同时也替赞助商做了一次精准带货。

**Perplexity 的“赞助追问”：**  
追问功能占 Perplexity 全部请求的 40% 流量。过去追问由大模型根据用户求知逻辑自然生成，现在品牌方可以竞价购买“追问位”。例如用户讨论“如何改善睡眠质量”时，系统会隐蔽地引导到床垫，再追问“想了解 Casper 床垫能如何改善你的深睡眠吗？”用户的好奇心被重组、包装为营销转化路径。

**微软 Copilot 等产品：**  
在复杂回答的引用脚注中隐蔽嵌入广告主链接。AI 不会成为广告行业的终结者，反而成了广告新的宿主、完美的推销员——它不需要吆五喝六，只用理智、平实、值得信赖的语气，将用户引向广告主预先买断的方向。

**风险：** 传统互联网时代，广告与内容之间存在肉眼可见的区别，重度用户能建立免疫机制。但在 AI 时代，这种区别变得更加模糊。用户看到一条看似诚恳专业的回答，往往容易忽略推理链路中已悄然塞进广告。这本身是一件危险的事情。

### 4. 屏幕所有权与控制权之争：谁真正拥有设备？

从宝马中控屏、Roku HDMI 专利到系统级广告，共同指向一个更深层的问题：消费者购买设备曾意味着获得绝对所有权，但在软件定义硬件的今天，设备可以随时变成厂商的广告牌。用户“不被打扰”的特权，可能只能通过支付昂贵的订阅或买断费用才能获得。这不仅是商业问题，更是数字权利问题。

## 三、对行业的启发与影响

### 1. 广告行业必须重构价值链条

传统展示/点击广告在 Agent 时代将逐渐失效。广告主需要从“买注意力”转向“买决策影响力”，例如在 Agent 的决策链路中竞价、提供结构化信息、影响推荐结果与比价排序。衡量指标也将从曝光、点击转向“被 Agent 采纳率”“转化归因”等新维度。广告技术公司需要开发面向 Agent 的广告协议与竞价系统。

### 2. AI 平台面临商业变现与用户信任的平衡

AI 原生广告若过度隐蔽，将侵蚀用户信任，引发监管与舆论反弹。平台需要明确披露广告来源、提供可关闭选项、建立可追溯机制。同时，应探索订阅、API、企业服务等多元收入，避免重走传统搜索引擎“广告侵蚀内容”的老路。透明度可能成为差异化竞争力：谁能提供“无广告/可验证无广告”的 AI 体验，谁就可能赢得高端用户与长期信任。

### 3. 硬件与操作系统厂商需重新审视“售后广告”边界

宝马、Roku 等案例表明，硬件厂商正把设备当作持续收入来源。短期可增收，但长期损害品牌与用户关系。汽车中控、电视 HDMI 等场景涉及驾驶安全与消费者权益，广告侵入可能触发立法与监管。厂商应把“无广告/干净体验”作为卖点，而非默认广告位。用户付费意愿与广告容忍度需要重新评估。

### 4. 用户注意力与数字权利的新议题

如果 AI 解放了注意力，但广告通过物理和系统底层夺回，用户并未真正获益。“不被打扰”可能成为付费特权，加剧数字鸿沟。需要公共讨论：屏幕所有权、系统广告开关、AI 广告披露标准等。文章结尾老先生想拍一张照片却被广告迷宫困住的场景，是一个警示：技术先进不应以牺牲基本体验为代价。

### 5. 对 AI 手机与智能设备的启示

文章直接点名安卓厂商：如果你们真的想做用户喜爱的 AI 手机，请把过去糟糕的广告机制解决掉。AI Agent 手机需要干净、可信的交互环境，否则用户不敢委托 Agent 执行任务。未来竞争可能从“谁的广告更精准”转向“谁更能保护用户注意力”。AI 体验与广告侵入存在根本冲突，谁能率先解决这一矛盾，谁就能在下一代设备竞争中占据先机。

---

## 四、一句话总结

AI Agent 正在抽空传统互联网的注意力地基，而旧商业力量在物理屏幕、操作系统和 AI 输出中疯狂反扑；若行业不重新定义屏幕所有权与广告边界，技术革命可能只是把用户从一种“数字迷宫”带入另一种更隐蔽的“算法迷宫”。
