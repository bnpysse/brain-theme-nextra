# 爱范儿早报精华简报

**来源**：爱范儿 ifanr  
**主题**：iPhone Duo 发布前黄牛溢价、AI Agent 竞赛升温、汽车智能化下放、出行服务密集更新  
**核心信号**：折叠屏首发炒作泡沫已现；OpenAI 因 Astra 需求过热暂停高价订阅；AI 平台广告与安全治理矛盾凸显；800V/激光雷达/线控底盘加速向大众车型渗透。

---

## 一、消费电子：iPhone Duo 发布前遭爆炒，三星主动“狙击”

- **iPhone Duo 国行价格**：256GB / 512GB / 1TB / 2TB 分别为 15999 / 17999 / 21499 / 26499 元，10 月 16 日晚 8 点预购，10 月 23 日正式发售。
- **黄牛市场**：闲鱼出现大量首发代抢。最高挂价 9.9 万元，但暂无成交；主流加价约 5000 元，最低加价 1000 元以上，1TB/2TB 高配仍在涨。代抢定金约 800 元，注明“跑单不退”。代抢服务费普遍约 200–1000 元。
- **竞争反应**：三星美国官方账号连续发文“热剩饭”“似曾相识”，强调自己 2019 年已推出折叠屏；罗永浩点评称折叠形态、屏下摄像头、内外屏接力等设计此前已有类似方案。

&gt; **分析师判断**：首发溢价预期强，但 9.9 万元标价更像噱头，市场尚未形成真实成交。三星的舆论战意在锚定“苹果是跟随者”，对首销情绪可能产生一定扰动，但实际影响有限。

## 二、AI 产业：Astra 需求爆棚，Agent 与平台政策成为新战场

- **OpenAI 暂停 ChatGPT Pro 20X 新订阅**：200 美元/月套餐暂停新订与升级，现有用户不受影响。官方称 Astra 需求“前所未有”，该类计划对系统压力最大。此前已预警若需求持续增长，可能不得不暂停。
- **OpenAI 平台广告收紧**：ChatGPT 不再接受图像、音频生成类竞品广告，视频生成暂不受限。Adobe 证实曾参与广告试点，新规关闭了部分品类。此举恰逢 ChatGPT Images 2.5 发布。
- **OpenAI 开放 Agents API 公测**：可直接调用 Codex Agent 基础设施。
- **Anthropic 安全事件**：黑客窃取部分 Claude 会话密钥，生成未授权 Claude Code OAuth token，导致用户额度异常消耗。Anthropic 已强制登出并撤销授权，退还未使用时长。用户应尽快检查第三方授权连接。
- **Mistral 完成 30 亿欧元 D 轮融资**：投后估值超 210 亿欧元，三星、EQT、PSG 领投，ASML、英伟达、a16z 等跟投。官方称是欧洲科技公司迄今最大单轮股权融资。
- **Kimi 开启全球招聘**：社招设 7 个“Wild Card”名额，面向复合型人才，可与创始团队直接沟通、获得独立算力和按当前估值锁定期权。明确不把绩点、辍学、创业失败、传统面试表现作为门槛。
- **支付宝设立“智能体涌现奖”**：每年投入 1000 万元，年度大奖 100 万元；阿宝已适配万余项服务，新增异步任务能力，并与星巴克推出“咖啡闹钟”。
- **DeepSeek**：聘请中信证券筹备科创板 IPO（快讯，原文未展开）。

&gt; **分析师判断**：  
&gt; 1. OpenAI 暂停 Pro 订阅本质是算力/系统容量瓶颈，说明 Astra 需求远超供给，高付费用户优先级正在被重新平衡。  
&gt; 2. AI Agent 不再只是模型能力竞赛，OpenAI、Meta、支付宝、Kimi 均在向“基础设施 + 平台控制权”倾斜。  
&gt; 3. OpenAI 一边发布新模型、一边限制竞品广告，平台利益冲突可能引发后续反垄断或公平竞争争议。

## 三、应用与出行服务：人人影视二次下架、旅行青蛙停运、高德“避雷”

- **人人影视 App**：回归约 10 天后再次下架，原文未披露具体原因。
- **《旅行青蛙·中国之旅》**：因 IP 授权到期，计划 12 月 8 日 18:00 停止运营。接近运营方灵犀互娱人士称，IP 方续约条件更严格，并限制联动活动与周边服务，双方仍在磋商；停运仅限中国大陆代理版本。
- **高德上线“避雷指南 1.0”**：从 15 个维度预判出行风险。
- **支付宝“碰一下”**：接入外滩大会 AI 会务和逛街助手。
- **豆包工作**：新增本地 Office 编辑、浏览器录制和执行环境切换。
- **小米回应 N90“服务车”分类**：私家车只需上牌前验车。

## 六、风险与关注点

1. **折叠屏黄牛泡沫**：9.9 万元标价无成交支撑，消费者应警惕高价代抢“跑单不退”风险。
2. **AI 账号安全**：Claude 会话密钥被窃事件说明，AI 账号授权、OAuth token 和额度风控已成为新的攻击面，用户应定期检查第三方连接。
3. **平台广告政策**：OpenAI 限制竞品广告可能引发公平竞争与反垄断关注，后续政策是否扩展至视频生成等品类需持续观察。
4. **汽车供应链**：理想自研 5C 电芯采用欣旺达/中创新航代工，反映出主机厂自研 + 外部代工并行的趋势；800V、激光雷达、线控底盘向更低价位下放，将对供应商成本和整车定价产生长期影响。
