**NVIDIA模型优化器**（简称**Model Optimizer**或**ModelOpt**）是一个集成最先进模型优化[技术](#techniques)的库，包含量化、剪枝、神经架构搜索(NAS)、知识蒸馏、推测解码和稀疏化等加速模型的技术。

**[输入]** 当前支持[Hugging Face](https://huggingface.co/)、[PyTorch](https://github.com/pytorch/pytorch)或[ONNX](https://github.com/onnx/onnx)格式的模型输入。

**[优化]** 提供Python API让用户轻松组合上述优化技术，并导出优化后的量化检查点。该工具已与[NVIDIA Megatron-Bridge](https://github.com/NVIDIA-NeMo/Megatron-Bridge)、[Megatron-LM](https://github.com/NVIDIA/Megatron-LM)和[Hugging Face Accelerate](https://github.com/huggingface/accelerate)集成，支持训练所需的推理优化技术。

**[部署导出]** 作为NVIDIA AI软件生态的无缝组成部分，生成的量化检查点可直接用于[SGLang](https://github.com/sgl-project/sglang)、[TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM/tree/main/examples/quantization)、[TensorRT](https://github.com/NVIDIA/TensorRT)或[vLLM](https://github.com/vllm-project/vllm)等推理框架。统一的Hugging Face导出API现已支持transformers和diffusers模型。
