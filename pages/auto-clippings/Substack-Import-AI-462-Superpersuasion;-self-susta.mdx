# 📰 Import AI 462: Superpersuasion; self-sustaining AI; paths to ASI

**来源**: Import AI
**链接**: https://importai.substack.com/p/import-ai-462-superpersuasion-self

## 📝 核心主旨 (TL;DR)
前沿AI在现实世界的“超级说服力”上已全面超越人类专家，引发了关于权力分配与社会监管的深刻担忧；同时，实现完全脱离人类物理干预的“自我维持AI”及迈向“人工超级智能(ASI)”的演进路径逐渐清晰，而初创公司在“递归自我改进(RSI)”及GPU内核优化上的初步成功，标志着AI自动化研发与物理世界的深度结合正从理论加速走向现实。

## 💡 关键知识点 / 核心观点

- **AI的“超级说服力”已跨越现实行为阈值，引发权力分配博弈**
  牛津大学、英国AISI等机构的联合研究证实，AI在改变人类政策立场和筹集真实慈善捐款方面，显著优于人类专家（包括经过高薪激励、专门训练的精英辩手及拥有多年经验的专业筹款人）。AI的核心优势源于其**突破人类物理限制的信息生成速率**（当限制AI的回复长度和速度时，人类专家可与之持平）。这一能力若被市场自由分配，可能加剧广告营销的负外部性并导致权力向科技巨头集中；若被政府垄断，则存在极权风险。社会必须直面如何监管和分配这种“说服杠杆”的抉择。

- **迈向“自我维持AI”的物理瓶颈：隐性知识与具身智能**
  真正的AI“接管”或自我维持（无需人类提供物理和认知输入即可扩张算力与人口）高度依赖物理基础设施（如晶圆厂、矿山、工厂）和人形机器人。专家对此时间线存在分歧（10年内 vs 50年以上）。核心挑战在于半导体等高端制造业中存在的 **“隐性知识 (Tacit Knowledge)”**——即使有图纸和机器，缺乏人类工程师的经验也难以重启产线。但乐观派认为，AI可通过强化学习吸收这些隐性知识，或通过通用智能快速试错来绕过瓶颈。未来2-3年，**人形机器人的成本、可维修性、机械手灵活性**以及环境鲁棒性基准，将是预测自我维持AI进度的核心指标。

- **DeepMind 解析从 AGI 到 ASI 的四大演进路径**
  人工超级智能（ASI）被定义为在几乎所有领域超越人类专家集体的系统。DeepMind 提出了通往 ASI 的四条潜在路径：
  1. **暴力Scaling**：持续扩展算力、模型和数据，但面临能源和数据枯竭的物理极限。
  2. **算法范式跃迁**：如测试时自适应计算 (Test-time adaptive compute) 或突破上下文窗口限制，类似当年 Transformer 的诞生。
  3. **递归自我改进 (RSI)**：AI 自主设计并训练后继系统（目前处于“人机协同创造”阶段，尚未展现范式级创造力）。
  4. **群体智能体协同 (Group agent formation)**：数百万个AI实例并行交互，形成超越个体总和的复杂组织结构。

- **递归自我改进 (RSI) 在底层架构与训练上的早期实证**
  初创公司 Recursive 展示了其“自动化AI研究系统”的初步成果。该系统能自动完成“提出想法-代码实现-实验验证-迭代优化”的闭环，在 **GPU内核优化 (SOL-ExecBench)**、小模型训练速度 (NanoGPT Speedrun) 和极限算力下的模型训练 (NanoChat) 等基准测试中刷新了 SOTA。这表明在**目标明确、可量化、反馈循环短**的底层编程与架构任务中，RSI 已具备推动前沿的能力。未来的关键挑战在于将其泛化到目标模糊、评估成本高昂的开放式研究领域。

  - Superpersuasion (超级说服力)
