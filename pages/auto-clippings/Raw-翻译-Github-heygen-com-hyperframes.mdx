HyperFrames是一个开源框架，可将HTML、CSS、媒体和可寻址动画转化为确定性MP4视频。可通过CLI本地使用，由AI编程智能体通过技能调用，或作为托管创作工作流背后的渲染核心。

## 快速开始

### 通过AI编程智能体

安装HyperFrames技能后，描述您想要的视频：

```bash
npx skills add heygen-com/hyperframes
```

&gt; 选择器打开时无预选内容——您只需要**核心技能组**：`/hyperframes`路由器会按需安装每个创作流程。智能体和非交互式运行应改用`npx hyperframes skills update`——它仅安装核心集合，而`skills add --all`会安装仓库中每个`SKILL.md`文件——20个已发布技能加6个仓库内部技能（位于`.claude/skills`/`.agents/skills`下）。要获取完整发布集合请使用`npx hyperframes skills`。
&gt;
&gt; `skills add`解析skills.sh注册表数据，可能滞后`main`分支数小时。`npx hyperframes skills update`直接从当前`main`分支安装，当您需要最新技能副本时请使用此命令。

尝试类似提示：

&gt; 使用`/hyperframes`创建一个10秒产品介绍视频，包含淡入标题、背景视频和微妙背景音乐。

这些技能会教导智能体HyperFrames生产循环：规划视频、编写有效HTML、连接可寻址动画、添加媒体、代码检查、预览和渲染。适用于Claude Code、Cursor、Gemini CLI、Codex等支持技能的编程智能体。

## 技能

HyperFrames提供20个按需加载的智能体技能。首先阅读`/hyperframes`——它是路由器和能力地图；为任何"制作一个..."请求（视频、演示文稿或组合端口）选择工作流，并指向下方领域技能。
