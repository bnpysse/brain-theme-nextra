# 精简速读

**华人世界被忽视的游戏主机：扩写中国家用游戏主机的时间线**

来源：少数派 sspai｜作者：讲座整理稿｜链接：sspai.com/post/113842

&gt; 本文基于四川美院讲座整理，重新梳理了1970年代至今国产家用游戏机的完整谱系，打破了「国产游戏机=小霸王」的刻板印象，揭示了一条被主流游戏媒体长期忽略却从未中断的产业链——从香港伟易达到台湾普泽/敦煌，从大陆体感机到开源掌机，国产游戏硬件的「仿冒污名」之下，其实暗藏着多维度的原创精神。

---

## 一、核心论点：国产游戏机史被"三重忽略"遮蔽

文章开篇便对主流叙事中的**三种刻板印象**提出挑战：

| 刻板印象 | 实际反驳 |
|---|---|
| 中国游戏机只有小霸王 | 早在1970年代末，港澳台就已出现基于Ay-3-8500芯片的Pong类家用机；四十年来形成横跨两岸的复杂产业链 |
| 2000年代"游戏机禁令"中断了国产游戏机发展 | 禁令客观挤压了产业，但并未中断开发；低龄教育市场和出口市场始终活跃，只是远离了核心玩家视野 |
| 国产游戏机=仿冒、无原创 | 在"仿冒"的污名背后，包含**多维度的原创精神**——从芯片自研到本体软件开发，许多产品在设计上有独立的技术路线 |

文章指出，这种忽略的历史根源在于：**中国游戏媒体话语权长期掌握在核心玩家手中，以美日商业大作为参照系的"鄙视链"将国产游戏机边缘化**。同时，中国长期缺少学术化的游戏表达语境，使得非核心玩家市场的产品几乎无人记录。

---

## 二、时间线总览：六阶段框架

演讲将国产游戏机发展线索分为**六个阶段**：

```
1980s        八位机开拓期
             → 伟易达 CreatiVision｜台湾普泽 BIT-60 / BIT-90
1990s        台湾厂商挑战主流市场
             → 16位主机 Super A'Can｜Gamate 掌机
2000s        设计与制造向大陆转移
             → 面向体感、低龄教育等非核心市场
2000s末-2010s  非通用系统开源掌机
             → 丁果 A320 → 安伯尼克延续
2010s        通用操作系统设备
             → 金星 JXD（安卓）｜GPD Win（Windows）
2010s中后期    创客市场细分
             → Meowbit｜奥比中光 Persee
```

这条时间线的关键**断裂与转向**在于：90年代台湾厂商试图进入核心玩家市场（Super A'Can），到2000年代大陆厂商**主动放弃核心市场、转向细分下沉市场**——这不是简单的溃败，而是一种适应性的商业进化。

## 三、关键厂商与产品：值得记住的名字

**1. 伟易达（1976～今）**
- **CreatiVision（1982）**：香港本土品牌电视游戏机，兼具BASIC编程功能。其游戏《直升机救援》被认为是**最早在家用机上实现等轴3D画面的作品之一**；
- **Laser 310**：80年代国内最流行的教育用家用电脑之一；
- **Socrates（80年代末）**：避开红海定位为纯教育游戏机，战略上避开了任天堂/世嘉的正面竞争；
- **Video Painter（90年代）**：将Quantel Paintbox（1981年售价15万美元的专业视频编辑设备）的核心绘图/动画功能集成到**100美元级的家庭玩具**——“这种惊人的成本控制力是长期以来中国厂商最重要的商业基因之一。”

**2. 台湾普泽 → 敦煌科技（联电子公司）**
- 围绕6502处理器开发BIT-60（兼容Atari卡带）、BIT-90（兼容ColecoVision卡带），是**后来"学习机"的原型**；
- 台湾电子游戏禁令（打击赌博街机时被扩大化）与大陆2000年代禁令"在初衷和实施方式上都有诸多相似"；
- **Gamate掌机（90年代）**：紧随GameBoy推出，售价100美元内，硬件不落下风，"但游戏库几乎只有第一方，第三方游戏稀缺明显限制了它的市场潜力"；
- **Super A'Can（1995）**：16位主机，摩托罗拉68000处理器 + **联电自研图形芯片和声音芯片**，是当时国产化程度最高的主机。但生不逢时：推出时16位市场已近尾声，同时受高端次世代机能（PlayStation）和低端小霸王兼容机的**三面挤压**，上市后即停产。

**3. 凌阳 + 虚实科技（2000年代）**
- **凌阳芯片**是"山寨Wii"体感机的核心——但文章明确指出，这些机器在**技术架构上与Wii完全不同，是独立开发的产品**；凌阳还通过"大学计划"在大陆培养了大批单片机开发者；
- **虚实科技芯片**沿用6502+类红白机PPU架构但加强性能，"让熟悉红白机开发的开发者更容易上手"，主要用于复古掌机和体感机，与凌阳构成竞争。

**4. 游戏MP4 → 开源掌机（2000年代中后期）**
- 游戏MP4是**应对禁令的折中路线**，瑞芯微RK2606与ADI Blackfin构成芯片供应两强；
- **丁果A320与歌美X760+** 使用相同硬件方案（君正JZ4732/JZ4740），但丁果支持原生游戏开发（《7夜》等），歌美则延续"功能机"逻辑——两者对产品的理解存在**本质性分歧**。这一分歧预示了后续开源掌机阵营的分化。

## 四、核心洞察：被忽视史的三个深层逻辑

**1. 中国游戏硬件的基因是成本控制与边缘创新**
从Video Painter的100美元突破到开源掌机对模拟器生态的整合，国产游戏硬件的核心竞争力在于暴力降低门槛，将专业能力下沉至消费级。

**2. 两岸产业链的协作从未中断，但话语权结构严重失衡**
台湾设计芯片 → 大陆OEM/ODM整机的模式贯穿2000年代，与联发科"山寨手机"模式同构。国内生产了大量游戏机，中文互联网资料却极少——这与产品的出口导向和下沉导向直接相关。

**3. "专用游戏机"是一个被大众媒体彻底遗忘的巨型品类**
从最早的Pong类产品到凌阳芯片的不可扩展游戏机，专用游戏机（Dedicated console）从未消失，只是从未被核心玩家世界记录。这是媒体话语权垄断最典型的体现。

## 五、方法启示

对于创作者和研究者，本文提供了几个可复用的分析思路：

- **警惕"核心玩家中心主义"的历史叙事**：历史往往由有话语权且愿意分享的人书写，沉默的大多数需要主动去打捞；
- **"仿冒"标签下的技术考古**：拆开一台"山寨Wii"，它的芯片、系统、软件栈都是独立的——污名化标签背后有一套完整的设计决策，值得严肃对待；
- **产业转移的时间线**：将硬件公司的芯片选型（凌阳 vs 虚实科技 vs 瑞芯微）与产品形态（体感机/MP4/开源掌机）交叉对照，可以还原出一条隐藏的行业演化路径。
