# 📰 From DeepSeek V3 to V3.2: Architecture, Sparse Attention, and RL Updates

**来源**: Ahead of AI
**链接**: https://magazine.sebastianraschka.com/p/technical-deepseek

## 📝 核心主旨 (TL;DR)
DeepSeek V3.2 标志着团队从“专用推理原型（R1）”向“高效混合旗舰”的战略转型。该版本通过引入 **DeepSeek 稀疏注意力（DSA）** 将长上下文计算复杂度从二次方降至线性，并结合 **“自验证+自反思”强化学习闭环** 攻克了传统 RLVR 中“答案正确但逻辑断层”的难题。配合现代化 GRPO 梯度优化策略，V3.2 在数学、代码与 Agent 任务上逼近头部闭源模型，同时实现了训练成本与推理延迟的大幅优化。

## 💡 关键知识点 / 核心观点
1. **架构演进：DeepSeek 稀疏注意力（DSA）打破固定窗口限制**
   在 V3 已采用的 MLA（多头潜在注意力，压缩 KV Cache 节省显存）基础上，V3.2-Exp/V3.2 创新性地部署了 DSA。该机制摒弃了 Gemma 3/Olmo 3 使用的固定宽度滑动窗口，改用“闪电索引器（Lightning Indexer）+ Token 选择器”。索引器利用当前 Query 与历史 Token 的压缩表征计算相似度得分（Scaled Dot Product + ReLU），选择器仅保留 Top-k（代码设为 2048）高相关 Token 构建稀疏掩码。这使得注意力计算复杂度由 $O(L^2)$ 骤降为 $O(Lk)$，在几乎不牺牲精度的前提下，显著缓解了长序列推理的显存与算力瓶颈。

2. **训练范式跃迁：自验证（Self-Verification）与自反思（Self-Refinement）闭环**
   传统 RLVR 依赖终态符号验证，易导致模型“蒙对答案”或无法处理定理证明等无明确数值解的任务。DeepSeekMath V2（作为 V3.2 的技术预演）提出分阶段校验体系：训练时部署独立的 Proof Verifier（LLM2）接收结构化打分（0/0.5/1），并由 Meta-Verifier（LLM3）监督校准防止幻觉；推理时则统一回单模型，利用训练中学到的严格评审标准进行多轮迭代自我修正（实验达 8 轮仍未饱和）。该设计实现了过程奖励的动态注入，大幅提升推导严谨性。

3. **强化学习管线现代化：GRPO 与 DAPO/Dr.GRPO 理念的深度集成**
   V3.2 在继承 GRPO 框架的同时，针对长序列训练不稳定问题进行了底层调优：
   * **奖励重构**：移除旧版格式奖励，新增 Agent 任务的长度惩罚；针对无可验证符号的通用指令，引入 LLM-as-a-Judge 个性化 Rubric 评估。
   * **梯度稳定化**：吸收业界最新实践，实施 Zero Gradient Filtering（剔除方差为零的无效样本）、Token-Level Loss（按总 Token 数归一化防长度偏差）、移除 KL Penalty（放宽策略更新边界防过拟合）、Higher Clip Upper Bound（增大正向更新幅度）及 Truncated Importance Sampling（对齐训练/推理分布差异）。

4. **产品路线图：从垂直突破走向通用混合架构**
   R1 被定位为推理方法论的“试验床”，而 V3.1/V3.2 转向 Hybrid Model 路线。用户无需加载两套权重，即可通过 Prompt Template 动态切换深度思考与常规生成模式。这一策略更贴合工业界“按需分配算力”的需求。此外，团队平稳度过中美芯片供应链交替期（经历 NVIDIA → Huawei 测试 → 回归 NVIDIA），证明了其全栈工程适配能力与快速迭代纪律。

## 🏷️ 提及的重要概念/公司/模型
**模型/项目**: DeepSeek V3 / V3.1 / V3.2 / V3.2-Exp / R1 / R1-0528 / DeepSeekMath V2、Qwen3、Gemma 3、Olmo 3、GPT-5 / GPT-5.1
**核心架构/机制**: Mixture-of-Experts (MoE)、Multi-Head Latent Attention (MLA)、DeepSeek Sparse Attention (DSA)、Lightning Indexer、Top-k Token Selector、Sliding Window Attention
**训练/强化学习**: Reinforcement Learning with Verifiable Rewards (RLVR)、Group Relative Policy Optimization (GRPO)、PPO / RLHF、Self-Verification & Self-Refinement、Process Reward Model (PRM)、LLM-as-a-Judge、DAPO / Dr.GRPO 优化项（Zero Gradient Filtering, Token-level Loss, No KL Loss, Higher Clip, Truncated Importance Sampling）
**硬件/生态**: NVIDIA GPU、Huawei Ascend / 昇腾芯片、Inference Infrastructure / KV Caching
