MCP â use pgbot as an agent tool
pgbot mcp speaks the Model Context Protocol on stdio, so an AI agent can call pgbot as a read-only tool. It exposes deterministic tools only â inspect (full findings as JSON) and unused_indexes â and lets the connected model do the explaining. No Gemini key involved: the agent reasons over the same findings the CLI computes.
