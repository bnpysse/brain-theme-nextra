### TL;DR

用户报告 Cursor 在 Mac Tahoe（macOS 26）上存在严重兼容性问题：无论是通过 IDE 还是 Agent 模式，输入任务后仅显示简短开始提示便卡死，长时间停留在“working process”或“looking for files”状态；即使在一个空文件夹中新建项目，文件扫描也异常缓慢。用户已尝试“传统终端（legacy terminal）”“kill bashes”等常规方案，均无效，因此怀疑这是 Cursor 在 Mac Tahoe 上的系统级通病。

### 核心观点 / 技术细节

- **环境**：Mac Tahoe（macOS 26）工作笔记本，安装 Cursor。
- **故障模式**：IDE 模式和 Agent 模式均无法正常工作。
- **具体表现**：任务启动后卡在“工作进程”或“查找文件”阶段，且空文件夹同样耗时，说明问题并非项目规模导致，而更可能是底层文件扫描/索引进程异常。
- **已尝试手段**：使用传统终端、终止 bash 进程等 Google 常见建议，均无效。
- **社区状态**：原帖未提供有效修复方案，用户疑问“是否 Cursor 在 Mac 上的通病”尚无明确答案，但反映了对新版 macOS 的适配缺口。

### 核心痛点

- **关键阻塞**：Cursor 在 macOS Tahoe 上无法完成任何任务（IDE/Agent 均失效），开发流程完全中断。
- **无有效修复**：常规终端和进程清理手段无效，缺少官方或社区认可的 workaround。
- **平台适配风险**：暴露了 Cursor 对最新 macOS 系统支持不足，可能影响从零搭建项目等基础场景。
