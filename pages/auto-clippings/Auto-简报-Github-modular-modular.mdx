### 核心总结
- Modular 平台是统一的 AI 开发与部署平台，开源组件主要包括 MAX 框架和 Mojo 语言。
- 仓库包含 Mojo 编译器、标准库、MAX 加速器库、推理服务器、模型流水线及代码示例等核心组件。
- 社区接受标准库、加速器库、模型架构、示例和文档等贡献，但暂不接受 Mojo 编译器贡献。
- 采用 Apache License v2.0（含 LLVM 例外），MAX 使用 Modular 社区许可证，第三方许可需自行验证。
