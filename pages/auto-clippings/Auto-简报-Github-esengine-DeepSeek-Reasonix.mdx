# DeepSeek-Reasonix (Reasonix)

## 📝 一句话简介
一款基于 Go 语言编写、专为 DeepSeek 前缀缓存（Prefix Cache）深度优化的轻量级 AI 编程 Agent，支持 CLI/TUI、桌面端及 VS Code 插件。

## 🛠 技术栈
- **核心语言**：Go (Golang) —— 采用 `CGO_ENABLED=0` 静态编译，跨平台无运行时依赖
- **通信/工具协议**：MCP (Model Context Protocol, 基于 stdio JSON-RPC)、ACP (Agent Communication Protocol)
- **前端/客户端扩展**：VS Code Extension (TypeScript)、跨平台桌面应用 (Electron/Tauri 等打包格式)
- **配置与数据**：TOML (`reasonix.toml`)
- **模型对接**：DeepSeek 原生 API、OpenAI 兼容接口

## 🌟 核心亮点
1. **极致的 Token 成本优化 (Cache-Aware)**：专门针对 DeepSeek 的 Prefix Cache（前缀缓存）机制设计上下文维护算法，在长会话中自动剪枝无效工具输出并注入稳定环境摘要，显著降低 API 消耗。
2. **极简部署与零依赖**：单静态 Go 二进制文件输出，无复杂依赖环境；同时覆盖 CLI/TUI、桌面 App、VS Code 插件三种形态，满足不同场景的使用习惯。
3. **多模型组合与双角色协同**：支持将“规划器 (Planner)”与“执行器 (Executor)”分配给不同模型独立运行，在保持各自缓存稳定的同时实现复杂任务的拆解与执行。
4. **高度可扩展的插件生态**：原生兼容 MCP (Model Context Protocol) 规范，外部工具可通过 JSON-RPC 管道接入，内置工具支持编译时自动注册。
5. **完善的工程化控制**：具备 Context Engine v2（上下文检索）、Checkpoints（会话快照与回滚）、子 Agent 配置文件 (Subagent Profiles) 和任务契约控制，保障大模型代码生成的可靠性。

## 🎯 适用场景
- **DeepSeek 重度用户**：希望以极低 Token 成本获得类似 Cursor / Claude Code 级别的 AI 辅助编程体验。
- **命令行与极客开发者**：习惯在 Terminal/TUI 环境中直接下发指令，让 AI 进行代码重构、 Bug 修复或自动化任务。
- **自定义 AI 工作流构建**：需要利用 MCP 协议扩展本地私有工具，或需要“规划+执行”双模型协同解决复杂工程难题的团队。
