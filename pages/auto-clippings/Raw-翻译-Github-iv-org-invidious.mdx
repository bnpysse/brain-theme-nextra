## Features
## 功能特性

**User features**
**用户功能**
- Lightweight
- No ads
- No tracking
- No JavaScript required
- Light/Dark themes
- Customizable homepage
- Subscriptions independent from Google
- Notifications for all subscribed channels
- Audio-only mode (with background play on mobile)
- Support for Reddit comments
- [Available in many languages](locales/), thanks to [our translators](#contribute)

- 轻量级
- 无广告
- 无追踪
- 无需JavaScript
- 亮色/暗色主题
- 可自定义主页
- 独立于Google的订阅系统
- 所有订阅频道通知
- 纯音频模式（支持移动端后台播放）
- 支持Reddit评论
- [支持多语言](locales/)，感谢[翻译贡献者](#contribute)

**Data import/export**
**数据导入导出**
- Import subscriptions from YouTube, NewPipe and FreeTube
- Import watch history from YouTube and NewPipe
- Export subscriptions to NewPipe and FreeTube
- Import/Export Invidious user data

- 从YouTube/NewPipe/FreeTube导入订阅
- 从YouTube/NewPipe导入观看历史
- 导出订阅至NewPipe/FreeTube
- 导入/导出Invidious用户数据

**Technical features**
**技术特性**
- Embedded video support
- [Developer API](https://docs.invidious.io/api/)
- Does not use official YouTube APIs
- No Contributor License Agreement (CLA)

- 嵌入式视频支持
- [开发者API](https://docs.invidious.io/api/)
- 不使用官方YouTube API
- 无需签署贡献者许可协议(CLA)
