How to connect

连接方式

Configure your client to use /api/mcp, then pass your API key in the authorization header.

Authorization: Bearer &lt;YOUR_API_KEY&gt;

Accept: application/json, text/event-stream

Streamable HTTP — your client handles protocol negotiation.

It is a remote Model Context Protocol server that lets compatible AI agents search for up to 20 businesses and receive results directly using your API-workspace credentials.

这是远程模型上下文协议服务器，兼容AI代理可通过API工作区凭证直接搜索最多20家企业并获取结果。

The server uses stateless Streamable HTTP at https://gmapscrawl.com/api/mcp. /mcp remains a compatibility alias. Your client initializes the connection and negotiates the protocol version.

服务器采用无状态流式HTTP协议（https://gmapscrawl.com/api/mcp），/mcp仍作为兼容别名保留。客户端负责初始化连接并协商协议版本。

Configure Authorization: Bearer with your API key in the client’s secret configuration. Browser login cookies do not authenticate this endpoint, and keys should never go in a prompt or URL.

在客户端密钥配置中设置Authorization: Bearer头。浏览器登录cookie无法验证此端点，密钥绝不应出现在提示词或URL中。

Yes, with a version that supports remote HTTP MCP and custom authorization headers. Use the client configurations above and ensure the configured environment variable is available to that client.

需使用支持远程HTTP MCP和自定义授权头的版本。采用上述客户端配置，并确保配置的环境变量对该客户端可用。

Business searches return available listing attributes, contact details, ratings, and review counts. The server exposes only search_google_maps.

商业搜索返回可用列表属性、联系方式、评分和评论数。服务器仅开放search_google_maps接口。

Live work requires an API entitlement and an available cloud service. MCP shares API usage; an Online subscription does not include it. Use a test credential to validate the integration with simulated fixtures.

正式使用需API授权和可用云服务。MCP共享API用量，在线订阅不包含此服务。使用测试凭证通过模拟数据进行集成验证。
