# 精华简报：美国财政部新顾问上任，意与中国争夺“黄金货币”先机

## 核心摘要

2025年10月9日，美国财政部任命经济学家朱迪·谢尔顿（Judy Shelton）担任财政部长贝森特的货币政策顾问，侧重评估中国金融状况。谢尔顿是“健全货币派”代表，长期主张恢复美元与黄金的联系。她明确警告：**美国不能让中国率先建立本国货币与黄金之间的新联系**，否则将是重大战略突破。本文基于其3月专访，系统梳理了她的政策主张及潜在影响。

## 一、背景：谢尔顿其人

- **身份**：曾任美国驻欧洲复兴开发银行执行董事，2019年获特朗普提名美联储理事，因金本位主张及对美联储独立性的看法引发争议，未获参议院确认

- **政策立场**：长期主张以黄金等价值标准约束货币政策，批评美联储过度干预金融市场

- **现任职务**：财政部长贝森特顾问，负责货币政策建议，侧重评估中国金融状况

## 二、核心主张：美国应抢在中国之前重建美元与黄金的联系

### 1. 战略紧迫性：货币竞争的地缘政治逻辑

- 谢尔顿引用诺贝尔经济学奖得主蒙代尔的观点：“伟大的国家通常拥有伟大的货币”，强调货币地位与国家实力的关联

- 西方冻结俄罗斯资产被视为金融“核武器”，促使多国寻求替代性货币安排，其中**中国对这一问题思考最为深入**

- 她向贝森特转发了英国前财政大臣克沃滕的文章，该文提出**中国可能成为第一个重新将本国货币与黄金挂钩的国家**——谢尔顿对此的判断是：率先行动的不该是中国，而应是美国

### 2. 具体政策构想：50年期黄金支持国债

| 要素 | 内容 |

|------|------|

| **设计逻辑** | 仿照通胀保值国债（TIPS），但以黄金价格而非CPI作为购买力保护基准 |

| **发行规模** | 定位为小众融资工具，规模小于浮动利率国债 |

| **核心机制** | 将部分黄金储备正式质押，作为债券担保资产 |

| **附加价值** | 通过法律安排封存黄金储备，限制未来政府随意出售黄金（针对英国戈登·布朗出售黄金的前车之鉴） |

### 3. 美联储改革方案

- **停止向银行准备金支付利息**：目前银行在美联储存放近3万亿美元现金，美联储为此支付利息。取消该机制将促使银行增购美国国债，压低市场利率

- **主动出售抵押贷款支持证券（MBS）**：美联储资产组合约6.7万亿美元，持有损失已超9000亿美元。当前仅靠自然到期缩减速度过慢，应主动出售

- **理顺黄金凭证问题**：美联储资产负债表上黄金凭证按每盎司42.22美元的法定价格估值（约110亿美元），与市场价值（约1.2万亿美元）存在巨大差距，且凭证并不赋予美联储黄金索取权，制度安排需要澄清

### 4. 对当前经济形势的判断

- 美国并非典型滞胀——就业状况尚可，劳动力市场是否走弱仍有争议

- 与伊朗的战争对美联储政策的影响存在双向可能性

## 三、影响分析

### 对美国

- 谢尔顿进入财政部标志着“健全货币派”首次在行政分支获得直接政策影响力

- 黄金挂钩国债若落地，将创造一种兼顾黄金避险属性与国债信用等级的新型资产，可能吸引大量配置需求

- 美联储改革主张若推进，将深刻改变美国货币市场运行逻辑

### 对中国

- 谢尔顿明确将中国视为货币竞争的主要对手，其政策建议具有针对性

- 若美国率先建立美元与黄金的联系，将强化美元信用，加大人民币国际化的外部压力

- 中国央行持续增持黄金储备的战略意图，可能因此受到更多关注

### 对全球货币体系

- 当前国际货币体系被批评为“反体系”（anti-system），黄金已超过欧元成为全球第二大储备资产

- 美国若恢复金本位关联，可能引发全球货币体系向“黄金锚”方向重构，布雷顿森林体系或将以新形式回归

## 四、分析师观察

1. **政策落地难度不容低估**：谢尔顿的主张在主流经济学界争议极大，金本位可能带来通缩压力、限制货币政策灵活性等弊端已被历史反复验证。其政策建议能否从“个人主张”转化为“政府政策”，存在很大不确定性。

2. **黄金挂钩国债的深层逻辑**：该构想表面是融资工具创新，实质是以市场化方式为美元引入黄金信用锚——既回避了恢复金本位的制度刚性，又能部分实现“约束货币纪律”的目标，策略上颇为精巧。

3. **值得关注的信号意义**：无论政策是否落地，谢尔顿的任命本身已释放明确信号——美国政府在战略层面开始认真对待黄金的货币角色，并将中国视为货币竞争的关键对手。这一动向值得持续跟踪。
