# 精华简报：Native is now the future of mobile at Shopify

**来源**：Simon Willison（AI 实用工程化）  
**原文链接**：https://simonwillison.net/2026/Sep/10/shopify-react-native/

## TL;DR

Shopify 宣布将其移动应用从 React Native 转回 iOS 与 Android 各自独立的原生代码库（Swift 与 Kotlin）。2020 年它选择 React Native，是为了避免双平台重复开发、让开发者能跨栈工作、减少功能对齐的负担；如今这些成本并未消失，但 AI 编码代理已经能在实现、代码翻译、测试和审查等环节承担足够多的工作，使“维护两套原生代码”不再成为决定性障碍。Shopify 同时充分肯定 React Native 在过去六年的价值，并对其维护的三个重要开源库做出后续安排。

---

## 核心观点与技术/商业洞察

### 1. 决策反转的本质：不是技术失败，而是成本方程改变

Shopify 明确重申了 2020 年从原生转向 React Native 的三个理由：

- 停止在两个平台上重复构建相同功能；
- 让开发者能够跨栈工作；
- 减少追逐功能对等（feature parity）的时间，把更多精力用于交付价值。

但现在它判断：**原生双平台开发的高成本依然存在，但 AI agents 已能把“实现、翻译、测试、审查”等工作做到足够好，使这项成本不再像 2020 年那样是决定性因素。**  
换言之，这不是“React Native 不行了”，而是“原生路线的额外代价已经被 AI 压到可接受范围”。

### 2. AI 成为架构选型的一等变量

过去技术选型主要围绕语言生态、团队能力、性能、招聘市场和长期维护成本。Shopify 的案例说明，**coding agents 的成熟度已经足以影响一家大型企业的移动端战略方向**。

尤其值得注意的是原文中的 “translation” 一词。AI 不仅能辅助编写代码，还能在 Swift 与 Kotlin 之间进行高质量的代码迁移、对照与转换。这直接削弱了 React Native “一次编写、双端运行”的核心卖点：如果 AI 能显著降低双平台代码的同步与翻译成本，那么“只维护一套 JS/TS 代码”的优势就会缩水。

### 3. 对 React Native 的公正评价，而非技术站队

Shopify 给了 React Native 非常体面的评价：**它在六年使用期间是一个优秀平台**。

这种表述很重要。它说明退出不是出于对某项技术的否定，而是基于组织成本与 AI 能力到达拐点后的理性选择。这种“技术无罪、经济理性”的决策逻辑，比单纯的原生 vs 跨平台争论更有参考价值。

### 4. 开源生态连锁反应：三个库的不同归宿

Shopify 是三个较有影响力的 React Native 库的维护者：

- `react-native-skia` —— 高性能 2D 图形库；
- `flash-list` —— 高性能列表组件；
- `restyle` —— 样式系统库。

其中前两个正在寻找新的维护者/新家，而 `restyle` 因用户规模相对较小，将在 **2026 年底归档**。

这提醒整个 RN 生态：**一家企业退出某项技术栈时，其开源资产不会自动消失，但可能停止维护。** 依赖这些库的团队必须进行风险评估与迁移规划。

### 5. 移动跨平台争论进入新阶段

Shopify 的路径是：早期原生 → 2020 React Native → 2026 原生。  
这不是简单的钟摆摆动，而是说明：**技术选型是周期性、情境化的，取决于工程能力、AI 工具成熟度和业务优先级。**

未来的竞争焦点可能不再是“原生 vs 跨平台”，而是：**谁能利用 AI 把双平台成本压到足够低，同时保留原生体验和平台特性。**

## 对行业的启发与影响

- **企业技术选型必须重估 AI 变量**  
  2020 年成立的决策理由，在 2026 年可能因 AI 工具而失效。做架构决策时，应把 AI 代理在代码生成、测试、审查、代码翻译等方面的能力纳入成本模型，而不只是计算人力成本。

- **原生技能可能重新升值**  
  如果大型厂商开始回归 Swift/Kotlin，市场对原生 iOS/Android 开发者的需求可能回升。同时，跨平台开发者也需要补充平台原生知识，以便更好地审查、调试和优化 AI 生成的平台代码。

- **跨平台框架的核心卖点被削弱**  
  “维护一套代码”是 React Native、Flutter 等框架的长期优势，但 AI 降低双平台维护成本后，这一优势的边际价值下降。跨平台框架需要更多强调 AI 难以替代的差异点，例如热更新、业务逻辑复用、统一状态管理、生态一致性等。

- **开源依赖方必须做供应链审计**  
  Shopify 的库退出/归档提醒团队：企业维护的开源项目可能随战略调整而停止支持。依赖方应关注项目的维护者背景、bus factor、长期支持承诺，并准备替代方案。

- **AI 工程化的重要信号**  
  Shopify 是一家大型电商平台，其基于 AI agents 进行重大架构迁移，说明 AI 编程工具已经进入“能影响企业战略决策”的阶段，而不仅是辅助补全或小规模提效。这为 coding agent 赛道提供了强有力的现实背书。
