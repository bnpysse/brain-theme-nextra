Apple 调整妙控键盘的键帽符号
8 月 25 日，Apple 公司更新了妙控键盘的细节外观，按键 Tab、Caps Lock、Shift、Return 和 Delete 等键帽不再使用文字标识，而是改为 ⇥、⇪、⇧、↵、⌫ 等纯符号标识。同时，带数字键盘的妙控键盘也将 Home、End、Page Down、Page Up 等键帽改成了纯符号标识。
本次更新的产品有妙控键盘、带触控 ID 的妙控键盘，以及带触控 ID 和数字键盘的妙控键盘（白色、黑色），唯一没有更新的是无触控 ID 带数字键盘的妙控键盘。来源
OpenAI 发布 ChatGPT Admin 插件
8 月 26 日，OpenAI 公司推出了一款全新的 ChatGPT Admin 插件，让工作区管理员可以直接通过对话管理用户和权限、分析使用情况，并根据相关数据生成报告。
通过 Admin 插件，管理员可以直接在 ChatGPT Work 和 Codex 中完成日常管理工作。管理员可以查看 ChatGPT Work 和 Codex 的活动数据及额度使用情况，找出哪些团队可能需要进一步支持，并及时发现哪些成员或团队即将达到额度上限。
管理员可以添加或移除成员、调整群组设置，并处理常规的入职、离职以及团队变动等事务。此外，管理员还能够查看用户的实际权限，排查访问问题，并根据角色或群组控制不同功能和模型的访问权限。
Admin 插件还支持管理使用额度和消费申请。管理员可以调整个人、群组以及整个工作区的额度限制，根据当前使用情况审核相关申请，并在掌握完整背景信息的情况下批准或拒绝这些请求。来源
闪迪推出宝可梦纪念款产品
近日，为庆祝宝可梦诞生三十周年，闪迪公司推出了两款授权存储产品，分别是闪迪宝可梦 USB-C 闪存盘梦幻版和闪迪宝可梦便携式 SSD 超梦版。
两款产品分别采用梦幻和超梦主题设计，在便携存储之外加入更适合粉丝和收藏者的外观元素。其中超梦版便携式 SSD 从超梦的力量感汲取设计灵感，最高读取速度为 1000MB/s，性能最高可达传统便携式硬盘的五倍。产品还具备最高两米的跌落防护，适合存储和处理照片、视频等体积较大的文件；容量可选 500GB 和 1TB，售价分别为 119.99 美元 和 199.99 美元。
梦幻版 USB-C 闪存盘采用小巧的口袋式设计，最高提供 128GB 容量。产品支持兼容的手机、平板电脑和电脑，方便用户在不同设备之间保存、传输和读取照片、视频及其它日常文件。128GB 版本的价格为 27.99 美元。来源
多亲发布 J36 AI 按键智能手机
多亲于 8 月 26 日发布一款多亲 J36 AI 按键智能手机，定价 659 元。多亲 J36 搭载 2.8 英寸 480*640 分辨率屏幕、MTK8766V 处理器、3GB + 32GB 存储、2600mAh 电池，运行 Android 13 系统。内置的 QIN AI 支持一句话打开蓝牙、一句话拨打电话、一句话完成 AI 写作。软件功能上，支持微信、支付宝、音乐、视频等各种 app，家长可审批安装、远程禁用、管理时长等；机身内置 FM 收音机、红外遥控。另外多亲 J36 AI 按键智能手机可选有无摄像头版本。有摄像头版本配备 13MP 后置 + 2MP 前置摄像头，无摄像头版本背面取消了镜头模组。来源
Commodore 推出《赛博朋克 2077》主题复古电脑
8 月 26 日，Commodore 团队联合 CD PROJEKT RED，为旗下 Commodore 77 复古电脑推出一款《赛博朋克 2077》主题特别版，这是 Commodore 品牌历史上首次推出基于游戏 IP 打造的联名硬件，目前已经开启预订，售价 377 美元，明年年初发货。
该产品以 Commodore 64 Ultimate 为基础，采用《赛博朋克 2077》风格半透明烟灰色机身，带有金属铭牌及青绿色氛围灯，机身底座同时还拥有可随音乐变化的 LED 灯效。Commodore 77 还提供大量《赛博朋克 2077》主题元素，包括定制版 Commodore 77 BASIC 2.0 开机界面、新菜单配色、霓虹电源灯、贴纸、徽章、主题包装，以及包含游戏世界观资料和《赛博朋克 2077》主题 BASIC 程序的定制螺旋装订说明书。
同时，该产品还附带一款专属 DEMO 演示程序，由波兰 C64 DEMO 团队 Arise 制作，并由芯片音乐制作人 LukHash 创作原声，该 DEMO 卡带仅随 Commodore 77 附赠。
硬件方面，Commodore 77 本质上是一款基于 FPGA 技术打造的 Commodore 64 复刻版复古电脑，主要用于玩 Commodore 64 游戏。相比原版 Commodore 64 的约 1MHz 处理器，新机最高运行频率提升至 77MHz，并采用 AMD Artix XC7A100T FPGA，性能强于 Commodore 64 Ultimate 使用的 XC7A50T。来源
