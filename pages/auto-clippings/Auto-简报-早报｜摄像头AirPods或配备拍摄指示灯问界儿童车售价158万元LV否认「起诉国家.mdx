## 一、核心摘要

本期早报信息密度较高，主要呈现四条主线：

1. **AI 竞争全面转向多模态与 Agent**：OpenAI、DeepSeek、小红书、商汤、百度、字节等均有模型或工具链更新，能力从文本扩展到图像、视频、音频、长上下文和工具调用。

## 二、分类简报

### 1. AI 模型与基础设施

- **OpenAI**：GPT Image 2 API 开始预览透明背景生成，补齐此前 API 不支持透明背景的能力缺口，可用于产品图、平面设计、网站原型和营销素材。同日 LMArena 出现匿名模型 `luna-lisa-alpha`，市场猜测与 OpenAI 下一代图像模型有关，但尚未确认。
- **DeepSeek**：上线实验性视觉理解模型 `DeepSeek-V4-Flash-Vision-Exp`，纯文本 Agent、推理与知识能力与 V4-Flash 正式版基本持平，并补上图像理解。API 支持 Chat Completions、Messages、Responses 三种格式，图片输入支持 base64、URL 和 Files API，单图最多 384 token，计费与 V4-Flash 相同。
- **小红书**：开源 `dots3-note preview`，总参数 2800 亿，推理激活 160 亿，支持 512K token 多模态上下文，可同时接收文本、图像、视频和音频，主要面向知识问答、数学推理、代码生成、工具调用和多步 Agent 工作流。
- **其他简讯**：商汤开源 SenseNova U1.5 正式版，原生支持 4K 图像生成；百度秒哒接入支付宝支付 Skill；豆包工作任务加入技能、连接器和专业 Agent；DeepSeek Harness 新增 Codex 与 Claude Code 子代理接口。
- **百度**：李彦宏在二季度电话会上表示，文心大模型要重回基础模型第一梯队，承认此前有试错，但将集中资源推进 AI 搜索、数字人和秒哒等重点方向，避免同时铺开所有场景。

### 2. 企业战略与资本市场

- **阿里巴巴**：二季度收入 2689.53 亿元，净利润 104.44 亿元，利润下滑主因经营利润减少及投资收益变动。业务架构重组：国内/国际电商、盒马及菜鸟部分业务并入阿里电商集团；云智能集团与平头哥合并为“AI 云与计算服务”；模型实验室、千问消费者业务、QwenWork 组成“AI 实验室与应用”。AI 云与计算服务季度收入 484.37 亿元，AI 相关产品收入连续 12 个季度三位数增长；资本开支增至 676.78 亿元。
- **腾讯芯片负责人创业**：高剑林被曝离职，计划围绕高性能 AI 服务器和 Agentic AI 创业，研发基于 RISC-V 架构的高性能 CPU。此前其团队完成腾讯首颗 TPU 架构 AI 芯片回片。目前腾讯与高剑林均未官宣新公司名称、融资或产品时间表。
- **旺旺**：被曝启动裁员，计划约 1000 人、已裁约 400 人；要求总部员工提交自评报告，由直属和隔级主管评分。董事长蔡衍明此前内部信称公司遭遇“重大经营危机”，要求淘汰无贡献干部。
- **LV**：否认“起诉国家知识产权局遭驳回”的报道，称案件仍在法定程序中，尚未形成最终结论。该案围绕四瓣花图形商标，国家知识产权局此前维持了个体户黄民耀的商标注册，LV 已提起行政诉讼。
- **泡泡玛特**：拟未来 6 个月内回购 20 亿—50 亿元股份；上半年收入 171.7 亿元，经调整净利润 51.6 亿元。王宁称今年大概率无法完成年初营收目标，下半年经营压力高于上半年。
- **奇瑞 AiMOGA**：筹备 IPO，奇瑞持股近 77%。自 2025 年 1 月孵化以来全球交付超 3000 台机器人，其中 2000 台海外；明年目标交付 1 万台。已有 110 台警务机器人在中国多个城市部署。
- **其他简讯**：同程旅行完成收购嘀嗒出行，后者保持独立运营；曝 YouTube 向头部创作者支付独占费用，阻止节目同步给 Netflix。

### 3. 硬件与消费电子

- **带摄像头 AirPods**：更多参数曝光，左右耳机或各配备一枚摄像头，可采集同步彩色静态图像供 Visual Intelligence 分析，目前不支持视频录制。主动模式采集 640×640 图像，输出 1024×1024；被动模式采集 320×320，输出 320×320 或 512×512。代码提到硬件指示灯及亮度控制，暗示可能配备拍摄指示灯。此前 B790 版本据称已取消，苹果转向代号 B798 的新一代产品，预计明年推出。
- **雷鸟 iO**：正式售价 2499 元，首发 1996 元起。34g 双目显示，等效 33 英寸画面，入眼亮度 1800 尼特；无摄像头，配备 4 颗阵列麦克风和 1 颗骨传导麦克风。录音、翻译等功能启用时隐私灯同步亮起且不能通过软件关闭。
- **AMD**：x86 客户端 CPU 出货份额首次突破 30%，达 30.3%，英特尔为 69.7%。一年内提升 6.4 个百分点。该统计不含 Arm 处理器，不代表终端保有量。

### 4. 汽车与监管

- **大规模召回**：特斯拉、小米、小鹏、吉利、零跑、奇瑞、东风、北汽蓝谷和一汽共 9 家车企备案召回约 427.6 万辆汽车。问题为车内应急机械拉手与内饰颜色接近、不易识别和操作，严重碰撞低压系统失效时可能影响逃生和救援。
- **召回规模**：特斯拉约 297.6 万辆（Model 3/Y/X/S），小米约 39 万辆 SU7，零跑约 37.1 万辆 C01/C11，小鹏约 26.5 万辆 G6/P7+/X9。
- **监管趋势**：中国已决定从 2027 年起禁止隐藏式车门外把手；美国监管机构正在研究新安全标准；联合国欧洲经济委员会也在起草断电后仍能从车内外开启车门的相关标准。

## 四、分析师洞察

1. **AI 竞争从“文本基准”转向“多模态 + Agent 工作流”**  
   OpenAI 补透明背景生成，DeepSeek 补视觉理解，小红书开源 512K 多模态模型，豆包加入技能/连接器/专业 Agent，DeepSeek Harness 接入 Codex 与 Claude Code 子代理接口。模型能力不再只拼文本分数，而是拼图像生成、长上下文、工具调用和 Agent 执行能力。开源权重 + API 限时免费成为获客和生态卡位的常见手段。

2. **阿里“AI 云 + 芯片”整合是战略聚焦，但利润承压**  
   将云智能与平头哥合并为“AI 云与计算服务”，显示阿里希望打通从芯片到云到模型的全栈 AI 基础设施。资本开支增至 676.78 亿元，AI 收入连续 12 季度三位数增长，但净利润下滑，说明 AI 投入仍处于重资本、长回报周期阶段。电商业务整合则是对冲主业增长压力的组织应对。

3. **隐藏式门把手从“高端设计”变为“安全负债”**  
   特斯拉带动隐藏式门把手普及，但断电后应急机械拉手不易识别的问题引发行业性召回。中国 2027 年禁令将直接改变新车设计方向，美国与欧洲也在推进相关标准。车企需在造型、成本与安全合规之间重新平衡，相关供应链可能面临调整。

4. **可穿戴设备隐私设计从“可选”变为“合规/卖点”**  
   带摄像头 AirPods 可能配备拍摄指示灯，雷鸟 iO 隐私灯不可软件关闭，表明在被动采集图像/音频的场景下，硬件级隐私提示正在成为产品设计和用户信任的关键要素。未来带摄像头的耳机、眼镜等设备若想进入主流市场，隐私可感知性将是一个重要门槛。

5. **芯片架构多元化加速**  
   AMD x86 客户端份额首次突破 30%，显示英特尔主导地位持续松动；腾讯芯片负责人创业瞄准 RISC-V AI CPU，则反映在 AI 服务器和 Agentic AI 负载下，市场对非 x86 架构的兴趣上升。RISC-V 在 AI CPU 领域的进展值得持续跟踪。
