# 📰 A Visual Guide to Attention Variants in Modern LLMs

**来源**: Ahead of AI
**链接**: https://magazine.sebastianraschka.com/p/visual-attention-variants

## 📝 核心主旨 (TL;DR)
本文系统梳理了现代大语言模型中主流注意力机制的演进路径与工程权衡。从基础的多头注意力（MHA）出发，重点拆解了以降低 KV Cache 开销为核心的 GQA 与 MLA、面向长上下文优化的 SWA 与动态稀疏注意力，以及融合线性状态空间的混合架构（Hybrid Attention）。核心结论指出：行业已从“盲目堆砌全局注意力”转向在**推理显存/计算成本**、**上下文长度**与**建模精度**之间寻找结构化最优解；轻量化、动态筛选与混合骨架设计已成为开源旗舰模型的主流架构趋势。

## 💡 关键知识点 / 核心观点
1. **GQA 与 MLA 的技术分野：头部共享 vs 潜在压缩**
   两者均是为解决 MHA 长序列推理时 KV Cache 内存墙而生的降维方案，但实现逻辑与适用边界不同。GQA 让多个 Query 头共享同一组 K/V 投影，以牺牲极少量建模精度为代价换取显著的缓存体积缩减，具有实现简单、调参鲁棒的优势，是目前 30B~70B 规模模型的“工程甜点区”。MLA（DeepSeek-V2 提出）则放弃共享头部，改为将完整的 K/V 张量压缩为低维潜在表示（Latent Representation）后再缓存，在同等显存节省下能更好地保留原始注意力分布，在百亿级参数与超长上下文中表现出更强的性能维持力，但算图复杂度高、训练稳定性要求更严。

2. **长上下文优化的双轨制：固定局部窗 vs 动态学习稀疏**
   为打破自注意力 $O(N^2)$ 的计算瓶颈，工业界衍生出两种约束范式。其一是**滑动窗口注意力（SWA）**，通过硬编码的局部邻域窗口（如 1024/128 tokens）与全局/局部层数配比（如 5:1 或 3:1）进行信息截断，常与 GQA 组合形成高性价比基线。其二是**DeepSeek 稀疏注意力（DSA）**，摒弃固定窗口，引入“闪电索引器+Top-K选择器”机制，基于压缩后的潜在表征动态计算历史 token 的相关性得分，仅保留高价值片段参与注意力计算。DSA 在保障信息召回精度的同时实现了更激进的算力削减，代表了从“规则限制”向“数据驱动筛选”的架构升级。

3. **混合架构（Hybrid Attention）确立长上下文新范式**
   面对 128k~1M 上下文带来的线性增长压力，纯 Transformer 已触及性价比拐点。新一代架构（Qwen3-Next/3.5、Kimi Linear、Ling 2.5 等）普遍采用“轻量线性状态空间模块 + 周期重型注意力层”的混合骨架。典型比例为 3:1，即大部分层采用 Gated DeltaNet / Lightning Attention / Mamba-2 等线性时间步长的序列 Mixer 以维持近似线性的显存曲线与高吞吐；每第 N 层插入 Gated Attention 或 Gated MLA 负责精确的内容检索与知识对齐。该设计标志着模型架构正式从“全量自注意力”迈向“选择性记忆网络”，在保证长程依赖建模能力的同时将推理延迟与硬件成本大幅压平。

## 🏷️ 提及的重要概念/公司/模型
- **注意力机制变体**: Multi-Head Attention (MHA), Grouped-Query Attention (GQA), Multi-Head Latent Attention (MLA), Sliding Window Attention (SWA), DeepSeek Sparse Attention (DSA), Gated Attention, Hybrid Attention, Linear Attention, State Space Models (SSM)
- **核心组件/技术栈**: KV Cache / 键值缓存, Query/Key/Value 投影矩阵, Causal Mask (因果掩码), Fast-weight Memory (快速权重记忆), Delta-rule Update (增量更新), QK-Norm / RMSNorm, Partial RoPE, Indexer & Token Selector (索引器与选择器)
- **代表性开源模型**: Llama 3, Qwen3 / Qwen3.5 / Qwen3-Next, Gemma 2 / Gemma 3, OLMo 2 / OLMo 3, Mistral (Small 3.1 / Large 3), DeepSeek (V2 / V3 / V3.1 / V3.2 / R1), Kimi K2 / Kimi Linear, GLM-5, Ling 2.5, Trinity (Arcee), Tiny Aya (3.35B / 4.1), Sarvam (30B / 105B), Nemotron
- **核心机构/实验室**: DeepSeek (深度求索), Qwen (阿里云通义), Google DeepMind, Meta AI, Mistral AI, Zero ONE / Zhipu AI (智谱), Moonshot AI (月之暗面), OpenGVLab (上海AI Lab), NVIDIA Research
