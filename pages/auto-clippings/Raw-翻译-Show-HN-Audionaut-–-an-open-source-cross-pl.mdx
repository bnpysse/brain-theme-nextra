Audionaut is a free, open-source desktop application for effortless audio editing and recording. Whether you're working on music, podcasts, or multitrack recordings, it gives you precise cutting, per-track playlists, flexible multi-channel support, and clean exports — without the weight and complexity of a full DAW. Audionaut is written in modern C++ on the JUCE framework and runs natively on Windows, macOS, and Linux.

Audionaut是一款免费开源的桌面应用程序，可轻松实现音频编辑与录制。无论您制作音乐、播客还是多轨录音，它都能提供精确剪辑、分轨播放列表、灵活的多通道支持以及纯净导出——无需承受完整数字音频工作站的臃肿与复杂。Audionaut基于JUCE框架采用现代C++编写，原生支持Windows、macOS和Linux系统。

Audionaut speaks MCP, so Claude and other agents can edit your sessions. With the app and Node.js 18+ installed:

Audionaut支持MCP协议，因此Claude等AI代理可编辑您的工程文件。安装应用和Node.js 18+后运行：

claude mcp add audionaut -- npx -y audionaut-mcp

Keep the project open in Audionaut and each edit arrives as one undo step. On macOS, keep projects in your Music folder. Claude Desktop setup and details: manual, chapter 11.

在Audionaut中保持工程打开状态，每次编辑都会生成独立撤销步骤。macOS系统建议将工程存放在Music文件夹。Claude桌面版设置详见手册第11章。

或克隆后执行：

The analysis features (BIC segmentation, onset detection, beat tracking) link against a static build of the Essentia submodule. Build it once after checking out the submodules:

分析功能（BIC分段、起始点检测、节拍追踪）需链接Essentia子模块的静态库。检出子模块后执行一次构建：

./Audionaut/Builds/build_essentia.sh

The script builds Essentia's 3rd-party dependencies statically (slow, skipped on re-runs; force with FORCE_3RDPARTY=1), then configures and builds Essentia itself with its waf build system into Submodules/essentia/build. It patches Essentia's Linux-oriented 3rd-party build scripts in the working tree as needed for macOS/Apple Silicon, so the essentia submodule will show as dirty afterwards — don't commit those changes.

该脚本会静态构建Essentia的第三方依赖（耗时较长，重复运行时会跳过；可通过FORCE_3RDPARTY=1强制重建），然后使用waf构建系统将Essentia本体编译到Submodules/essentia/build目录。它会针对macOS/Apple Silicon平台修补Essentia原本面向Linux的第三方构建脚本，因此essentia子模块会显示为"dirty"状态——请勿提交这些变更。

Prerequisites:

前置条件：

- Python ≤ 3.11 — Essentia's bundled waf needs distutils , removed in Python 3.12. The script picks a suitable interpreter automatically; override withPYTHON=... ./Audionaut/Builds/build_essentia.sh .

- Python ≤ 3.11 —— Essentia内置的waf需要distutils工具包（Python 3.12已移除）。脚本会自动选择合适解释器，也可通过PYTHON=... ./Audionaut/Builds/build_essentia.sh手动指定

- pkg-config (e.g. brew install pkg-config )

- pkg-config（例如通过brew install pkg-config安装）

- CMake 3.x recommended — some 3rd-party deps ship very old CMakeLists that CMake 4.x refuses (e.g. pip install "cmake~=3.31.0" ).

- 推荐CMake 3.x —— 某些第三方依赖包含的CMakeLists过于陈旧，CMake 4.x会拒绝处理（例如可通过pip install "cmake~=3.31.0"安装）

Building Essentia is optional: without it, ESSENTIA_ENABLED auto-detects off and the app and tests compile with the analysis features disabled.

Essentia的构建是可选的：若不构建，ESSENTIA_ENABLED将自动关闭，应用程序和测试程序会禁用分析功能进行编译。

Stem separation runs demucs.cpp, a C++ port of Meta's Demucs, compiled straight from the Submodules/demucs.cpp submodule — no separate build step. It needs the submodule's vendored Eigen (Submodules/demucs.cpp/vendor/eigen, a nested submodule that --recursive fetches); the CMake build detects it and sets AUDIONAUT_ENABLE_DEMUCS accordingly. The model weights are not in the repository: the app downloads them on first use into its Models folder, or point the CLI at a copy with --model.

音轨分离功能使用demucs.cpp实现（Meta公司Demucs的C++移植版），直接从Submodules/demucs.cpp子模块编译——无需单独构建步骤。该功能需要子模块内嵌的Eigen库（通过--recursive获取的嵌套子模块Submodules/demucs.cpp/vendor/eigen），CMake构建时会自动检测并设置AUDIONAUT_ENABLE_DEMUCS参数。模型权重不包含在仓库中：应用首次使用时会自动下载到Models文件夹，或通过CLI的--model参数指定路径。

audionaut-cli gives scripts, CI and AI agents headless access to .audium projects — no GUI, no audio device. It builds alongside the tests:

audionaut-cli为脚本、CI和AI代理提供无头模式访问.audium工程的能力——无需GUI或音频设备。它与测试程序一同构建：

cmake -B build -S Audionaut/Catch2Tests

cmake --build build -j8 --target AudionautCli

./build/AudionautCli_artefacts/AudionautCli --help

Every command takes --json to emit exactly one machine-readable result envelope on stdout (&#123;"ok": true, "result": ...&#125; or &#123;"ok": false, "error": ...&#125;) with all logging on stderr, plus --quiet. Exit codes: 0 success, 1 operation failed, 2 usage error, 3 feature unavailable in this build (e.g. analyze without Essentia). Option values may be given as --opt value or --opt=value.

所有命令都支持--json参数，在stdout输出标准化机器可读结果（&#123;"ok": true, "result": ...&#125; 或 &#123;"ok": false, "error": ...&#125;），日志输出到stderr，另支持--quiet静默模式。退出码：0成功，1操作失败，2用法错误，3当前构建不支持该功能（如未编译Essentia时使用分析功能）。参数值可用--opt value或--opt=value形式传递。

audionaut-cli create  song.audium --channels 2

audionaut-cli import  song.audium take1.wav take2.wav --position 4.5

audionaut-cli info    song.audium --json

audionaut-cli analyze song.audium --types sbic,beat_degara

audionaut-cli auto-edit song.audium --track 0 --measures 4

audionaut-cli assemble  song.audium --duration 60 --mode random

audionaut-cli split   song.audium --at 23              # bar 23; --unit beats|seconds|clocks

audionaut-cli create-region song.audium --name chorus --start 17 --end 25

audionaut-cli set-region  song.audium --region chorus --rename drop --length 8

audionaut-cli place-clip  song.audium --region drop --at 33

audionaut-cli move-clip   song.audium --region drop --to 41

audionaut-cli remove-clip song.audium --at 41 --track 0

audionaut-cli clip-gain   song.audium --region drop --gain -6 --db

audionaut-cli clip-fades  song.audium --region drop --fade-in 1 --fade-out 2 --unit beat
