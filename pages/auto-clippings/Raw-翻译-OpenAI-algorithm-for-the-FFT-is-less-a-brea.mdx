The fast Fourier transform is a clever recursive procedure devised by James Cooley and John Tukey in 1965.² The main idea is that a length-n Fourier transform can be computed by shuffling the input vector, computing two Fourier transforms of length n/2 on the shuffled components, and then recombining the outputs using atomic arithmetic operations. The shuffles and recombinations take a linear number of arithmetic operations. Repeating this procedure iteratively, namely, log₂(n) times, computes the full discrete Fourier transform. With the bookkeeping, the FFT computes a length-n Fourier transform in fewer than 5 n log₂ n arithmetic operations.

快速傅里叶变换是由James Cooley和John Tukey于1965年发明的一种巧妙的递归过程。² 其主要思想是：通过打乱输入向量，对打乱后的分量计算两个长度为n/2的傅里叶变换，然后使用原子算术运算重新组合输出结果，即可计算出长度为n的傅里叶变换。打乱和重组的操作需要线性数量的算术运算。重复这个过程（即迭代log₂(n)次）就能计算出完整的离散傅里叶变换。通过这种记账方式，FFT在少于5 n log₂ n次算术运算内即可完成长度为n的傅里叶变换。

To make this acceleration concrete, when n is 1,000, n² is 1,000,000 and 5 * n log n is around 50,000, a 20-fold speedup. When n is 1,000,000, the speedup is 10,000-fold. These speedups can be the difference between a transform being computable or not given the constraints of a signal processing application.
