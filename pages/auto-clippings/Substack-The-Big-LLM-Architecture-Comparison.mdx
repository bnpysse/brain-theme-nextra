# 📰 The Big LLM Architecture Comparison

**来源**: Ahead of AI
**链接**: https://magazine.sebastianraschka.com/p/the-big-llm-architecture-comparison

## 📝 核心主旨 (TL;DR)
尽管LLM底层骨架（Transformer）在过去七年中保持高度相似，但2025年的架构演进已彻底告别“宏观结构颠覆”，全面转向“微观效率与稳定性精调”。当前旗舰开源模型的设计共识在于：通过注意力机制变体（MLA/滑动窗口）与MoE稀疏路由解耦参数总量与推理算力；通过归一化层位置重构与QK-Norm提升训练动力学稳定性；并深度结合硬件特性（端侧流式加载、动态切片、算子级延迟优化），在维持甚至扩大模型知识容量的同时，实现部署成本与推理延迟的系统性压降。

## 💡 关键知识点 / 核心观点
1. **注意力机制的“显存-性能”权衡取代标准MHA**：为缓解KV Cache带来的显存墙，架构师分化为两条路径。DeepSeek V3/R1采用Multi-Head Latent Attention (MLA)，先将KV张量压缩至低维潜空间存储，推理时再投影还原。消融实验显示，MLA不仅显存占用更低，且建模性能略优于主流的GQA。Gemma 3则另辟蹊径，大幅提升Sliding Window Attention（局部注意力）比例至5:1（全局:局部），并将窗口缩至1024，在几乎不增加困惑度的前提下实现KV Cache的断崖式下降。
2. **MoE成为Scaling定律下的默认基础设施**：2025年顶级基座模型几乎全员拥抱MoE，核心价值在于将“总参数量”与“每步激活参数量”脱钩（如DeepSeek V3总计671B但仅激活37B；Llama 4为400B总参/17B激参）。设计哲学出现分化：DeepSeek沿用大量小专家+全局共享专家以强化通用模式学习；Llama 4采用交替密集/稀疏块配合少数大专家；Qwen3则直接砍掉共享专家以降低算子冗余。官方同步发布Dense与MoE双版本，以兼顾轻量化微调生态与大规模高并发推理需求。
3. **归一化布局与QK-Norm重塑训练收敛曲线**：Pre-Norm虽为GPT/Llama系标配，但OLMo 2验证了将RMSNorm置于残差分支内部（Modified Post-Norm）可显著提升训练震荡期的稳定性。同时，QK-Norm（在RoPE前对Q/K独立施加RMSNorm）被OLMo 2、Gemma 2/3广泛集成，有效平滑注意力分数分布。Gemma 3进一步创新，在Attention与FFN模块前后同时放置Norm层，以极低的计算开销换取更强的梯度容错与收敛鲁棒性。
4. **硬件感知设计推动架构向“场景定制化”演进**：纯算法指标不再是唯一标尺，端侧适配与推理延迟成为架构决策权重。Google Gemma 3n引入Per-Layer Embedding (PLE)，将部分词表/模态嵌入卸载至CPU/SSD按需读取，并搭配MatFormer实现单架构的多粒度动态裁剪。Mistral Small 3.1则反向操作，主动放弃滑动窗口的理论显存收益，转而依赖定制Tokenizer压缩Prompt长度、削减网络深度，并追求与FlashAttention的最佳兼容性，以锁定最低Token生成延迟。这标志着LLM架构已进入“计算图即产品形态”的工程深水区。

## 🏷️ 提及的重要概念/公司/模型
**🏢 核心公司/研究机构**：DeepSeek、Allen Institute for AI (OLMo)、Google (Gemma)、Mistral AI、Meta AI (Llama)、阿里云/Qwen团队
**🤖 重点模型系列**：DeepSeek V3 / R1、OLMo 2、Gemma 3 / 3n、Mistral Small 3.1 (24B)、Llama 4 Maverick、Qwen3 (含0.6B~235B-Dense及30B/235B-MoE)、Llama 3、GPT-2
**⚙️ 关键技术/架构概念**：
- `注意力变体`：Multi-Head Latent Attention (MLA)、Grouped-Query Attention (GQA)、Multi-Head Attention (MHA)、Sliding Window / Local Attention
- `稀疏化架构`：Mixture-of-Experts (MoE)、Shared Expert、Sparse vs. Dense Transformer、Active Parameters
- `层规范与动力学`：Pre-Norm / Post-Norm / Modified Post-Norm、QK-Norm、RMSNorm、Gradient Stabilization
- `部署与硬件优化`：KV Cache Management、Per-Layer Embedding (PLE)、MatFormer (Dynamic Model Slicing)、FlashAttention、Custom Tokenizer
