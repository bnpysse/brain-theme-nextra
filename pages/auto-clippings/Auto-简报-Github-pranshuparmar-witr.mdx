### 核心总结
- **核心功能**：witr 是一款用于追踪进程、端口、容器或文件启动链的工具，旨在精准解答系统资源“为什么在运行（Why is this running?）”。
- **解决痛点**：弥补了 `ps`、`top` 等传统工具只展示运行状态而缺乏因果关系解释的不足，将复杂的系统调用链和因果关系显式化。
- **产品特性**：支持机器可读的 JSON 输出与交互式 TUI 仪表盘，全面兼容 Linux、macOS、Windows 和 FreeBSD，并提供一键脚本及丰富的包管理器（如 Homebrew、apt、Winget 等）安装方式。
