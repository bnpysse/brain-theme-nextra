drawgent: your coding agent on a live Excalidraw canvas#

drawgent：实时Excalidraw画布上的编程代理#

drawgent connects your own Claude Code, Codex or opencode (your install, login, config and

repo) to an Excalidraw whiteboard. Ask for a diagram in the chat panel, or write AGENT: …

next to the part of a drawing you want changed. The agent looks at the canvas (screenshot +

scene), edits it live, checks the result, and marks the note DONE.

drawgent将您本地的Claude Code、Codex或opencode（需自行安装/登录/配置/仓库）连接到Excalidraw白板。在聊天面板请求图表，或在需要修改的绘图旁标注AGENT:...。代理会实时查看画布（截图+场景）、进行编辑、检查结果，并将备注标记为DONE。

drawgent up#

drawgent up启动#

Runs in the current directory (the workspace):

在当前目录（工作区）运行：

- starts the editor + API on 127.0.0.1:7300 (next free port if taken);

- 在127.0.0.1:7300启动编辑器+API（端口占用时自动选择下一可用端口）

- starts a new session of your agent over ACP, working in the workspace;

- 通过ACP启动新代理会话，在工作区运行

- opens your browser. On a headless box it prints the ssh -L command instead.

- 打开浏览器（无头模式会打印ssh -L转发命令）

Connects the canvas to a session you already run. Without an id it lists the sessions it finds (current directory first) and lets you pick one:

将画布连接到已有会话。无id参数时会列出可检测到的会话（当前目录优先）供选择：

|---|---|---|

| Claude Code | claude agents --json (interactive and background sessions) | fork: a new session carrying the full conversation, driven by drawgent over ACP. Your terminal session is left untouched |

Using the canvas#

画布使用指南#

- Chat panel (right side): send a request, watch replies and tool calls stream in, approve permission prompts, press Stop to cancel a turn.

- 聊天面板（右侧）：发送请求，查看回复和工具调用流，审批权限提示，按Stop取消当前轮次

- On the canvas: write a text starting with AGENT: next to or inside a shape, or draw an

arrow from the note to a shape. It fires about 2.5 s after you stop typing, with its

position, what it points at and what is nearby. The agent resolves it into a greenDONE: … note. Edit it back toAGENT: to send it again.

- 画布操作：在图形旁/内部以AGENT:开头的文字，或从备注指向图形的箭头。停止输入2.5秒后触发，代理会根据位置/指向目标/周边元素将其解析为绿色DONE:备注。重新编辑为AGENT:可再次发送

- Prompts are queued and run one at a time. A queued note that was already handled is skipped.

- 提示按队列顺序执行，已处理的排队备注会自动跳过

excalidraw.com rooms#

excalidraw.com协作房间#

drawgent up --room 'https://excalidraw.com/#room=&lt;id&gt;,&lt;key&gt;'

drawgent up --room 'https://excalidraw.com/#room=&lt;id&gt;,&lt;key&gt;'

- drawgent joins the room as a collaborator (🤖 Agent , with a cursor that follows its edits).

Humans can stay on excalidraw.com: theirAGENT: notes reach your agent, and its edits

appear there live.

- drawgent以协作者身份加入房间（🤖 Agent机器人，光标随编辑移动）。人类用户可在excalidraw.com正常操作：其AGENT:备注会传递至您的代理，代理的编辑实时可见

- Traffic is end-to-end encrypted with the room key. Empty rooms are loaded from and saved to excalidraw's Firestore storage.

- 通信使用房间密钥端到端加密。空房间从Excalidraw的Firestore存储加载/保存

- The local editor mirrors the room and still has the chat panel.

- 本地编辑器同步房间状态，并保留聊天面板

其他命令#

- drawgent mcp：带画布工具的stdio MCP服务器。由代理启动，自动寻找运行的drawgent up实例

- drawgent serve : low-level server with explicit agents (--agent claude,codex,opencode as set up,

orname=command for any ACP agent); for scripts and containers.

- drawgent serve：底层服务器（通过--agent显式指定claude/codex/opencode，或name=command自定义ACP代理），适用于脚本和容器
