HiSparse

HiSparse

To overcome this limitation, the SGLang team designed HiSparse, a hierarchical memory system that proactively offloads KV cache entries from device HBM to host DRAM.

为突破此限制，SGLang团队开发了HiSparse分层内存系统，主动将KV缓存条目从设备HBM卸载至主机DRAM

HiSparse behaves like an LRU (Least Recently Used) cache

HiSparse采用类LRU（最近最少使用）缓存机制

, where it loads tokens from DRAM to HBM upon top-k selection cache miss, and it offloads tokens from HBM to DRAM based on the LRU eviction policy. To reduce the cache miss latency, HiSparse overlaps KV cache loading of layer N with the execution of layer N-1 (layer-wise overlapping), introduced in HiSparse’s prior work HiCache.

当top-k选择缓存未命中时从DRAM加载token至HBM，并依据LRU淘汰策略将token从HBM卸载至DRAM。为降低缓存未命中延迟，HiSparse采用层间重叠技术——在HiCache前期工作中提出的将第N层KV缓存加载与第N-1层执行重叠的机制
