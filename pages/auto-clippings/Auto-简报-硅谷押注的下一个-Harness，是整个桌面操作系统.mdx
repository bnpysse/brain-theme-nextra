# 简报｜硅谷押注的下一个 Harness，是整个桌面操作系统

**来源：** 极客公园  
**作者：** 张勇毅  
**链接：** http://www.geekpark.net/news/369298

---

## TL;DR

本文认为，Omarchy 4.0 的真正意义不是“AI 操作系统”，而是“AI 读得懂的操作系统”。它把整个桌面环境文本化、脚本化、插件化，使 AI Agent 能像人一样读取、修改、执行并观察反馈，从而把 Harness 从应用层下沉到操作系统层。DHH 与八位产业领袖各投 100 万美元成立 Omacom 基金会，押注的不是 Linux 市场份额，而是模型之上、硬件之下这一二十年未变的新层——操作系统定义权，以及 AI 接管操作电脑后新的硬件分发与软件入口逻辑。

---

## 核心观点与技术/商业洞察

### 1. 系统即 Harness：Omarchy 的架构本质

Omarchy 4.0 的核心卖点不是“内置 AI”，而是把整个操作系统改造成 AI Agent 可读、可写、可执行、可反馈的环境。

- 桌面环境被重写为单一进程 **Quickshell**，状态栏、启动器、菜单、通知、锁屏全部纳入其中。
- 系统配置全部改为 **Lua 脚本**，插件就是一个 **Git 仓库**。
- 外部程序可以直接给 Shell 发指令，系统里每一个部件都是文本文件，改完立刻看到结果。

这意味着，一个 Agent 所需的四样东西——**工具、权限、状态、反馈**——Omarchy 全部原生具备。文章用一句话点破：

&gt; “这个操作系统，本身就是一个 Harness。”

过去一年，Harness 一直是应用级产品（OpenClaw、Claude Code、DeepSeek Harness 等），Omarchy 把它往下压了一格，压进了操作系统。这是产品架构层面的关键差异。

### 2. 范式转移：从“给人用的 GUI”到“给 AI 读得懂的系统”

文章提出一个尖锐对比：苹果和微软的 AI（Apple Intelligence、Copilot）做的是“按钮”——能看屏幕、读剪贴板、总结邮件，但改不了系统。封闭系统、签名、沙盒，每一层都在阻止任何程序碰系统本身，AI 也不例外。

这不是模型能力问题，而是**不敢交出系统**。苹果微软背着几十亿用户，每一次放开系统权限都是一次事故风险，不可能把钥匙交给一个每周都在变的 AI。

Omarchy 押的是硬币反面：

&gt; “操作电脑这件事要换主体。如果操作电脑的变成 Agent，系统要先让 Agent 看得懂、改得动，人只负责说要什么。”

这背后不是新技术，而是 Unix 五十年前的老规矩：**一切皆文件**。苹果微软花了二十年把这条规矩藏到 GUI 后面，Omarchy 把它重新翻到台前，Agent 正好读得懂。小厂没有几十亿用户包袱，跑的方向是操作系统定义本身。

### 3. 800 万美元的商业逻辑：不是投资，是牌桌门票

8 月 21 日，DHH 宣布成立 Omacom 基金会，首期 800 万美元来自八个人，每人 100 万。名单包括：

- 戴尔创始人 Michael Dell
- 推特联合创始人 Jack Dorsey
- Shopify CEO、Stripe CEO
- Cloudflare CEO
- Oculus 联合创始人
- 37signals 两位创始人（DHH 自己是其中之一）

文章分析，这 100 万对这些人“不算钱”，更像一张门票：先坐进下一代桌面操作系统的牌桌，再看牌怎么发。

**硬件厂商的算盘：**  
戴尔和 Oculus 创始人是硬件出身。过去两年“AIPC”概念一直由微软定义，PC 厂商只能跟着走。但如果下一代桌面的操作者变成 Agent，操作系统就不一定还是 Windows，戴尔手里就多了一条不经过微软的路。Omarchy 4.0 专门给 2026 款 XPS 调了扬声器，Framework 去年已将其列为官方支持系统。

**软件/平台厂商的算盘：**  
Shopify、Stripe、Cloudflare、Block 都养着成千上万名开发者。一个让 Agent 替人操作电脑的系统，省下的是工程师时间。37signals 已宣布三年内把运维和 Ruby 团队全部换过去。更重要的是**下一代应用分发入口**：如果装好电脑第一件事是唤出 Agent，那它默认调用谁家的服务，谁就白拿一个新入口。Omarchy 官网和软件源镜像现在就跑在 Cloudflare 上。

文章强调，这些人押的不是 Linux 市场份额——Omarchy 连 Apple Silicon 都不支持，不会替代 macOS 和 Windows。他们押的是**模型之上、硬件之下的一层新东西**，这一层正在从应用变成操作系统，而操作系统层已经二十年没有新玩家了。

### 4. 与 OpenClaw 的对照：硬件红利的转移

文章将 Omarchy 与年初爆火的 OpenClaw（龙虾）类比：

- OpenClaw 也是一个人的业余项目，把 Agent 装进电脑、给它真实权限，三个月星数超过 Linux 本身。
- 创始人被 OpenAI 招走，项目交给基金会。
- 它顺手把 Mac mini 卖到断货，Mac 销量逆势涨 6%，苹果什么都没做。

上一波硬件红利落在苹果头上，这一波戴尔们不想再当看客。区别在于：OpenClaw 之后，大厂把命令行打包成图标，普通人才真正用上；Omarchy 还停在开发者圈，那一步“打包”还没发生——而这可能正是 800 万要买的东西。

### 5. 现实边界：半成品、脆弱性与门槛

文章没有回避 Omarchy 4 的局限：

- **系统级脆弱**：Codex 升到 0.149，状态栏用量显示就坏了；Gemini 命令行工具改名，默认列表就过期。九家模型能力每周都在变，系统级集成意味着系统级脆弱。
- **门槛只拆了一半**：AI 替你敲了命令行，但没替你记快捷键。平铺式窗口管理器的学习曲线是英文社区最一致的抱怨。
- **中文仍是二等公民**：输入法引擎要自己装，语音输入基本只认英文。
- **硬件挑人**：Apple Silicon 要靠社区分支绕路，NVIDIA 50 系显卡装完黑屏，连专门调过音的 XPS 13 都有人报滚动卡顿。

一句话总结：

&gt; “AI 接管的是操作电脑这件事，接管不了 Linux 的老毛病。该坏的地方照坏，只是现在坏了，有人替你修。”

### 6. 命名哲学：从 Omakase 到自选

Omarchy 来自 **Omakase**，日料里的“主厨推荐”，也是 Rails 一直以来的哲学：别选了，按我配的来。Omarchy 3 之前一直靠 DHH 个人品味小范围口口相传。

4.0 之后，系统对 AI 可读可写，意味着每个人都能把 DHH 的口味改成自己的口味。如果这条路走通，以后每个人电脑里的系统，可能都是自己和 AI 一起攒出来的那一个。

## 对行业的启发与影响

### 1. 操作系统层可能重新洗牌

过去二十年，桌面操作系统层没有新玩家。Omarchy 的出现提示：**AI Agent 可能成为操作系统的一等公民**，而不仅是应用层功能。如果“操作电脑的主体”从人变成 Agent，那么系统设计的核心问题就从“人怎么点得动”变成“Agent 怎么读得懂、改得动”。这会动摇以 GUI 为中心的 OS 设计范式。

### 2. 大厂“按钮式 AI”面临结构性挑战

苹果和微软的 AI 策略是保守的——AI 作为助手，但不能碰系统。Omarchy 证明，小厂可以靠“交出系统钥匙”获得开发者社区的爆发式响应（10 天 1,074 个插件）。大厂难以自我颠覆，但可能被迫在“开放系统权限”和“保持封闭安全”之间重新权衡。

### 3. 硬件厂商获得绕开微软的潜在路径

戴尔、Framework 等硬件厂商对 Omarchy 的支持，本质是在 AIPC 定义权上对冲微软。如果 AI 原生操作系统成熟，PC 厂商可以不再依赖 Windows 的 AI 能力，而是直接预装一个 Agent 可操作的系统。这可能改变 PC 产业链的权力结构。

### 4. 应用分发入口可能从应用商店转向 Agent 默认调用

如果用户装好电脑第一件事是唤出 Agent，那么 Agent 默认调用谁家的服务（云、支付、电商、开发工具），谁就掌握了新的分发入口。Cloudflare 托管 Omarchy 官网和软件源镜像，Shopify、Stripe 的参与，都指向这一逻辑。

### 5. 开源小团队在操作系统定义权上可能领先

Omarchy 和 OpenClaw 都是个人业余项目起家，靠开源社区快速建立生态。这说明在 AI 原生系统这一新层，**速度、架构灵活性和无用户包袱**比资源规模更重要。大厂有资源，但难以下决心把系统钥匙交给 AI。

### 6. 从开发者出圈仍需“打包”和本地化

Omarchy 目前仍停留在开发者圈，中文支持、硬件兼容、学习曲线都是出圈障碍。文章暗示，800 万美元要买的可能正是“把命令行打包成图标”的那一步——让普通人真正用上。谁能完成这一步，谁就可能复制 Mac 从开发者到大众的路径。

### 7. 长期愿景：操作系统从“给人用”到“人机协作”

Omarchy 的终极想象不是替代人，而是让每个人和 AI 一起“攒”出自己的系统。这呼应了极客一问：

&gt; “下一代操作系统，是给人用的还是给 AI 用的？”

答案可能是：**给人用，但由 AI 操作；人负责意图，AI 负责执行。** 这是“AI 接管”的真正含义——不是替你做决定，是替你操作系统。
