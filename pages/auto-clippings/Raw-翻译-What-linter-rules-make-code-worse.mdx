【帖子标题】：哪些代码审查规则会让代码变得更差？

【帖子正文】：

对于我来说，一个典型的例子是

S101

该规则禁止使用

assert

语句。

其理由是在以

-O

选项运行 Python 时，断言会消失，因此不应该用于运行时验证或接口约束。这条警告是正确的，但这个规则似乎从这个事实中得出了错误的结论。

断言对于检查内部不变量仍然非常有用，即那些应该由程序逻辑已保证的条件，失败表明存在bug。拥有这样的断言对于调试来说极其有帮助。

因此，全面禁止反而更有可能阻止有用的检查而非防止误用。

你认为有哪些代码审查规则总体上更有害而不是有益？
