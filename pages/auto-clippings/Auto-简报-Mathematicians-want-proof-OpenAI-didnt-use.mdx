# 精华简报：数学家要求 OpenAI 证明未使用其工作

## TL;DR

OpenAI 近期的数学突破——包括“非 sofic 群”成果以及涉及纳维-斯托克斯千年难题的解法——在学术圈引发强烈质疑。多位数学家认为，OpenAI 可能通过用户与 ChatGPT/Codex 的互动，间接吸收未发表的研究思路或专业内容，用于训练模型或辅助推理，却未披露、未获同意、未署名。OpenAI 仅否认“直接访问特定用户数据”，但不排除“去标识化数据”间接帮助模型，这种模糊区分被批评为不诚实，进一步加剧了 AI 公司与学术界之间的信任危机。

## 核心观点与技术/商业洞察

### 1. 两起争议：从 Buckmaster 到 Thom

- 纽约大学教授 Tristan Buckmaster 与 Anthropic 研究员 Levent Alpöge 私下研究纳维-斯托克斯千年难题。OpenAI 宣布解决该问题后，Buckmaster 质疑模型是否受益于他使用 Codex 的经历。OpenAI 公开回应称“研究者或智能体在对方公开发布前未以任何方式看到其工作”，并否认访问特定用户数据，但同时补充“无法排除去标识化数据帮助改进模型”。
- 数学家 Andreas Thom 随后公开质疑 OpenAI 在“非 sofic 群”上的成果。该领域是 Thom 与 Gábor Kun 的专长，OpenAI 的成果被承认高度依赖二人先前工作，但最初未充分致谢，之后才“悄悄修改”。
- Thom 观察到，自己与同事曾与 ChatGPT 互动，且 OpenAI 对其技术路线的掌握程度“详细到不寻常”，怀疑这些交互进入了训练数据或推理可访问范围。

### 2. “去标识化”之争：名字可删，思想不可删

- Thom 询问 OpenAI 研究员，自己的 ChatGPT 对话是否成为训练数据或被推理过程访问。对方只回答“不能直接访问对话”，但未说明是否进入训练数据池。
- Thom 认为这是“不诚实”：OpenAI 用“去标识化”淡化问题，但数学思想的知识内容不会因为移除姓名而消失。
- 如果未发表研究被用户输入后用于提升模型，再由模型反过来与研究者竞争发表，这在伦理上不可辩护。

### 3. 举证责任在谁？

- 研究者没有能力逆向工程 OpenAI 的训练管线，只有 OpenAI 掌握相关数据。因此，若要否认使用了某些用户工作，责任应在 OpenAI：披露所有必要数据集，澄清数据使用条款和设置。
- 当前 OpenAI 的回应停留在“直接访问”层面，未提供可验证证据排除“间接影响”，形成信息不对称。

### 4. 更深层的学术生态风险

- 数学界担忧：若科技巨头仅凭网络传言得知某研究者接近突破，并迅速投入资源发起竞赛，可能迫使数学家转向保密，减少预印本公开和学术交流。
- OpenAI 的“胜利时刻”因此蒙上阴影：即使千年难题解法最终被验证，其获取数据和灵感的方式若不透明，学术共同体难以给予完全信任。

## 启发与影响

### 对 AI 行业

- 必须建立可审计的训练数据来源机制。只承诺“未直接访问”不够，需能证明哪些数据被用于训练、哪些被排除，尤其是专业用户输入的高价值内容。
- 去标识化不能成为规避知识产权和伦理责任的理由。训练数据治理需从“身份匿名”升级到“思想/内容溯源”。
- 竞争优势若建立在不透明利用用户专业输入上，会引发用户流失、法律诉讼和监管干预。

### 对学术界与研究者

- 使用 ChatGPT/Codex 等工具时需重新评估风险：未发表的想法、证明思路、代码可能被系统记录并进入训练流程。
- 学术机构应制定 AI 工具使用规范，明确哪些工作内容不可输入第三方模型。
- 可能需要新的引用、致谢和披露规则，以应对 AI 公司参与科研竞赛的伦理问题。

### 对监管与政策

- 生成式 AI 训练数据的透明性应成为监管重点，包括用户数据是否用于训练、如何选择、如何排除。
- 需要界定“去标识化数据”在知识产权语境下的含义，尤其在专业领域，匿名化不足以保护原创思想。
- 可能要求模型提供商保留数据溯源记录，并在争议发生时承担举证责任。

### 对 OpenAI 及同类公司

- 信任是科学合作的基础。若不能自证清白，里程碑成果的公信力将大打折扣。
- 主动披露数据管线、发布审计报告、设置用户数据退出机制，比事后“措辞精确的否认”更能修复关系。
- 在科研竞赛中，OpenAI 需要明确伦理边界：不应利用用户未公开的研究来抢占发表先机。
