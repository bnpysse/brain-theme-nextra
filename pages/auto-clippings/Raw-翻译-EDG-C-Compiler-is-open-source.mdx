【文章标题】：EDG C++ 编译器开源

【文章正文】：

Welcome to the open source EDG C/C++ compiler project!

欢迎加入开源的EDG C/C++编译器项目！

The EDG C/C++ front end is the primary focus of this repository. The EDG front end is known for: its excellent parsing compatibility and bug emulation, to make sure source that compiles with Clang, GCC, and MSVC compiles with EDG; extensive documentation, to assist with development and modification; and extreme configurability, to allow it to be derived for use into a large number of C/C++ oriented products.

EDG C/C++前端是本代码库的核心部分。该前端以三大特性著称：卓越的解析兼容性与错误模拟能力，确保能与Clang/GCC/MSVC编译的源码同样通过EDG编译；详尽的文档支持，助力开发与修改；极致的可配置性，可衍生应用于大量C/C++相关产品。

The compiler project also includes: a C-generating back end, which can be used to generate C code for C++ programs; a C++-generating back end, which is useful for source-to-source transformation applications; a prelinker, which handles automatic template instantiation; a minimal runtime support library (but not any "real" libraries, e.g., for stream I/O); utilities to write the intermediate language to a file, read it back in, and display it in human-readable form; a name demangler; and a collection of purpose built development tools.

该项目还包含：可生成C++程序对应C代码的C语言后端；适用于源码转换应用的C++生成后端；处理自动模板实例化的预链接器；最小化运行时支持库（不包含流I/O等"完整"库）；中间语言文件读写及可视化工具；名称还原器；以及一系列专用开发工具。

See the documentation on: https://edgcpp.org/doc/.

完整文档请见：https://edgcpp.org/doc/

Note

注意

If you would like to build a local copy of the documentation see the documentation build guide.

如需本地构建文档，请参阅文档构建指南。

To get started, it's recommended for most people to clone the repository using a partial clone (this keeps a full copy of the git history while only downloading the most recent version of each file, git can implicitly fetch older versions as needed):

建议初学者使用部分克隆获取代码库（在保留完整git历史记录的同时仅下载文件最新版本，git会根据需要自动获取旧版本）：

git clone --filter=blob:none git@github.com:edgcpp/compiler.git

If you are looking to build the front end from source and use it, please see the build instructions.

如需从源码构建前端并使用，请参阅构建指南。

If you are looking to make changes to the front end, please see the contribution guide and the development guide for quickly getting setup.

如需修改前端代码，请查阅贡献指南和开发指南快速配置环境。

To further aid humans and AI agents in product development there is additional documentation for tips, tricks, and tutorials that can be found in the development annex.

开发附录中还提供了技巧指南和教程文档，可助力开发者和AI智能体进行产品研发。
