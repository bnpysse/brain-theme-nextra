# 📰 Gemini is Cooked but GCP is Cooking

**来源**: SemiAnalysis
**链接**: https://newsletter.semianalysis.com/p/gemini-is-cooked-but-gcp-is-cooking

## 📝 核心主旨 (TL;DR)
Google正经历从“前沿AI研发驱动”向“基础设施商业变现驱动”的底层战略切换。随着DeepMind核心领军人物集体出走及顶级算力资源被大幅倾斜至公有云业务，Gemini系列模型已实质丧失争夺技术SOTA的组织决心与硬件底座；与此同时，GCP通过大规模对外打包销售TPU计算系统及云端基础设施，成功实现营收结构与利润曲线的爆发性跃迁。文章核心结论明确：Google管理层已主动放弃短期内追赶AGI前沿的竞争姿态，将DeepMind降级为常规模型维护部门，全面押注云业务的“系统级TaaS变现”以兑现确定的财务回报。

## 💡 关键知识点 / 核心观点
1. **领导力真空与前沿研发失速的逻辑链条**：Demis Hassabis退居二线，Jeff Dean携Sanjay Ghemawat、Quoc Le、Oriol Vinyals等顶梁柱出走成立“Discovery Loop”，并非单纯的人事变动，而是对现有技术路线与资源分配的无声否定。Gemini自2025年底的3 Pro触顶后，后续版本（3.5/3.6/4系列）在推理、代码生成及多模态对齐上持续落后于OpenAI、Anthropic及国内一线模型。API调用量增速从60%骤降至38%，叠加强化学习（RL）团队大规模流失，证明Google已缺乏支撑下一代基座模型突破的“技术信仰”。
2. **内部算力政治决断：云业务总裁Thomas Kurian胜出**：算力是AI进步的氧气，但Google内部出现了严重的战略割裂。云部门主导了算力分配权的争夺，将原本应用于前沿训练的TPU大量以长期合约形式出售给Anthropic、Meta、Citadel及政府机构。这标志着Google将自身重新定位为“中立的基础设施平台”，通过牺牲自身模型的算力独占性，换取更高确定性的市场覆盖率与客户粘性。
3. **GCP的“系统级TaaS”模式与财务杠杆效应**：GCP的增长引擎已从传统云服务器转向整机柜级别的TPU系统售卖（定价约350亿美元/GW规模）。该模式会计处理采用总额法，直接推高营收基数。当前积压订单超1500亿美元，预计未来数月还将新增超2500亿美元的RPO（剩余履约义务）。尽管系统销售的EBIT利润率略低于纯软件/托管云（稳定在30%上下区间），但其规模效应将推动GCP 2027年营收同比增速突破100%，并为母公司贡献约3美元的EPS增量。
4. **企业级Agent平台的“曲线救国”路径**：在一阶自有模型增长见顶的背景下，Gemini Enterprise Agent Platform（原Vertex）成为实际的业务压舱石。该平台通过无缝集成第三方高质量模型（如Claude）、提供企业级安全网关与工作流编排能力，维持了强劲的B端需求。这表明Google当前的务实策略是：放弃底层的“造剑”内卷，转而在应用层构建兼容多模型的“武器库”分发网络。
