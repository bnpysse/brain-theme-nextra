# 📰 Beginnings

**来源**: The Wondrous Mind of Dereck Bearsong
**链接**: https://dereckbearsong.substack.com/p/beginnings

## 📝 核心主旨 (TL;DR)
作者 Dereck Bearsong 通过这篇开篇之作介绍了个人背景与博客愿景，并重点分享了他为拒绝 Windows 11 的隐私侵犯与系统臃肿，将个人桌面迁移至 Linux Mint 并改造为本地 AI 与自动化应用服务器的技术实践，未来博客将聚焦于本地大模型（LLM）与自动化工作流（如 n8n）的深度结合。

## 💡 关键知识点 / 核心观点
1. **操作系统迁移与隐私保护实践**：在 Windows 10 即将 EOL（生命周期结束）的背景下，作者拒绝转向带有持续遥测（Telemetry）和隐私妥协的 Windows 11，选择迁移至轻量且注重隐私的 Linux Mint。这反映了技术极客对系统臃肿的抵制，以及对数据隐私和系统底层掌控权的重视。
2. **基于 Docker 的本地化 AI 与自托管架构**：作者将个人桌面改造为自托管应用服务器（App Server），并通过 Docker 容器化技术统一部署了 SearXNG（隐私搜索）、Ollama 与 OpenWebUI（本地大模型交互）、以及 Stable Diffusion（本地 AI 绘图）。这展示了一套完整的、脱离云厂商依赖的本地化 AI 基础设施搭建方案。
3. **AI 与自动化工作流的深度融合**：作者将 n8n（开源自动化平台）与 Ollama（本地大模型运行框架）作为核心探索方向。其核心逻辑在于利用本地大模型的推理与生成能力赋能 n8n 工作流，探索“AI + 自动化”在提升个人及团队效率中的实际落地场景。

## 🏷️ 提及的重要概念/公司/模型
- **操作系统**: Linux Mint, Windows 10, Windows 11
- **AI 模型与框架**: Ollama (本地大模型运行框架), OpenWebUI (大模型交互界面), Stable Diffusion (AI 图像生成模型)
- **自动化与搜索工具**: n8n (工作流自动化平台), SearXNG (开源隐私搜索引擎)
- **技术架构与概念**: Docker (容器化技术), App Server (应用服务器), Self-hosting (自托管), Telemetry (遥测技术), EOL (End of Life / 产品生命周期结束)
