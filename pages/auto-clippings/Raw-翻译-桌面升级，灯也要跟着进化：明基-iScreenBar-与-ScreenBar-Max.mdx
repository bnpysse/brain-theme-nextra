【文章标题】：桌面升级，灯也要跟着进化：明基 iScreenBar 与 ScreenBar Max 体验

【文章正文】：
2017 年，明基推出第一代 ScreenBar，把原本占据桌面的灯座挪到屏幕上方，再用非对称光路照亮桌面、避开屏幕，由此创造了世界上第一盏屏幕挂灯。
此后近十年的产品迭代，大致沿着物理结构和智能体验两个方向展开。灯头变得更轻，安装结构可以兼容更多显示器，非对称光路不断调整照射范围，同时减少屏幕反光；另一边则加入了无线控制器、自动调光、色温调整与人体感应。到了近两年，从 ScreenBar Pro 开始，挂灯已经可以安静地待在屏幕上，自动启闭并调节亮度和色温，使用时几乎感觉不到它的存在。
我们此前体验 ScreenBar Pro 时，最深刻的印象是「似若无物」。它可以恰到好处地照亮桌面，不占空间，也几乎不需要用户主动调整。一个产品能够做到离不开但想不起，意味着它已经非常成熟，我确实很难再想象它还能发生什么明显变化。
但桌面没有停在原地。有人换成了把主机、摄像头、麦克风和扬声器都收进一块屏幕的 iMac；有人把第二块显示器搬上桌面，甚至横竖屏错落使用；AI 时代里，多线程变得越来越频繁，带鱼屏也越来越长。除此之外桌面也未必只放着键盘，纸张、数位板和各种需要动手处理的物件，都在争夺桌面的照明。于是我们看到过去围绕一块标准显示器形成的灯光方案，开始出现瓶颈。
于是在 ScreenBar 十周年新品发布会上，明基带来了全新产品 iScreenBar 和 ScreenBar Max，分别从两个方向回应了数字桌面的变化。
iScreenBar 做得更轻巧，也更靠近 iMac。它顺着 iMac 原有的外观和结构寻找自己的位置，再把灯光控制接入 macOS。安装完成后，iScreenBar 看起来像是 iMac 原本就有的一部分；ScreenBar Max 则离开了单块显示器，独立支臂让灯头可以越过双屏之间的缝隙，调整高度、距离和照射位置；更宽的灯头也把光线带到屏幕之外，照顾整张工作台上的键盘、纸张和其它物件。
前者尽量顺着一台高度整合的电脑去设计，后者则接受大型工作站桌面不断扩张的现实。一个努力降低灯在桌面上的存在感，一个主动承担更多照明任务。两款产品由相同的技术积累创造，形态却满足着不同的场景和需求。
因此，iScreenBar 和 ScreenBar Max 更像是 ScreenBar 产品线向外分出的两套新方案。明基没有重新发明灯，也没有推翻过去十年的设计。它重新观察了灯周围的屏幕、设备和使用方式，再把已经成熟的光学、结构与智能体验放进两张不同的桌面。
藏在 iMac 设计里的 iScreenBar
iMac 很容易被一件不合适的配件破坏掉完整感。
现款 iMac 将人物居中摄像头、三麦克风阵列和六扬声器系统装进同一副机身，颜色、材质与线条也保持着很强的统一性。尽管普通显示器挂灯也能装在 iMac 上，但安装之后厚重的夹具可能挡住摄像头和背后的麦克风开口，线材也会沿着整洁的机身背面突兀垂落。这些在颜色、材质、结构或比例上的偏离，都使得 iMac 原本完整的外观多出了一个醒目的附件，甚至还会干扰其正常工作。
iScreenBar 采用磁吸方式安装，固定结构因此可以做得更轻。灯体的颜色与材质也顺着 iMac 调整，同时避开机身上的摄像头、麦克风和扬声器。线材沿机身背面收拢以后，正面留下的部分只有灯头本身。灯体做得更轻巧以后，照明仍要覆盖 iMac 前方常用的桌面。
iScreenBar 使用第三代 ASYM-Light 非对称光学，将光线集中投向键盘与桌面，让屏幕和眼睛避开直射光。于是尽管灯可以贴近 iMac 安装，但桌面上的照明范围没有因此而打折。
但外观只完成了一部分工作。iMac 的优势一直来自软硬件配合，于是除了成熟的根据环境光照自动调光功能，iScreenBar 还把灯光控制接入了 macOS。其配套应用可以通过 Power Sync 让灯跟随 iMac 开关机。用户坐到电脑前开始和结束工作，灯便会随着电脑启闭。如果设置了人体感应，临时离开桌面时同样不用惦记开关。
应用还能为不同软件保存灯光设置。例如写稿时可以使用偏中性的亮度和色温，处理图片时调用另一套照明，打开视频会议软件后则可以切换到视频通话补光模式，基于环境光照提升视频效果。这件事看上去或许没有硬件参数那么直接，却很符合 iMac 用户的操作习惯。iMac 的许多体验原本就由软硬件共同完成——电脑知道用户正在做什么，然后调整设备状态——只是现在灯光也加入了这套工作流。
iScreenBar 的适用范围十分明确。它围绕 iMac 的机身结构、外观与 macOS 设计，如果换成其它电脑和显示器，许多细节都会失去作用。但对于一台很难随意增加配件的 iMac 来说，iScreenBar 愿意服从电脑原有的设计，恰好构成了它存在的理由。
ScreenBar Max 想要照顾一整张工作台
ScreenBar Max 在假定用户的桌面已经没有一个明确的中心。在单屏桌面上，人、显示器和挂灯大多位于同一条中轴线上。两块屏幕并排以后，人的座位可能对着两块屏幕之间，也可能长期偏向其中一块。显示区域的中心、桌面的中心和用户所在的位置开始互相错开。
传统挂灯固定在其中一块屏幕上，光线容易偏向一侧；放在两块屏幕的接缝附近，又会遇到边框、角度与安装稳定性的问题。如果其中一块显示器竖放，或者换成长比例的带鱼屏，屏幕上方也很难找到一个同时适合安装与照明的位置。
ScreenBar Max 因此离开了显示器顶部。它通过桌夹或者可选底座固定在桌面上，再用独立支臂将足足 85cm 的超长灯头伸到屏幕前方。灯头不需要依附某一块显示器，显示器升降、旋转或者重新排列时，灯的位置也可以单独调整。
独立支臂提供了高度和前后位置的调整空间，基于在用的显示器尺寸，最高支持 55 - 71cm 范围的高度调节，同时还有 17.5 - 28cm 的滑轨前后调节，如果希望光集中在键盘附近，可以将灯头向后移动；桌面上摊开纸张、手账或者正在处理的设备时，也可以把灯头向前伸。
为了让光线能有效覆盖双屏桌面，ScreenBar Max 推出了全新的 ASYM-TriZone 全景非对称光型。得益于 ScreenBar Max 更宽的灯头，照明被延伸到两块屏幕前方，光线主要投向桌面，同时利用遮光设计减少显示器反光和直射眼睛的光线。两块屏幕之间原本容易变暗的位置，也被纳入了照明范围。
更宽的光型还要处理桌面操作产生的阴影，ScreenBar Max 通过交错排列灯珠减少方向不同的多重阴影；灯头背面的环境光则照向墙面，缓和亮屏与暗背景之间的反差。所以它虽然看起来好似一盏传统台灯，但使用体验则截然不同。
除此之外，ScreenBar Max 还将亮度、色温、自动调光和人体感应等控制集中在带显示屏的控制器上。用户可以直接看到当前状态，再根据桌面变化重新设置。对于一盏服务于现代数字桌面的灯具来说，明确且自动调整的照明状态比按键方便得多。
ScreenBar Max 面对的是双屏、竖屏和带鱼屏组成的工作站，以及那些同时承担电脑操作、阅读和手工处理的桌面。它离开屏幕之后获得了更大的调整范围，也接受了更明确的存在感。
让光适应已经改变的桌面
iScreenBar 和 ScreenBar Max 看起来差异很大，但使用的仍然是明基过去十年逐渐积累下来的非对称照明、自动调光与人体感应经验。成熟技术成了两款产品共同的起点，明基因此可以把更多精力放在灯与其它设备的关系上。
iScreenBar 需要理解 iMac，它顺着一体机原有的外观与结构安装，再通过配套软件参与电脑的使用过程；ScreenBar Max 则需要理解日益复杂的桌面陈设与用户需求，它放弃依附单块显示器，通过独立支臂回应不断增加的屏幕与桌面操作。
而这两款新品与旧款之间则没有简单的替代关系。如果你使用的是一块标准显示器，仍然适合传统 ScreenBar Pro 或 ScreenBar Halo，iMac 用户可以选择 iScreenBar，双屏和大型工作站则更容易发挥 ScreenBar Max 的能力。桌面不同，照明需要处理的问题也会随之变化。
这也解释了明基为什么一直在做看上去颇为专用的灯，除了显示器挂灯，还有面向笔记本电脑、阅读和钢琴等场景的产品。笔记本电脑会移动，阅读和练琴时的坐姿和琴谱琴键照明需求也不同。显示器挂灯只是这些具体方案中的一种。
我们过去在分享效率工具时，也经常会遇到类似的情况。参数表只能说明一件产品可以做什么，只有具体的场景才会解释产品为什么长成现在的样子。明基用不同的产品点亮在做不同事的我们，才能看出一个设计究竟是解决了问题，还是只增加了功能。
我以前很难想象显示器挂灯还能发生什么变化，是因为我一直只关注在灯本身。但 iScreenBar 和 ScreenBar Max 跳出了产品，回到真实场景里，在实际体验中改变了灯与屏幕、桌面和人的关系。明基用过去十年回答了一盏显示器挂灯怎样才能做好，现在的两款新品开始处理使用场景的变化：电脑性能越来越强，工作站越来越大，人在桌面上做的事情也越来越多。光源也该有不同的形态和位置。
祝你找到最适合自己的那束光。
