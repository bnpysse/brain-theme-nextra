【文章标题】：Zig v0.17.0

【文章正文】：

Zig is a general-purpose programming language and toolchain for maintaining robust, optimal, and reusable software.

Zig是一种通用编程语言和工具链，用于维护健壮、高效且可复用的软件。

Zig development is funded via Zig Software Foundation, a 501(c)(3) non-profit organization. Please consider a recurring donation so that we can offer more billable hours to our core team members. This is the most straightforward way to accelerate the project along the Roadmap to 1.0. If you need donation receipts or are looking to migrate away from GitHub Sponsors, we recommend donating via Every.org.

Zig的开发由501(c)(3)非营利组织Zig软件基金会资助。请考虑定期捐赠，这样我们可以为核心团队成员提供更多可计费工时。这是推动项目沿着1.0路线图前进最直接的方式。如需捐赠收据或希望迁移GitHub Sponsors之外的捐赠渠道，我们推荐通过Every.org进行捐赠。

This release features 5 months of work: changes from 206 different contributors, spread among 925 commits.

本次版本包含5个月的工作成果：来自206位贡献者的更改，分布在925次提交中。

Originally predicted to be shorter, this release cycle ended up substantial, with the Build System reworked, including the introduction of the Build Server Protocol, and the ELF Linker enhanced to the point where we expect Incremental Compilation to work for everyone on x86_64-linux.

原本预计周期会更短，但最终这个发布周期成果丰硕：重构了构建系统（包括引入构建服务器协议），并增强ELF链接器至我们预期x86_64-linux平台所有用户都能使用增量编译的程度。

Zig supports a wide range of architectures and operating systems. The Support Table and Additional Platforms sections cover the targets that Zig can build programs for, while the zig-bootstrap README covers the targets that the Zig Compiler itself can be easily cross-compiled to run on.

Zig支持广泛的架构和操作系统。"支持表格"和"附加平台"部分涵盖Zig可构建程序的目标平台，而zig-bootstrap的README则说明Zig编译器本身可轻松交叉编译运行的目标平台。

Notable changes:

重要变更：

aarch64-openbsd is now tested natively in Zig's CI, ensuring high-quality support going forward.

aarch64-openbsd现在已在Zig的CI中原生测试，确保未来提供高质量支持。

aarch64-freebsd and aarch64-netbsd CI jobs now run on pull requests too, in addition to master pushes.

aarch64-freebsd和aarch64-netbsd的CI任务现在也针对pull请求运行（除主分支推送外）。

aarch64-windows binaries, including the Zig Compiler, has been worked around.

已解决aarch64-windows二进制文件（包括Zig编译器）的问题。

loongarch32-linux-gnu[sf] targets has been added.

新增loongarch32-linux-gnu[sf]目标平台。

sparc64-linux. This is largely thanks to Zig's new ELF linker which now has better support for this target than LLD.

sparc64-linux。这主要归功于Zig的新ELF链接器，现在对该平台的支持优于LLD。

aarch64-switch, arm-gba, mipsel-psx, and powerpc-wiiu

新增aarch64-switch、arm-gba、mipsel-psx和powerpc-wiiu支持。

xtensa-linux support has been added to Zig. Note that, for now, this support can only be exercised via the C backend or the experimental LLVM backend.

Zig新增xtensa-linux支持。请注意目前只能通过C后端或实验性LLVM后端使用该功能。

arc[eb]-linux, csky-linux, and m88k-openbsd when using the C backend.

使用C后端时支持arc[eb]-linux、csky-linux和m88k-openbsd。

microblaze[el]-linux, sh[eb]-linux, and sparc-linux.

新增microblaze[el]-linux、sh[eb]-linux和sparc-linux支持。

-mabi=ieeelongdouble for all PowerPC targets. This is just a formalization of what was already reality; Zig has never supported the IBM "double-double" format for long double and likely never will. As a result, this release drops support for powerpc-linux-gnueabi[hf] because glibc only supports the "double-double" format on these targets. The powerpc-linux-musleabi[hf] targets remain supported as they use the IEEE format.

所有PowerPC目标平台采用-mabi=ieeelongdouble。这只是对现有事实的规范化——Zig从未支持IBM的"double-double"长双精度格式且可能永远不会。因此本版本停止支持powerpc-linux-gnueabi[hf]，因为glibc在这些目标上仅支持"double-double"格式。而使用IEEE格式的powerpc-linux-musleabi[hf]目标仍受支持。

powerpc64-linux-gnu. Zig has only ever supported linking ELFv2 binaries for 64-bit PowerPC, and glibc does not officially support ELFv2 on big endian - nor IEEE

powerpc64-linux-gnu。Zig始终仅支持64位PowerPC的ELFv2二进制链接，而glibc官方不支持大端序的ELFv2——也不支持IEEE。

Zig's level of support for various targets is broadly categorized into four tiers with Tier 1 being the highest. The goal is for Tier 1 targets to have zero disabled tests - this will become a requirement for post-1.0.0 Zig releases.

Zig对不同目标平台的支持级别大致分为四个等级，其中第1级为最高。目标是让第1级目标平台实现零禁用测试——这将成为Zig 1.0.0之后版本的硬性要求。
