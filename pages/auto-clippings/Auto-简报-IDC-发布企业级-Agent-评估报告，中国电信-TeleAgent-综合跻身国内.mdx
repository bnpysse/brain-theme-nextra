# 精华简报：IDC 企业级 Agent 评估与中国电信 TeleAgent

&gt; **来源**：极客公园  
&gt; **原文链接**：http://www.geekpark.net/news/370511  
&gt; **主题**：IDC 发布《中国企业级通用 Agent 产品技术评估》，中国电信星辰超级智能体 TeleAgent 综合进入国内第一梯队

---

## TL;DR

IDC 最新发布的《中国企业级通用 Agent 产品技术评估》显示，中国电信星辰超级智能体 TeleAgent 在统一仿真测试中综合得分 6.85，进入国内第一梯队，并在成本效率、安全可控、任务表现等维度高于行业普遍水平。其竞争力并非来自单一模型能力，而是依托中国电信在算力、平台、数据、模型、应用上的全栈布局，以及面向“写、查、数、管”高频办公任务的工程化落地能力。报告同时释放出一个明确信号：企业级 Agent 正从对话问答工具，转向能够自主拆解任务、调用工具并完成作业的新型办公入口，成本、安全、系统对接与权限治理将成为下一阶段竞争的关键。

## 核心观点与洞察

### 1. 评估方法论升级：从“演示能力”转向“生产环境可用性”

此次 IDC 评估不再只看模型能否完成演示任务，而是在统一仿真环境中引入**脏数据、权限约束、模糊指令**等真实工作场景干扰，覆盖任务表现、成本效率、交互体验、安全可控、生态开放性等九大维度。这说明企业级 Agent 的评估标准正在从“能不能说得好”转向“能不能在复杂、受限、不可控的真实业务环境中稳定落地”。

其中，**成本效率被提到与任务表现同等重要的位置**，尤其值得关注。TeleAgent 在 Token 消耗方面优于同类产品，这意味着在需要高频调用、规模化部署的企业场景中，其单位任务成本有望显著降低。对于计划将 Agent 嵌入日常业务流程的企业而言，Token 消耗直接关系到大模型推理成本、调用频率与规模化后的总拥有成本，这正在成为选型中的核心指标之一。

### 2. TeleAgent 的竞争力本质是“全栈可控”，而非单点模型优势

TeleAgent 的背后是中国电信在算力、平台、数据、模型、应用上的全栈布局。中电信人工智能公司连接基础研究、工程研发与产品落地，星辰通用人工智能实验室基于国产算力和国产框架，自主完成十亿、百亿、千亿参数语义基础大模型的预训练和后训练，并将模型开源。

这一策略的意义在于：  
- **自主可控**：基于国产算力和框架完成训练，降低了对外部技术栈的依赖，尤其契合政企和央企的合规要求。  
- **开源生态渗透**：相关模型在 Hugging Face 等主流开源社区总下载量突破百万，并已助力多家央企建设行业基座大模型。这不仅是技术输出，更是一种生态和标准层面的渗透。  
- **多模态与端边云协同**：星辰大模型覆盖多种尺寸，支持端、边、云协同，并融合语义、语音、图像、视频四类模态，为 Agent 在不同终端和场景中的部署提供了基础。

因此，TeleAgent 的第一梯队位置，更多来自“底座能力 + 工程化 + 行业触达”的组合，而非单纯的模型榜单排名。

### 3. 安全可信从“内容层”延伸到“执行层”

当智能体从对话问答走向任务执行，安全边界也随之变化。传统大模型安全更多关注内容生成是否合规，而企业级 Agent 的更大风险在于**越权操作、误操作和数据泄露**。

TeleAgent 围绕**基础模型、执行框架、技能记忆、资产通信**四个层面构建安全防护策略，并经过多轮安全测评。这实际上把安全从“模型输出审核”扩展到了“Agent 行为治理”：  
- **执行框架**需要约束 Agent 能调用哪些工具、访问哪些系统；  
- **技能记忆**可能沉淀企业敏感流程，需要防止技能被滥用或泄露；  
- **资产通信**则关系到 Agent 在执行任务时与外部的数据交换边界。

这一变化意味着，企业级 Agent 的安全能力将越来越像一个“数字员工的权限与审计系统”，而不是简单的输入输出过滤。

### 4. 办公场景是当前最清晰的落地路径，信创适配成为政企突破口

TeleAgent 围绕“写、查、数、管”四类能力，将自然语言指令转化为可执行的办公业务操作。这四类能力对应的是企业中高频、相对标准化、可度量的任务，是 Agent 最容易产生确定性价值的场景。

在产品化层面，TeleAgent 已完成 Windows、macOS 及 Linux 信创环境的多终端适配，并取得银河麒麟、统信 UOS 官方兼容性认证。这说明其目标市场不仅是普通个人用户，更包括对国产化、安全合规有严格要求的政企客户。注册用户突破 120 万、Skill 技能数量从数千个扩展至 5 万余个，则表明其已经在办公场景中形成了一定的用户规模和技能生态。

从行业规律看，**Agent 最先规模化落地的往往是高频、结构化、容错率相对可控的办公任务**，而非复杂决策场景。TeleAgent 的路径符合这一判断。

### 5. 市场进入选型加速期，竞争焦点转向交付与治理

IDC 调研显示，国内近半数企业用户已经涉足通用 Agent 选型。这表明企业级 Agent 市场正在从概念验证走向实际采购和部署。更重要的是，智能体正在从对话问答工具，转向能够自主拆解任务、调用工具并完成作业的新型办公入口。

这意味着下一阶段竞争将不再只是“模型强不强”，而是：  
- 复杂任务能否**稳定交付**；  
- 能否与现有企业系统**有效对接**；  
- 权限治理和运行过程能否**可管理、可审计**；  
- 单位任务成本是否具备**规模化经济性**。

文章最后也明确指出，这些问题是包括 TeleAgent 在内的所有智能体产品需要持续回答的挑战。

## 启发与影响

### 对技术供应商与行业竞争者

- **成本优化应成为产品核心指标**：Token 消耗、推理效率、缓存与调度策略等，将直接影响企业客户的规模化部署意愿。仅靠模型能力难以建立壁垒，工程效率和成本控制同样关键。
- **全栈能力与国产化适配是政企市场的准入门槛**：在信创、央企、政务等市场中，能否基于国产算力、国产框架完成训练和部署，并通过麒麟、统信等认证，将直接决定能否进入采购清单。
- **安全治理需要前置于架构设计**：企业级 Agent 必须把权限管理、执行审计、数据边界作为底层能力，而非事后补充。能够提供可审计执行链路的厂商将获得信任优势。
- **开源与行业基座模型是生态渗透策略**：通过开源模型和帮助行业建设基座大模型，可以在早期绑定生态伙伴，形成事实标准。

### 对企业用户与采购方

- **选型应超越“演示效果”**：应重点考察在脏数据、权限约束、模糊指令等真实条件下的稳定性，以及单位任务成本、与现有系统的集成难度。
- **优先从高频办公任务切入**：企业可以优先在“写、查、数、管”等标准化办公场景中试点 Agent，积累技能库和权限管理经验，再逐步扩展到更复杂的业务流程。
- **关注部署模式与信创兼容性**：如果企业有国产化要求，需确认产品对信创操作系统、国产算力环境的支持程度，以及端、边、云协同部署能力。

### 对市场格局

- 企业级 Agent 正从“AI 聊天工具”演变为“新型办公入口”，未来可能重塑企业软件交互层，甚至影响传统 OA、ERP、知识管理等系统的用户入口地位。
- 具备算力、模型、平台和应用全栈能力的运营商/云厂商，在政企和行业市场中拥有显著差异化优势，可能改变 AI 应用赛道的竞争格局。
- 随着近半数企业用户进入选型阶段，2025—2026 年可能成为企业级 Agent 从试点走向规模部署的关键窗口期。

## 待观察问题

尽管 TeleAgent 在本轮评估中进入第一梯队，但文章亦指出，随着企业将 Agent 接入实际业务，以下问题仍需持续验证：  
1. 复杂任务能否稳定交付，而非仅在标准化办公任务中表现优秀；  
2. 能否顺畅对接企业现有业务系统，避免形成新的数据孤岛；  
3. 权限治理、操作审计和运行过程能否满足企业级合规要求；  
4. 在真实规模化部署中，成本效率优势能否持续保持。

这些问题的解决程度，将决定包括 TeleAgent 在内的企业级 Agent 产品能否从“第一梯队”走向“大规模生产力工具”。
