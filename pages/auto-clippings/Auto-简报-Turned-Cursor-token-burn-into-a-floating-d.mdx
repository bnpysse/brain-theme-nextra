# Reddit r/CursorAI 热帖精华简报

**主题**：将 Cursor token 消耗变成桌面浮动营火（macOS, MIT）  
**链接**：https://www.reddit.com/r/CursorAI/comments/1wgsp3s/turned_cursor_token_burn_into_a_floating_desktop/

---

## 一、TL;DR

TinyFire 是一款 macOS 上的浮动像素营火小工具，它将 Cursor 的 token 消耗强度实时映射为火焰大小——高消耗时火焰变大，空闲时只剩余烬——并同时读取 Claude Code 与 Codex 的用量数据。该工具优先在本地存在 token 时调用 Dashboard API，否则进行本地估算；作者强调其仅本地运行、不上传数据，并以 MIT 协议开源。帖子的核心讨论点是：这种“安静桌面伴侣”对 Cursor 会话究竟有实际用途，还是仅仅可爱。

---

## 二、核心观点与技术细节

- **产品形态**  
  - macOS 浮动像素营火，属于桌面环境可视化/外周提示工具。  
  - 目标是将原本只存在于图表中的用量数据，变成可“扫一眼”感知的桌面元素。

- **数据映射逻辑**  
  - `Hard burn → bigger flame`：高强度 token 消耗对应更大火焰。  
  - `Idle → embers`：空闲状态显示余烬。  
  - 换句话说，火焰大小是 token 消耗强度的直观隐喻。

- **数据来源与处理**  
  - 读取本地 Cursor usage。  
  - 当本地存在 token 时，优先通过 Dashboard API 获取用量。  
  - 否则采用本地估算。  
  - 额外整合 Claude Code / Codex 的使用数据。  
  - 作者声明：Local only — nothing uploaded（仅本地运行，不上传任何数据）。

- **开源与获取方式**  
  - 许可证：MIT。  
  - 下载：https://tinyfire.createfun.ai/  
  - GitHub：https://github.com/wdkwdkwdk/tinyfire

- **作者抛出的讨论问题**  
  - “Is a quiet desk companion useful for Cursor sessions, or just cute?”  
  - 即：安静的桌面伴侣对 Cursor 会话是实用，还是仅仅可爱？

---

## 三、核心痛点

- **用量反馈不直观**  
  Cursor 使用/消耗数据通常只存在于图表中，用户难以在开发过程中实时、低干扰地感知 token 消耗。

- **缺乏桌面级环境警示**  
  当 token 消耗强度上升时，缺少一种无需切换窗口、无需打开仪表盘即可感知的外周提示机制。

- **隐私与本地化诉求**  
  用户对用量统计类工具存在数据上传顾虑，需要本地运行、不向外传输数据的替代方案。

- **实用性与趣味性边界模糊**  
  社区需要判断此类“安静桌面伴侣”能否真正帮助注意力管理或成本控制，还是仅提供情绪价值。
