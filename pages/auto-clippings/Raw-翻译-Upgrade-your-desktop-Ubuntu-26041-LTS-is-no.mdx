User experience and performance enhancements

用户体验与性能提升

With the GNOME 50 desktop environment and a modernized set of default applications, Ubuntu 26.04 LTS fully embraces Wayland, completing the upstream shift from X.org. This shift delivers smoother visuals, per-monitor scaling, native touch and gesture support, removes screen tearing and optimizes performance across platforms, including support for the latest NVIDIA production drivers. Fractional scaling and variable refresh rate (VRR) are no longer experimental, and GNOME 50 brings faster animations and a cleaner workspace.

通过GNOME 50桌面环境和现代化默认应用套件，Ubuntu 26.04 LTS全面转向Wayland，完成了从X.org的上游迁移。这一转变带来更流畅的视觉效果、多显示器独立缩放、原生触控手势支持，消除了屏幕撕裂现象并优化跨平台性能，包括支持最新的NVIDIA生产级驱动。分数缩放和可变刷新率(VRR)不再是实验功能，GNOME 50还带来更快的动画效果和更简洁的工作空间。

New default applications include the Papers document viewer, the Loupe image viewer, the Ptyxis terminal, and the Resources system monitor, along with a broad set of accessibility fixes across the Shell and default applications to ensure compliance with global regulations. The App Center now provides a unified software management experience, with debs and snaps displayed side-by-side in a single place.

新版默认应用包含Papers文档查看器、Loupe图像查看器、Ptyxis终端和Resources系统监视器，同时对Shell和默认应用进行了全面的无障碍功能修复以确保符合全球规范。应用中心现在提供统一的软件管理体验，deb和snap格式软件可在同一界面并列展示。

Your development and AI tools, right at home on Ubuntu

开发与AI工具，在Ubuntu上得心应手

As the target platform for open source software vendors and community projects, Ubuntu 26.04 LTS ships with the latest toolchains for Python, Rust, Ruby, Go, PHP, and Perl, and users get first access to the latest updates for key libraries and packages.

作为开源软件供应商和社区项目的目标平台，Ubuntu 26.04 LTS预装Python、Rust、Ruby、Go、PHP和Perl的最新工具链，用户可优先获取关键库和软件包的最新更新。

In fields such as data science and machine learning, Ubuntu is the operating system (OS) of choice for many of the most popular frameworks. This includes OpenCV, TensorFlow, Keras, PyTorch, and Kubeflow.

在数据科学和机器学习领域，Ubuntu是众多流行框架的首选操作系统，包括OpenCV、TensorFlow、Keras、PyTorch和Kubeflow。

Ubuntu 26.04 LTS is the first Ubuntu release to natively distribute NVIDIA CUDA as part of its software repositories, and NVIDIA DOCA-OFED for high-performance networking is available through an official PPA starting with this release. The AMD ROCm software platform is also now available in Ubuntu’s repositories – an open software ecosystem for hardware-accelerated AI, machine learning, and HPC workloads on AMD Instinct and AMD Radeon GPUs.

Ubuntu 26.04 LTS是首个原生集成NVIDIA CUDA到软件仓库的版本，高性能网络组件NVIDIA DOCA-OFED也通过官方PPA提供。AMD ROCm软件平台现也已加入Ubuntu仓库——这是面向AMD Instinct和Radeon GPU硬件加速AI、机器学习及高性能计算的开放软件生态系统。

Security and compliance features for enterprises

企业级安全与合规特性

Ubuntu 26.04 LTS builds on the resilience-focused improvements introduced in interim releases, bringing security and compliance enhancements that shrink the attack surface and harden the OS against unauthorized or malicious entry attempts.

Ubuntu 26.04 LTS基于临时版本中引入的弹性改进，进一步增强了安全与合规特性，既缩小了攻击面，又强化了系统对抗未授权或恶意入侵的能力。

TPM-backed full-disk encryption is now generally available in the Ubuntu installer. By tying encryption to the TPM security chip, disk encryption is bound to a specific device, significantly raising the bar for physical access attacks while improving the user experience. As part of this release, the Security Center becomes a control plane for platform protections. Through the Security Center, administrators can inspect and manage TPM-backed encryption state, recovery mechanisms, Secure Boot status, and disk protection configuration after deployment.

Ubuntu安装程序现已全面支持TPM全盘加密。通过将加密与TPM安全芯片绑定，磁盘加密将锁定特定设备，在提升用户体验的同时大幅提高物理攻击门槛。本次发布中，安全中心升级为平台保护控制平面，管理员可通过其查看和管理TPM加密状态、恢复机制、安全启动状态及部署后的磁盘保护配置。

Ubuntu 26.04 LTS is the first LTS to expand the number of memory safe system components. In practice, this means new kernel drivers and subsystems written in Rust, as well as sudo-rs and uutils coreutils, bringing memory-safe reimplementations of foundational system tools such as sudo and ls while GNU implementations remain available for compatibility.

Ubuntu 26.04 LTS是首个扩展内存安全系统组件数量的LTS版本，实际表现为新增采用Rust编写的内核驱动和子系统，以及sudo-rs和uutils coreutils，这些组件为sudo和ls等基础系统工具提供了内存安全的重实现，同时保留GNU实现以确保兼容性。

Cryptographic defaults in Ubuntu 26.04 LTS are post-quantum aware: hybrid post-quantum key exchange is enabled by default, and legacy cipher support has been fully retired. Ubuntu 26.04 LTS provides host and guest support for confidential computing on Intel Trust Domain Extensions and AMD SEV, extends Canonical Livepatch to Arm64 for the first time, and delivers an updated WSL experience with cloud-init and Ubuntu Pro for WSL.

Ubuntu 26.04 LTS的加密默认设置已具备后量子意识：默认启用混合后量子密钥交换，并完全移除了传统加密支持。本版本为Intel TDX和AMD SEV机密计算提供主客机支持，首次将Canonical Livepatch扩展到Arm64架构，并通过cloud-init和Ubuntu Pro for WSL提供更新的WSL体验。
