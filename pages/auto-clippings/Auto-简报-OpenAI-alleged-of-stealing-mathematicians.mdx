# 精华简报：OpenAI 被指控窃取数学家工作成果

**来源**：Reddit r/LocalLLaMA 热帖  
**链接**：https://www.reddit.com/r/LocalLLaMA/comments/1wapjaw/openai_alleged_of_stealing_mathematicians_work/

## 1. TL;DR

两位数学家声称历时约一年攻克一项高难度数学问题，并将每份研究草稿输入 OpenAI 的 Codex 辅助工作；在他们计划发表成果前几天，OpenAI 据称突然公布或展示了相同的解法。事后涉事方询问 OpenAI 模型（Sol 和 Astra）是否使用了二人的私人聊天记录或草稿进行训练，OpenAI 未正面回答。该帖将此事件视为云端模型隐私失控与研究成果归属争议的又一案例，进一步强化了社区对本地部署 LLM 的诉求。目前该指控仍为单方说法，未经独立证实。

## 2. 核心观点与技术细节

- **事件主体**：两位数学研究者，涉事声明托管于纽约大学数学科学研究所（NYU CIMS）页面。
- **工作方式**：二人花费约一年时间研究数学难题，并将每一份草稿输入 OpenAI 的 Codex 模型/工具，作为研究辅助。
- **时间线冲突**：在他们准备发表成果的前几天，OpenAI 被指突然出现并给出相同解法。
- **关键质询**：OpenAI 被问及其模型 Sol 和 Astra 是否在二人私人聊天或草稿上训练，但 OpenAI 未回答该问题。
- **社区解读**：如果用户输入内容被用于训练，意味着借助云端 LLM 产生的科研数据可能被平台吸收、重现，甚至被抢先发布。
- **证据材料**：涉事方声明 PDF：https://cims.nyu.edu/~tristanb/statement.pdf ，具体技术细节需查阅原文。
- **信源可靠性**：该信息来自 Reddit 帖文，属单方指控；OpenAI 尚无公开正式回应，是否存在模型训练或成果抄袭尚未证实。

## 3. 核心痛点

- **训练数据边界不清**：用户无法确认输入云端模型的私有内容是否会被用作训练语料，隐私保护机制不透明。
- **学术与成果归属风险**：借助模型完成的工作可能被平台方复用、重现或抢先发布，威胁研究者的优先权与知识产权。
- **厂商回应不透明**：在涉及训练数据来源的关键问题上保持沉默，削弱用户信任，也增加取证与合规难度。
- **云端依赖的脆弱性**：该事件加剧了社区对云端模型的隐私担忧，强化了自建硬件、本地运行开源 LLM 的动机。
