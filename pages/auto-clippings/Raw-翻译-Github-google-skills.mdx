# 代理技能

[![通过skills.sh安装](https://img.shields.io/badge/skills.sh-install-green)](https://skills.sh/google/skills)

此仓库包含针对Google产品的代理技能，包括[Google Cloud](https://cloud.google.com)。

&gt; [!NOTE]
&gt; 此仓库正处于积极开发中。

## 安装

```bash
npx skills add google/skills
```

从`npx install`命令，可以选择安装此repo中的特定技能。

## 插件

此仓库还捆绑了针对代理框架的Google产品插件（技能 + MCP服务器）。

| 代理框架 | 安装 |
| :--- | :--- |
| **Claude Code** | `claude plugin marketplace add google/skills`，然后 `claude plugin install &lt;plugin&gt;@google-plugins` |
| **Codex** | `codex plugin marketplace add google/skills`，然后从 `/plugins` 浏览器中安装 |
| **Antigravity CLI** | `agy plugin install https://github.com/google/skills/&lt;plugin-path&gt;` |
