&gt; _类似DeepWiki，但更深入。_ DeepWiki帮助您理解代码，GitNexus让您分析代码——知识图谱追踪所有关系，而不仅仅是描述。

**一句话总结：** **CLI + MCP** 使您的AI智能体更可靠——它为Cursor、Claude Code、Antigravity、Codex等工具提供代码库的深层架构视图，避免遗漏依赖、破坏调用链和盲目修改。即使是较小的模型也能获得完整的架构清晰度。**网页界面**让您能在浏览器中快速与任何仓库对话。

## 快速开始

```bash
# 1. 索引您的仓库（在仓库根目录运行）
npx gitnexus analyze

# 2. 连接编辑器（一次性操作，自动检测Claude Code、Cursor、Codex等）
npx gitnexus setup
```

完成。`analyze`命令会索引代码库、安装智能体技能、注册Claude Code钩子，并创建`AGENTS.md`/`CLAUDE.md`上下文文件——全部通过一个命令完成。`setup`命令会写入MCP配置，让您的AI智能体可以使用图谱。

&lt;details&gt;
&lt;summary&gt;**安装问题？** npm 11崩溃 · 冷安装缓慢 · 缺少C++工具链&lt;/summary&gt;

&gt; **使用npm 11.x？** `npx`可能在安装过程中崩溃，显示`Cannot destructure property 'package' of 'node.target'`（这是npm/arborist的bug，发生在GitNexus运行之前）。请改用pnpm——它会明确构建原生依赖：
&gt;
&gt; ```bash
&gt; pnpm --allow-build=@ladybugdb/core --allow-build=gitnexus --allow-build=tree-sitter dlx gitnexus@latest analyze
&gt; ```
&gt;
&gt; 或者全局安装（`npm install -g gitnexus@latest`）后运行`gitnexus analyze`。详见[#1939](https://github.com/abhigyanpatwari/GitNexus/issues/1939)。

&gt; **最快的MCP启动方式：** 在运行`gitnexus setup`前全局安装（`npm i -g gitnexus`）——这会写入绝对路径的MCP配置，完全绕过`npx`。在冷缓存情况下，基于`npx`的MCP安装可能超过Claude Code的`MCP_TIMEOUT`限制。
