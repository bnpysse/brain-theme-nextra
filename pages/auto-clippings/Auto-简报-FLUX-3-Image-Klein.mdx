# FLUX 3 Image Klein 发布简报

## 核心要点

Black Forest Labs（BFL）发布 **FLUX 3 Image Klein**——一款 56 亿参数的开源权重图像生成模型，在文本到图像、图像编辑和多参考生成三大任务上，以更小参数规模实现领先质量，并针对消费级 GPU 深度优化。

---

## 模型定位与能力

- **参数规模**：5.6B，为同类对比中最小开源模型（Qwen-Image 2.1 为 7B，Krea 2 为 12.9B）

- **核心能力**：与完整版 FLUX 3 Image 共享——原生 4K 生成、像素级编辑、边界框控制（元素定位/编辑区域限定）

- **多参考生成**：最多支持 10 张参考图像

- **多模态基础**：基于 FLUX 3 在图像、视频、音频上的联合学习，增强真实世界物理与交互感知

## 性能与效率

- **质量领先**：内部评估中，文本到图像、多参考生成、图像编辑均排名第一，超越更大开源模型及闭源模型（Ideogram V4.5、FLUX.2 [pro]）

- **对比提升**：相比 FLUX.2 [klein] 9B，文本到图像 Elo +91，图像编辑 Elo +70，参数减少 38%

- **速度优势**：扩展速度-质量帕累托前沿；通过 BFL API 延迟低于 Qwen-Image 2.1、FLUX.2 [pro]、Ideogram V4.5、Krea 2

- **硬件适配**：

- 权重占用：BF16 11.2GB / FP8 5.6GB

- INT8 版本可在 8GB 显存的 NVIDIA RTX GPU 上运行（ComfyUI / Diffusers）

- 蒸馏模型 + INT8：RTX 5090 生成 1MP 图像约 4 秒，RTX 4070 约 9 秒

## 发布形式与生态

- **许可证**：FLUX Kommunity License

- **模型版本**：基础版（适合微调）+ 蒸馏版（低延迟），另有 FP8、INT8、NVFP4 量化版本（NVIDIA 支持）

- **微调支持**：Diffusers、Ostris AI Toolkit 首日支持 LoRA；NVIDIA NeMo AutoModel 提供现成配方

- **API 定价**：$0.009 / 1K 图像，支持提示词上采样与像素恢复（精确保留未编辑区域）

- **生态集成**：ComfyUI、Hugging Face Diffusers、TensorRT-LLM、SGLang Diffusion、vLLM-Omni 首日支持

## 战略意义

FLUX 3 Image Klein 以“更小、更快、更强”的策略切入开源图像生成市场，显著降低本地部署与设备端编辑门槛，同时保持顶级质量，有望推动图像模型在消费硬件上的大规模落地，并对闭源商业模型形成有力竞争。
