## **Summary**
## **摘要**

*Efficiently finding registered accounts from emails.*
*高效地从邮箱中查找已注册账户。*

Holehe checks if an email is attached to an account on sites like twitter, instagram, imgur and more than 120 others.
Holehe 检查一个邮箱是否关联到某个账户，支持 Twitter、Instagram、Imgur 以及超过 120 个其他网站。

+ Retrieves information using the forgotten password function.
+ **[Does not alert the target email.](https://github.com/megadose/holehe/issues/12)**
+ Runs on [Python 3](https://www.python.org/downloads/release/python-370/).
+ 使用“忘记密码”功能检索信息。
+ **[不会向目标邮箱发送警报。](https://github.com/megadose/holehe/issues/12)**
+ 运行于 [Python 3](https://www.python.org/downloads/release/python-370/)。

### 📚 命令行示例


### 📈 Python Example
### 📈 Python 示例

```python
import trio
import httpx

from holehe.modules.social_media.snapchat import snapchat


async def main():
    email = "test@gmail.com"
    out = []
    client = httpx.AsyncClient()

    await snapchat(email, client, out)

    print(out)
    await client.aclose()

trio.run(main)
```

## Module Output
## 模块输出

For each module, data is returned in a standard dictionary with the following json-equivalent format :
对于每个模块，数据以标准字典形式返回，格式对应如下 JSON：

```json
&#123;
  "name": "example",
  "rateLimit": false,
  "exists": true,
  "emailrecovery": "ex****e@gmail.com",
  "phoneNumber": "0*******78",
  "others": null
&#125;
```

- rateLitmit : Lets you know if you've been rate-limited.
- exists : If an account exists for the email on that service.
- emailrecovery : Sometimes partially obfuscated recovery emails are returned.
- phoneNumber : Sometimes partially obfuscated recovery phone numbers are returned.
- others : Any extra info.
- rateLitmit：让你了解是否已被限流。
- exists：该邮箱在此服务上是否存在账户。
- emailrecovery：有时会返回部分混淆的恢复邮箱。
- phoneNumber：有时会返回部分混淆的恢复手机号。
- others：任何其他信息。

Rate limit? Change your IP.
遇到限流？更换你的 IP 地址。
