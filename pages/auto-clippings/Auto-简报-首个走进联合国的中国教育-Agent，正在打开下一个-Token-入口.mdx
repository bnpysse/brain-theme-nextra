**来源：** 爱范儿 ifanr  
**链接：** https://www.ifanr.com/1678673

## TL;DR

教育正在成为继 Coding 之后，Agent 时代一个被长期低估但已开始规模化验证的高价值入口。中国清华系团队打造的 OpenMAIC 教育 Agent，凭借从“课件生成”向“完整课程生产工作流”的进化，以及“工作流 + Skill + 开放 SDK/生态”的产品架构，登上联合国教科文组织 Digital Learning Week 2026 官方舞台。其单次任务平均 Token 消耗从旧版约 35.8 万上升至 v1.0 约 362.5 万，平均调用模型 74.3 次，说明 AI 已从一问一答进入长链条、多轮次的知识生产工作。OpenMAIC 的开源策略与 Harness 接入，正在让“教育能力”成为通用 Agent 生态中的可嵌入能力层，也为中国 AI 全球竞争提供了一种从参数榜单走向方法、标准与工作流输出的新范式。

---

## 一、核心观点与技术/商业洞察

### 1. 教育是 Coding 之后下一个高价值 Agent 入口

文章指出，AI 行业长期寻找 Coding 之后的下一个高价值场景，办公软件、智能硬件都在争夺入口，但教育可能才是被低估的答案。

其判断依据在于：

- **任务结构相似**：一门课程的生成涉及理解学习目标、检索核验材料、组织知识顺序、生成讲解/幻灯片/互动/反馈，并在多轮修改中持续调用模型，与软件工程一样拥有长任务链条。
- **需求已开始规模化验证**：OECD TALIS 2024 数据显示，约三分之一的初中教师已在工作中使用 AI；其中 64% 用于生成教案或课堂活动。
- **从聊天到生产**：教育场景正在，也必须从“一问一答”转向“一整套知识生产工作”，这为 Agent 深度介入创造了条件。

### 2. Token 用量十倍增长，是“工作流深化”的关键信号

OpenMAIC v1.0 的数据极具代表性：

| 指标 | 旧版 OpenMAIC | v1.0 Agent 专业工作台 |
|---|---|---|
| 平均单任务 Token 消耗 | 约 35.8 万 | 约 362.5 万 |
| 单任务平均调用模型次数 | — | 74.3 次 |
| 变化倍数 | — | ≈ 10.1 倍 |

这一变化并非单纯的功能增强，而是产品边界转移：从“课堂生成器”升级为“完整课程工作台”。AI 开始承担规划、检索、生成、互动与修改，Token 由此从账单单位变成衡量 AI 深入真实任务程度的“生产资料”。

### 3. 竞争焦点从“生成什么”转向“如何稳定生产”

过去教育数字化的重点是存储与分发，但课程生产高度依赖教师个人经验。生成式 AI 降低了课件制作门槛，也暴露出新问题：如何让 AI 理解材料、遵循教学方法、完成多轮修改，并把有效做法迁移到下一门课。

OpenMAIC v1.0 的应对是切入完整生产链：

- 用持续对话承接课程目标、受众、时长、素材；
- 调用搜索、幻灯片、Quiz、互动页面、声音、项目式学习等工具；
- 在同一任务内继续修改、复用，使课程成为“可反复编辑的内容工程”。

因此，教育 Agent 的战场不在单次课件，而在于**能否稳定生产可迭代的学习产品**。

### 4. Skill 将隐性教学经验资产化，开放 SDK 构建“教育能力层”

OpenMAIC 将费曼学习法、螺旋式课程等教学方法封装为 Skill，并允许用户自定义 Skill。原本隐性的教学设计经验由此被描述、调用、迁移，逐步沉淀为可复用的生产资产。

更重要的是，OpenMAIC 通过标准化 Skill 与 SDK 接入 DeepSeek Harness、Codex、WorkBuddy 等 Agent 工作台：

- 模型负责理解与推理；
- Harness 提供工具调用、进度保存与连续执行环境；
- OpenMAIC 提供课程生产能力。

这意味着教育能力开始像搜索、写作、编程一样，成为可嵌入不同场景的通用能力。产品边界从“课程生成工具”，走向“课程生产系统”，再进一步成为 Agent 生态中的“教育能力层”。

### 5. 开源是一种产业策略，争夺的是关键中间层

文章认为，当基础模型逐步趋同，教育 Agent 的竞争会从单点功能转向工作流与生态。谁能让更多教学法被复用、让更多开发者接入、让课程能力在不同 Harness 之间流动，谁就更可能定义教育内容的新生产标准，并承接由此产生的 Token 消耗。

教育 Agent 价值链可拆为：

- **上游**：基础模型，提供推理与多模态能力；
- **中游**：组织任务、调用工具、沉淀教学方法的生产系统；
- **下游**：学校、教师、具体课程。

OpenMAIC 选择开源并保持模型与 Harness 的开放性，允许替换模型与材料、本地部署、二次开发，适配不同语言、文化与教学目标。其争取的正是中游“关键中间层”的标准与生态位。

### 6. 走进联合国，是中国 AI 从参数输出到方法输出的标志

这场 UNESCO 官方活动中，团队用 90 分钟向各国教师、校长、教育管理者和政策制定者介绍 OpenMAIC，并让参与者亲手生成课程。其意义在于：

- 对资源有限的学校和教师，开放的课程生产能力降低了优质内容门槛；
- 对 AI 教育行业，开放使技术路径和教学假设可被检验、比较与修正；
- 对中国 AI 而言，模型参数和榜单展示技术能力，开源应用则把能力变成全球教育工作者可以使用、修改和再创造的工具。

中国团队输出的不仅是一款产品，更是一套建设 AI 原生学习环境的方法。

## 二、对行业的启发与影响

### 1. 对教育行业：从课件工具到课程生产系统

教师角色将从“独自完成课程生产”转向“调用、审查与修改 Agent 生产结果”。教学法、课程设计经验可通过 Skill 被沉淀和复用，从而降低优质课程的生产门槛，并推动教师能力从“制作”向“教学设计 + 质量判断”升级。

### 2. 对内容行业：存量知识获得“第二条生命线”

OpenMAIC 的案例显示，旧教案、历史报道、专业文章均可在 Agent 中被重组为讲解、互动、小测甚至决策模型。内容不再止于一次阅读，而可以生长为可操作、可反馈、可迭代的学习产品，为媒体、出版、知识付费打开新的资产复用与商业变现空间。

### 3. 对 AI/Agent 产业：Token 经济的新入口正在形成

教育场景的 Token 消耗增长证明，Agent 深度介入长链条任务会带来数量级的用量提升。衡量产品价值的指标将从单一的生成次数、MAU，转向**单任务 Token 消耗、模型调用次数、任务完成深度与可复用资产沉淀**。工作流 + Skill + 开放生态，可能成为 Agent 应用竞争的新壁垒。

### 4. 对开发者与生态：教育能力将成为可嵌入的基础能力

通过 SDK 与 Harness 标准接口，课程生成不再是独立产品，而可以嵌入编程、办公、企业培训等各类 Agent。教育能力的中台化趋势明显，未来可能出现“教育中间层”的生态竞争，类似今天搜索、支付、地图在移动互联网中的位置。

### 5. 对教育公平与公共政策：开源、可检验与本地化是关键

开源使不同语言、文化与资源水平的地区都能部署和二次开发，降低优质教育内容的门槛。但同时也对课程质量评估、教学法有效性验证、数据治理与本地化适配提出更高要求。政策制定者应关注如何将开放的 AI 教育能力纳入公共教育体系，而非仅依赖商业产品。

### 6. 对中国 AI 全球化：从模型性能到方法、标准与生态输出

OpenMAIC 走进联合国表明，中国 AI 的全球竞争力不再只体现为参数与榜单，也可以体现为**可被全球用户采纳的工作流、教学法封装与开源生态**。这种“能力层”的标准化与生态化输出，或将成为中国 AI 在应用出海、标准定义与产业影响力上的新路径。
