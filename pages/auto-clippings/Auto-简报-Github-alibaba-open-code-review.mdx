### 核心总结
- OpenCodeReview是阿里巴巴开源的AI驱动代码审查CLI工具，前身为阿里内部官方AI代码评审助手，历经两年大规模落地验证（服务数万名开发者、识别百万级代码缺陷）后对外开源，仅需配置大模型端点即可投入使用。
- 该工具依托具备工具调用能力的Agent读取代码变更、调用可配置大模型，可生成行级精准的结构化评审意见，还支持全文件扫描以适配无有效diff的代码审计场景；使用相同底层模型时，相较通用Agent（Claude Code）精度、F1值显著更高，token消耗仅约为其1/9。
