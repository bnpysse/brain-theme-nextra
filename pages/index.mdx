# 欢迎访问 Woodman 的第二大脑 (Second Brain)

这里是基于 Nextra 与 Cloudflare 全球 CDN 托管的知识沉淀库与个人数字花园。

## 核心架构概览

- 🤖 **TG Bot / 音视频流水线**：实时抓取头条/抖音/B站/YouTube，调用百炼 SenseVoice 进行音轨转录与多模型智能摘要。
- 📡 **信息雷达 (RSS Fetcher)**：自动化追踪 Reddit、GitHub Trending、Substack 精选大咖专栏。
- 🌐 **双轨网络体系**：基于 Cloudflare Tunnel (`imdld.com`) 与 DDNS (`donglida.xyz`) 构建的高可用私有云架构。
- 📊 **Omni 智能看板**：集成量化与多维数据全景分析。
